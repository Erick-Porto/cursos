## :icon[eye] Por que isso importa

Você investiu horas em modelagem, SQL, transações, backup e um projeto completo. Esse conhecimento só vira oportunidade quando alguém **consegue encontrá-lo**.

:::center
![Funil da oportunidade em quatro etapas: visibilidade, contato, entrevista e vaga, cada uma mais estreita que a anterior](images/34-funil-da-oportunidade.svg)
:::

Cada etapa depende da anterior: sem visibilidade não há contato; sem contato não há entrevista. Esta aula trabalha a boca do funil.

:::question
Se um recrutador buscasse "DBA júnior MySQL" hoje, seu perfil apareceria?
:::

---

## :icon[search] Como recrutadores buscam DBAs

Recrutadores não leem perfis um a um. Eles **pesquisam por palavras-chave** e só abrem os perfis que aparecem.

| Tipo | Palavras-chave que buscam |
|---|---|
| Tecnologias | MySQL, PostgreSQL, SQL |
| Rotinas de DBA | backup, restore, performance, modelagem de dados |
| Programação | stored procedures, triggers, views |
| Cargos | DBA júnior, analista de banco de dados |
| Ferramentas | MySQL Workbench, DBeaver, Git |

:::tip
Use os termos exatamente como aparecem nas vagas. "Backup e restore" é encontrado; "cópias de segurança" costuma não ser.
:::

## :icon[id-card] Perfil no LinkedIn: título e resumo

O **título** aparece em toda busca e em cada comentário seu. É o campo mais lido do perfil.

::::columns
:::col
**Fraco**

`Estudante | Em busca de oportunidades`
:::
:::col
**Forte**

`DBA Júnior | MySQL | PostgreSQL | SQL | Backup e performance`
:::
::::

O **resumo** ("Sobre") tem três parágrafos curtos: quem você é, o que sabe fazer (com as palavras-chave) e o que busca. Cite o projeto final.

:::tip
Foto com rosto visível e fundo neutro. Personalize a URL do perfil com seu nome.
:::

## :icon[graduation-cap] Cadastrando este curso no LinkedIn

A seção **Formação acadêmica** é onde o curso ganha palavras-chave e um certificado anexado.

:::steps
1. No perfil, clique em **Adicionar seção do perfil** e escolha **Formação acadêmica**
2. Instituição: o nome da escola ou plataforma onde você fez o curso
3. Diploma: "Curso livre" ou "Qualificação profissional"; área de estudo: "Administração de Banco de Dados"
4. Datas de início e término (ou marque "estudando atualmente")
5. Descrição: cole e adapte o modelo desta aula
6. Mídia: anexe o certificado em PDF e salve
:::

## :icon[file-text] Modelo de descrição do curso

Cole na descrição da formação e troque os colchetes pelos seus dados. Palavras-chave no texto, não só na lista de competências.

```plaintext
Administração de Bancos de Dados (MySQL 8) - [carga horária] horas
Instituição: [nome]. Conclusão: [mês/ano].

Competências desenvolvidas:
- Modelagem conceitual e lógica (MER, normalização até a 3FN)
- SQL: consultas com JOIN e subconsultas, DDL, DML, views e índices
- Transações, níveis de isolamento, locks e deadlocks
- Stored procedures, triggers e tabelas temporárias
- Monitoramento, EXPLAIN e estratégias de índices
- Backup e restore com mysqldump, auditoria

Projeto final: banco de dados completo para [tema], com DDL, DML,
procedures, triggers, views e backup. Repositório: [link do GitHub].
```

:::tip
Mantenha até 15 linhas. Recrutadores leem em diagonal.
:::

## :icon[flask-conical] Pratique

:::example
Em um bloco de notas, escreva agora:

1. Seu **título** do LinkedIn, com até 3 palavras-chave de DBA
2. As **5 competências** que você quer no topo do perfil
3. Uma frase sobre o **projeto final**: tema, o que o banco faz e quais recursos usou (procedures, triggers, backup)

Depois compare com o modelo de descrição desta aula. As palavras-chave que faltam no seu texto são as que o recrutador não vai encontrar.
:::

## :icon[megaphone] Publicar e fazer rede

::::columns
:::col
**Publicar sem exagero**

- Conclusão do curso, com imagem do certificado
- Projeto final: tema, função do banco e link do GitHub
- Um aprendizado concreto do curso
- Três a cinco hashtags: #MySQL #SQL #DBA
:::
:::col
**Networking estratégico**

- :icon[user-plus] Siga DBAs, engenheiros de dados e recrutadores
- :icon[message-square] Comente com perguntas, não só "parabéns"
- :icon[users] Entre em grupos de MySQL, PostgreSQL e carreira em TI
- :icon[send] Convite sempre com uma nota: quem você é e por que quer se conectar
:::
::::

:::warning
Concluir um curso não faz de você "especialista". Diga o que fez e o que sabe fazer: a credibilidade vem da precisão.
:::

## :icon[file-text] Currículo de DBA júnior

Uma página, em PDF, adaptada a cada vaga. Sem experiência formal, os **projetos** carregam o currículo.

:::steps
1. **Contato**: nome, cidade, e-mail, telefone, links do LinkedIn e do GitHub
2. **Resumo**: duas linhas com cargo pretendido e principais tecnologias
3. **Competências técnicas**: bancos, SQL, administração, ferramentas
4. **Formação**: este curso e outras formações, da mais recente para a mais antiga
5. **Projetos**: o projeto final, com tecnologias e o que você construiu
6. **Experiência**: estágios ou outros empregos, destacando o que é transferível
:::

Modelo da seção Formação:

```plaintext
FORMAÇÃO
Administração de Bancos de Dados (MySQL 8) - [instituição], [mês/ano]
Modelagem, SQL, transações, procedures e triggers, EXPLAIN e índices,
backup e restore com mysqldump, auditoria.
Projeto final: [tema] - DDL, DML, procedures, views e backup.
github.com/[usuario]/[repositorio]
```

## :icon[git-branch] GitHub como portfólio

Um gestor técnico abre o repositório antes da entrevista. A entrega do projeto final já tem a estrutura certa: basta publicar.

:::center
![As três vitrines do DBA júnior: o currículo aponta para o LinkedIn e para o GitHub, e o LinkedIn aponta para o GitHub](images/34-tres-vitrines.svg)
:::

- :icon[square-check] Repositório público com nome claro, como `clinica-mysql`
- :icon[square-check] `README.md`: o que o banco faz, como executar os scripts na ordem, imagem do modelo
- :icon[square-check] `ddl.sql`, `dml.sql`, `procedures.sql`, `consultas.sql` e `backup.sql`
- :icon[square-check] Dados de teste fictícios, nunca dados reais de pessoas
- :icon[square-check] Link do repositório no LinkedIn e no currículo

## :icon[triangle-alert] Erros comuns

:::warning
- Título "Estudante" sem nenhuma palavra-chave de banco de dados
- Perfil cadastrado e abandonado: sem publicação, sem comentário, sem rede
- Convite de conexão sem mensagem, ou com pedido de vaga logo na primeira frase
- Publicação inflada: "especialista em todos os bancos" depois de um curso
- Currículo de três páginas que mistura tudo, ou repositório sem README
:::

## :icon[compass] Para continuar estudando

O mercado de dados muda rápido. Três caminhos que aproveitam o que você já sabe:

- :icon[award] **Certificações**: Oracle MySQL 8.0 Database Administrator (1Z0-908) valida a administração; certificações de nuvem cobrem bancos gerenciados
- :icon[database] **PostgreSQL**: `pg_dump`, `EXPLAIN ANALYZE`, roles e extensões; muitas vagas pedem os dois SGBDs
- :icon[cloud] **Nuvem**: bancos gerenciados como Amazon RDS, Google Cloud SQL e Azure Database for MySQL; backup e replicação viram configuração

:::tip
Escolha um caminho e crie um segundo projeto no GitHub com ele. Portfólio cresce com projetos, não com listas de cursos.
:::
