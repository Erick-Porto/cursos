Este curso forma a base de um **administrador de bancos de dados júnior**. Você começa entendendo
o que é um SGBD e termina operando um banco MySQL de verdade: modelando, consultando, protegendo
dados com transações, programando no banco, medindo desempenho, fazendo backup e auditando.

**Para quem é:** pessoas que já usam o computador com desconforto zero, mas nunca administraram um
banco de dados. Não é preciso saber programar. Quem já conhece SQL básico pode avançar mais rápido
pelos módulos de consultas.

**O que você vai construir:**

- um modelo de dados completo (do MER ao script de criação) para um sistema de biblioteca
- consultas com filtros, agregações, JOINs e subconsultas sobre uma base de loja virtual
- procedures, triggers e views em um laboratório gamificado de RPG
- um plano de backup com restauração testada e uma trilha de auditoria por triggers

**Como funciona:** 34 aulas curtas, em 8 módulos, cada uma com um quiz de fixação. Duas provas
parciais e uma prova final liberam o certificado. O dialeto usado nos exemplos é o **MySQL 8**, com
observações sobre o PostgreSQL quando a diferença importa.
