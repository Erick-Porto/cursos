Este curso apresenta os conceitos essenciais de bancos de dados relacionais e a linguagem SQL
do zero. Ao final, você será capaz de ler dados de uma tabela, escolher colunas e filtrar linhas
com segurança.

**Para quem é:** pessoas sem experiência prévia com bancos de dados.

**Como funciona:** cada aula tem slides curtos e um quiz de fixação. A prova final libera o
certificado de conclusão do curso.
