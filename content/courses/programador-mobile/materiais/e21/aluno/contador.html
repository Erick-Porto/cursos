Contador em JavaScript puro

O mesmo contador do slide, para testar e acompanhar a demonstração do instrutor. Funciona no computador e no celular.

1. Teste o contador

Cliques: 0

Na memória total = 0

2. Acompanhe a demonstração

  1. Clique em Clicar três vezes. A tela e a memória mostram 3.
  2. No computador, aperte F12, abra a aba Console, digite total e aperte Enter. Aparece 3: é a mesma variável do quadro "Na memória".
  3. Marque Desligar a linha e clique mais três vezes. A tela fica parada em 3.
  4. Olhe o quadro "Na memória" (ou digite total no Console de novo): vale 6.

A variável mudou; a tela não. No JavaScript puro, cada clique pede duas atualizações, o dado e a tela, e manter as duas em dia é trabalho seu.

3. O código, linha por linha

contador.html 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Contador</title>
</head>
<body>
  <p>Cliques: <span id="total">0</span></p>
  <button id="botao">Clicar</button>

  <script>
    let total = 0
    const span = document.querySelector('#total')
    const botao = document.querySelector('#botao')

    botao.addEventListener('click', () => {
      total = total + 1
      span.textContent = total
    })
  </script>
</body>
</html>
<span id="total">0</span>
O lugar da tela onde o número aparece. O id é o nome que o JavaScript usa para encontrá-lo.
let total = 0
A variável que guarda o número de cliques, na memória. Começa em 0. É let, e não const, porque o valor muda a cada clique (E05).
const span = document.querySelector('#total')
A novidade de hoje. O navegador monta o DOM, a árvore de elementos da página: é a cópia que você editou na aba Elements do DevTools, no E01. O querySelector procura nessa árvore o elemento com id="total"; o # indica id, como num seletor de CSS. O elemento encontrado fica guardado em span.
botao.addEventListener('click', () => { ... })
Espera o clique. A arrow function (E07) é um callback (E10): o navegador a chama a cada clique, como o setTimeout do E18 chama a função quando o tempo acaba.
total = total + 1
Atualiza o dado.
span.textContent = total
Atualiza a tela: troca o texto do elemento no DOM. Sem esta linha, o dado muda e a tela fica parada.

4. Pense

Aqui são só duas coisas para manter em dia: a variável e um span. Em um app com dezenas de telas, quem garante que tudo muda junto a cada clique? É o problema que o React resolve: no próximo slide, o mesmo contador em React.

5. Refaça em casa

Crie um arquivo contador.html no VS Code, cole o código copiado acima, salve e abra o arquivo no navegador.

Desafio: acrescente um botão Zerar que volta o contador a 0. Lembre de atualizar o dado e a tela.
