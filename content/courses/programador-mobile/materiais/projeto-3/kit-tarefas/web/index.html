    O que a página usa

    Cada item vem do seu código em src/, com os nomes do enunciado. A página confere com os exemplos do enunciado (hoje = 10/11/2026). Salvou um arquivo? Recarregue a página.

    Tela pronta do curso: você não precisa mudar estes arquivos. Se algo sair errado, o problema está no seu código, e o teste dele é o melhor lugar para achar.
