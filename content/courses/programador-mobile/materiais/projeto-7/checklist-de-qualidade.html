Checklist de qualidade

Antes do APK, cada pessoa passa a sua tela por estes nove itens, no próprio celular. O que falhar vira uma correção na branch qualidade- mais o nome da tela, com pull request. A banca confere os mesmos itens no E45.

A sua tela

0 de 9 itens conferidos As marcações ficam só neste navegador.

Os nove itens

Como conferir
git switch main, git pull e npx expo start -c. Abra a sua tela e faça tudo o que ela faz. Olhe o celular e o terminal.
Se falhar
Leia a mensagem inteira: ela diz o arquivo e a linha. Aviso de key numa lista: falta o keyExtractor da FlatList ou a key no map.
Como conferir
Troque o tema pelo botão da aba Sobre e, depois, pelo tema do celular, com o app aberto.
Se falhar
O texto precisa da cor do tema no array de style: [estilos.nome, { color: cores.texto }], com const { cores } = useTema();.
Como conferir
No terminal, na pasta do app. A primeira busca deve vir vazia:
terminal
git grep -n -E "#[0-9a-fA-F]{3,8}\b" -- app src/components ":(exclude)src/components/ui"
git grep -n -E "(fontSize|gap|padding|margin|borderRadius): [0-9]" -- app src/components ":(exclude)src/components/ui"
Se falhar
Troque padding: 16 por padding: espaco.md e fontSize: 24 por fontSize: fonte.titulo, com import { espaco, fonte } from '@/theme';. Medidas de tamanho, como width: 72, podem ficar.
Como conferir
Apague tudo pela sua tela (ou cancele, ou esvazie o carrinho). A lista mostra o aviso. Tela sem lista: marque e siga.
Se falhar
Na FlatList, ListEmptyComponent={<EstadoVazio titulo="Nenhum lançamento" mensagem="..." />}.
Como conferir
Toque em salvar com tudo vazio. Depois, preencha um campo errado de cada vez. Toque em cada campo: o teclado certo aparece (o numérico no valor). Tela sem formulário: marque e siga.
Se falhar
A função validar() devolve um objeto com uma mensagem por campo, e cada Campo e cada Opcoes recebe a sua com a prop erro, como no Projeto 6.
Como conferir
Ligue o TalkBack (Android: Configurações, Acessibilidade) ou o VoiceOver (iPhone) e toque uma vez em cada cartão e em cada botão. Desligue antes de continuar.
Se falhar
BotaoIcone sempre com rotulo, como rotulo={`Apagar ${lancamento.descricao}`}. No bloco do cartão, accessible e um accessibilityLabel com tudo numa frase.
Como conferir
Nas configurações do celular, aumente o tamanho da fonte ao máximo e volte ao app. Volte o tamanho depois.
Se falhar
O bloco dos textos precisa de flex: 1 para quebrar a linha, como a coluna do cartão no Projeto 6.
Como conferir
Crie ou apague algo pela sua tela. Tire o Expo Go da lista de apps abertos e abra o app de novo.
Se falhar
A tela precisa usar o adicionar ou o remover do quadro (useContext), e não um useState próprio com a lista.
Como conferir
Leia a sua tela em voz alta, do título ao último botão. Procure no código: git grep -n "Em construção" -- app deve vir vazio no fim.
Se falhar
Troque pelo texto que a pessoa do briefing entende, sem palavra técnica.

Tudo marcado? Commit na branch qualidade- mais o nome da tela, push e pull request. O APK sai da main com todas as correções.
