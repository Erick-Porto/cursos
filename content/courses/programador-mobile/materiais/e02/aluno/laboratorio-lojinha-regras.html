Laboratório: o projeto lojinha-regras

Hoje nasce a pasta que acompanha você até o E20: os dados da Lojinha, um script que grava o catálogo em JSON e um relatório no terminal, tudo com um package.json e um pacote instalado do npm. Tempo: 55 minutos. Rode todos os comandos no terminal do VS Code, aberto na pasta lojinha-regras.

O que entregar

0 de 8 itens prontos. As marcações ficam só neste navegador.

Passo a passo

  1. Abra a pasta lojinha-regras no VS Code

    Se ainda não existe, crie na sua pasta de projetos: mkdir lojinha-regras, cd lojinha-regras e code .. O ola.js da aula pode ser apagado.

    Abra o terminal integrado pelo menu Terminal, New Terminal. Ele já começa na pasta do projeto.

  2. Crie src/data/produtos.js

  3. Crie e rode o gerador: src/scripts/gerar-catalogo.js

    Este você digita, linha por linha: é digitando que se aprende a ler um erro.

    src/scripts/gerar-catalogo.js
    import fs from 'node:fs';
import { categorias, produtos } from '../data/produtos.js';

const catalogo = { categorias, produtos };
const texto = JSON.stringify(catalogo, null, 2);
fs.writeFileSync('src/data/catalogo.json', texto);

console.log('catalogo.json gravado com', produtos.length, 'produtos');

    Rode da raiz do projeto: node src/scripts/gerar-catalogo.js. A saída é catalogo.json gravado com 12 produtos, e o arquivo src/data/catalogo.json aparece no painel. Abra e veja o mesmo catálogo, agora em JSON.

  4. Crie e rode o relatório: src/scripts/relatorio-catalogo.js

    src/scripts/relatorio-catalogo.js
    import fs from 'node:fs';

const texto = fs.readFileSync('src/data/catalogo.json', 'utf-8');
const catalogo = JSON.parse(texto);
const categoria = process.argv[2];

let lista = catalogo.produtos;
let titulo = 'todas as categorias';
if (categoria) {
  lista = lista.filter((produto) => produto.categoria === categoria);
  titulo = categoria;
}

const destaques = lista.filter((produto) => produto.destaque);
const semImagem = lista.filter((produto) => produto.imagem === '');
const soma = lista.reduce((total, produto) => total + produto.preco, 0);
const media = soma / lista.length;

console.log('Relatório do catálogo:', titulo);
console.log('Produtos:', lista.length);
console.log('Em destaque:', destaques.length);
console.log('Preço médio: R$', media.toFixed(2));
console.log('Sem imagem:', semImagem.length);

    Rode node src/scripts/relatorio-catalogo.js e depois com uma categoria no fim: audio, casa, esporte ou livros. Compare com a tabela de saídas.

  5. Crie o package.json

    No terminal: npm init -y. Rode o relatório de novo. Se aparecer Cannot use import statement outside a module, ou um aviso MODULE_TYPELESS_PACKAGE_JSON, falta o "type": "module".

    Edite o arquivo até ficar assim. Se o npm escreveu "type": "commonjs", troque por "module"; se não escreveu a linha, acrescente. Cuidado com as vírgulas: cada linha termina com vírgula, menos a última de cada bloco.

    package.json
    {
  "name": "lojinha-regras",
  "version": "1.0.0",
  "description": "Regras de negócio da Lojinha",
  "main": "index.js",
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1",
    "catalogo": "node src/scripts/gerar-catalogo.js",
    "relatorio": "node src/scripts/relatorio-catalogo.js"
  },
  "keywords": [],
  "author": "",
  "license": "ISC",
  "type": "module"
}

    Agora os comandos têm nome: npm run catalogo, npm run relatorio e npm run relatorio audio. Só npm run, sem nome, lista os scripts.

  6. Instale o picocolors e pinte o relatório

    No terminal: npm install picocolors. Confira as três novidades: a seção dependencies no package.json, a pasta node_modules/ e o arquivo package-lock.json.

    No relatório, acrescente a segunda linha de import no topo e troque o primeiro e o último console.log:

    trechos de relatorio-catalogo.js
    import pc from 'picocolors';

console.log(pc.bold('Relatório do catálogo:'), titulo);
console.log(pc.yellow('Sem imagem:'), semImagem.length);

    npm run relatorio: o título sai em negrito e o "Sem imagem" em amarelo.

  7. Teste o "Sem imagem"

    No src/data/catalogo.json, procure a Bola de Futebol e esvazie a imagem: "imagem": "". Salve e rode npm run relatorio esporte: Sem imagem: 1.

    Para desfazer, não edite de volta: rode npm run catalogo. O gerador grava o JSON de novo a partir do produtos.js, e o relatório volta a Sem imagem: 0.

  8. Acrescente a linha "Acima de R$ 200"

    A dona da loja quer saber quantos produtos passam de R$ 200. Siga o modelo da linha destaques: um filter com a condição produto.preco > 200 e um console.log com o .length, logo depois do "Em destaque".

    Ver uma resposta
    as duas linhas novas
    const caros = lista.filter((produto) => produto.preco > 200);

console.log('Acima de R$ 200:', caros.length);

    A primeira vai junto das outras contas; a segunda, depois do console.log do "Em destaque". O Fone, de R$ 199,90, não entra.

  9. Apague o node_modules e recupere

    Apague a pasta node_modules pelo painel do VS Code e rode o relatório: Cannot find package 'picocolors'. Agora npm install, sem nome de pacote: o npm lê o package.json e o lock e baixa tudo de novo. O relatório volta a funcionar.

  10. Entregue

    Na entrega do laboratório E02, no sistema, cole o conteúdo do package.json e a saída de npm run relatorio casa. Guarde a pasta: no E03 ela vai para o GitHub.

Rode tudo da raiz do lojinha-regras. Com node, um terminal aberto em src/scripts/ faz o relatório procurar src/scripts/src/data/catalogo.json e falhar com ENOENT. Com npm run, o npm já roda a partir da raiz.

Terminou antes?

  • Acrescente a avaliação média, no modelo do preço médio: some produto.avaliacao em vez de produto.preco. Para o catálogo inteiro, dá 4.45.
  • Pinte de verde, com pc.green, a linha "Em destaque". A lista de cores está na página do pacote, em npmjs.com.
  • Ajude quem está ao lado a achar o erro, sem pegar o teclado.
