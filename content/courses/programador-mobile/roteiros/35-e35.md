## Visão do encontro

**Objetivo:** a turma cria o único componente próprio do Projeto 6, o `CartaoCasa`, e aprende com ele a projetar uma peça (o que recebe e o que mostra), as props de dados e de ação, os ícones do `@expo/vector-icons`, a `Image` com endereço da internet e a imagem de reserva, o retorno visual com o `pressed` do `Pressable`, o `Alert.alert` e as variantes das peças do kit. A prática é a etapa 3 do projeto: quatro passos juntos e o selo de vagas como Sua vez.

**Como a aula funciona:** como nos encontros anteriores, cada conceito vem em três slides. A seção (título e gancho) é a hora da conversa: leia o gancho, ouça duas ou três respostas e explique com a analogia indicada abaixo. A âncora é o que o aluno lê para revisar. Depois de cada conceito vem um slide **Projeto 6 · Passo K**: a turma faz junto com você, no próprio computador e no próprio celular, e só segue quando o "Pronto quando" aparece em todos. A **Sua vez** é sozinha, sem a solução no slide.

**Resultado ao fim das 4h:** no `casas-de-adocao` de cada aluno, o arquivo novo `src/components/CartaoCasa.js`, com o manual no topo, as props `casa` e `onPress`, a foto do picsum ou a pata numa caixa na cor da borda, uma linha com `location-outline` e bairro, cidade, outra com `paw-outline` e `casa.aceita`, o `Pressable` com `pressed` (opacidade 0.6) e o `Badge` com o selo e o tom da tabela de vagas. A Início (`app/index.js`) importa o `CartaoCasa`, tem `Alert` no import de `react-native`, não tem mais os estilos do cartão, nem o `Badge`, nem o `raio`, e passa a cada cartão um `onPress` com a seta, que chama o `Alert.alert` com o nome e o horário de visitas da casa. Commit `Projeto 6: etapa 3, CartaoCasa` e `git push`. O código completo está na solução de referência, no bloco "Projeto: sua vez".

**Pré-requisitos:** E33 (flexbox, a `Tela`, o atalho `@/`), E34 (tokens, `useTema()`, a cor no array de `style`, o ternário do botão de tema), E30 (`Image` local com `require`, `Pressable` com `onPress`, o caso "sem a seta"), E25 (props desestruturadas, o manual no topo das peças, a `key`), E26 (função como prop: o botão do elevador, "o pai guarda, o filho avisa"), E10 (`else if`, ternário), E13 (colchetes), E17 (`??`) e E06 (template string). A turma **não** viu: `Image` com `uri`, o `Ionicons` escrito por ela, o `style` como função de `pressed`, `opacity` e `Alert`. Tudo isso é explicado hoje.

**Materiais:** projetor com o VS Code em fonte grande e o seu celular espelhado (ou o emulador Android), Wi-Fi que deixe passar o `picsum.photos` (as fotos das casas), o site icons.expo.fyi aberto numa aba, quiz publicado. A especificação do projeto está no enunciado (página do curso, **Projetos**) e a solução completa em `privado/projetos/projeto-6/` (a etapa 3 em `etapas/etapa-3/`).

## Abertura (10 min)

## Projeto: sua vez (30 min)

**Enunciado:** o slide "Projeto 6 · Sua vez: o selo de vagas". No `CartaoCasa`, o `Badge` mostra o texto e o tom pela tabela de vagas livres: 0, "Lotada" e `perigo`; 1, "Última vaga" e `alerta`; 2 ou 3, "Últimas 2 vagas" ou "Últimas 3 vagas" e `alerta`; 4 ou mais, o número ("8 vagas") e `sucesso`.

**Organização:** individual, cada um no próprio computador e no próprio celular, sem olhar a tela do vizinho nos primeiros 15 minutos. Depois disso, quem travou pode pedir ajuda a um colega, que explica sem digitar por ele.

**Marcos:** 3:15, a `const livres` e os dois `let` antes do `return`, e o `Badge` com `texto={selo}` e `tom={tom}` (todas em verde com o número, inclusive "0 vagas"); 3:25, as três saídas da estrada; 3:35, os 12 selos conferidos e o commit.

**O que observar:**

- `if (livres = 0)`, com um sinal só: tenta guardar 0 na caixa em vez de comparar, e a `const` é a caixa lacrada, então o app mostra um erro; pergunte "quantos sinais de igual tem a pergunta?" (o `===` da aula 3) e lembre que `<=` é "menor ou igual"
- A ordem das saídas: com `livres <= 3` antes de `livres === 1`, a Casa da Pipoca fica "Últimas 1 vagas"; pergunte "qual pergunta a Casa da Pipoca responde primeiro?"
- `let selo` escrito **dentro** do `if`: fora das chaves, a caixa não existe (`Property 'selo' doesn't exist`); as caixas nascem antes do `if`
- Aspas simples no lugar da crase: aparece `Últimas ${livres} vagas`, ao pé da letra
- `tom="tom"`, com aspas: vai o texto `'tom'`, que não é variante nenhuma, e o selo fica cinza (o `??` do `Badge`)
- O cálculo depois do `return`: nunca roda

Pergunta para quem travou: "faça a tabela da bateria com a Casa da Pipoca: quantas vagas livres? Qual pergunta dá `true` primeiro?".

:::example Solução de referência
`src/components/CartaoCasa.js` no fim da etapa 3 (igual a `privado/projetos/projeto-6/etapas/etapa-3/src/components/CartaoCasa.js`):

```jsx
// CartaoCasa: o cartão de uma casa na lista.
// Props:
//   casa     o objeto da casa (nome, bairro, cidade, aceita, foto, capacidade, ocupacao...)
//   onPress  o que fazer quando tocam no cartão
import { Image, Pressable, StyleSheet, Text, View } from 'react-native';
import { Ionicons } from '@expo/vector-icons';
import { Badge, Cartao } from '@/components/ui';
import { espaco, fonte, raio, useTema } from '@/theme';

export default function CartaoCasa({ casa, onPress }) {
  const { cores } = useTema();
  const livres = casa.capacidade - casa.ocupacao;

  let selo = `${livres} vagas`;
  let tom = 'sucesso';
  if (livres <= 0) {
    selo = 'Lotada';
    tom = 'perigo';
  } else if (livres === 1) {
    selo = 'Última vaga';
    tom = 'alerta';
  } else if (livres <= 3) {
    selo = `Últimas ${livres} vagas`;
    tom = 'alerta';
  }

  return (
    <Pressable onPress={onPress} style={({ pressed }) => (pressed ? estilos.apertado : null)}>
      <Cartao style={estilos.cartao}>
        {casa.foto ? (
          <Image source={{ uri: casa.foto }} style={estilos.foto} />
        ) : (
          <View style={[estilos.foto, estilos.semFoto, { backgroundColor: cores.borda }]}>
            <Ionicons name="paw" size={32} color={cores.textoSuave} />
          </View>
        )}
        <View style={estilos.textos}>
          <Text style={[estilos.nome, { color: cores.texto }]}>{casa.nome}</Text>
          <View style={estilos.linha}>
            <Ionicons name="location-outline" size={16} color={cores.textoSuave} />
            <Text style={[estilos.detalhe, { color: cores.textoSuave }]}>
              {casa.bairro}, {casa.cidade}
            </Text>
          </View>
          <View style={estilos.linha}>
            <Ionicons name="paw-outline" size={16} color={cores.textoSuave} />
            <Text style={[estilos.detalhe, { color: cores.textoSuave }]}>{casa.aceita}</Text>
          </View>
          <Badge texto={selo} tom={tom} />
        </View>
      </Cartao>
    </Pressable>
  );
}

const estilos = StyleSheet.create({
  apertado: { opacity: 0.6 },
  cartao: { flexDirection: 'row', alignItems: 'center', gap: espaco.md },
  foto: { width: 72, height: 72, borderRadius: raio.sm },
  semFoto: { alignItems: 'center', justifyContent: 'center' },
  textos: { flex: 1, gap: espaco.xs },
  nome: { fontSize: fonte.corpo, fontWeight: 'bold' },
  linha: { flexDirection: 'row', alignItems: 'center', gap: espaco.xs },
  detalhe: { flex: 1, fontSize: fonte.pequena },
});
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `Element type is invalid ... got: undefined` | `import { CartaoCasa }`, com chaves, ou faltou o `export default` no arquivo | Um `export default` se importa sem chaves; as chaves são para os nomes da vitrine do kit |
| `Unable to resolve "@/components/CartaoCasa"` | arquivo em `src/components/ui/`, ou com outra grafia | Mover para `src/components/`; conferir as maiúsculas; `npx expo start -c` |
| Nomes em branco e "NaN vagas" | `function CartaoCasa(casa)`, sem as chaves | Mostrar com um `console.log(casa)` no começo da função: a ficha inteira das props aparece no terminal |
| Nenhuma foto, só as patas | rede da escola bloqueando o `picsum.photos`, ou `Image` sem `style` | Abrir o endereço da foto no navegador do celular; se não abrir, hotspot; senão, conferir o `style={estilos.foto}` |
| `?` no lugar de um ícone e aviso no terminal | nome de ícone que não existe (`pata`, `location_outline`) | Copiar o nome do icons.expo.fyi, com o filtro Ionicons |
| O toque não faz nada | `onPress` fora do `Pressable`, ou a Início não passou a prop | Ler as duas pontas: `onPress={onPress}` no cartão e `onPress={() => ...}` na Início |
| Avisos abrindo sozinhos ao salvar | `onPress={Alert.alert(...)}`, sem a seta | `() =>` antes do `Alert`, como no E30 |
| `Property 'Alert' doesn't exist` | `Alert` fora do import | `import { Alert, StyleSheet, Text, View } from 'react-native';` |
| Selo cinza em todos os cartões | `tom` não passado ao `Badge`, ou passado com aspas (`tom="tom"`) | `tom={tom}`, com chaves |
