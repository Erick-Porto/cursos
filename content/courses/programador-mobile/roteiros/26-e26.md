## Visão do encontro

**Objetivo:** a tela do livro de receitas passa a reagir à pessoa. A turma aprende o evento (`onClick`, `onChange`), o estado (`useState`), o input controlado, a lista filtrada a partir do estado e a função passada como prop, construindo a etapa 3 do Projeto 4: a busca com o `CampoBusca` do kit, a `ListaVazia`, o seu segundo componente, o `BotaoFavorito`, e as favoritas guardadas no `App`. Não há laboratório à parte: os passos do projeto são a prática do dia.

**Como a aula funciona:** cada conceito vem em três slides, como desde a aula 3. A seção (título e gancho) é a hora da conversa: leia o gancho, ouça duas ou três respostas e explique com a analogia indicada abaixo. O slide seguinte é a âncora, o que o aluno lê para revisar. Depois do conceito vem um slide **Projeto 4 · Passo K**: a turma faz junto com você, no próprio computador, e só segue quando o "Pronto quando" aparece na tela de todos. No fim, a **Sua vez** é feita sozinho, sem a solução no slide.

**Resultado ao fim das 4h:** no `livro-de-receitas` de cada aluno, `src/components/BotaoFavorito.jsx` (novo, com `ativo` e `aoClicar`); o `CartaoReceita` com as props `favorita` e `aoFavoritar` e o botão no `cartao__rodape`; o `App.jsx` com os estados `busca` (`useState('')`) e `favoritas` (`useState([])`), a `alternarFavorita` com `if`/`else` (põe com spread, tira com `filter`), a lista `visiveis`, o `let conteudo` com a `ListaVazia` e a grade, o `CampoBusca` com `valor` e `aoMudar` e o `Cabecalho` com `totalFavoritas={favoritas.length}`. Na tela: `frango` e `FRANGO` mostram os 2 de frango, `xyz` mostra a `ListaVazia`, o botão marca e desmarca, o cabeçalho conta "Nenhuma favorita", "1 favorita", "2 favoritas", e a marca sobrevive à busca. Commit `Projeto 4: etapa 3, busca e favoritas` e `git push`.

**Pré-requisitos:** E24 e E25: componente, JSX, Vite e `npm run dev`, props desestruturadas, `map` com `key`. Do JavaScript da grade: o `filter` (aula 3), `includes` e `toLowerCase` (E09 e E14), `if`/`else`, `!` e ternário (E10), `let` (E06), função seta (E07), `push` (E11), desestruturação de objeto (E13), spread e `filter` para tirar sem mutar (E15). A turma **não** viu estado, eventos no React, `<input>` nem `<label>`. O `useEffect` é do E27: não fale dele hoje.

**Materiais:** projetor com o VS Code em fonte grande e o Chrome com o DevTools acoplado (aba **Console**), o seu `livro-de-receitas` no fim da etapa 2, uma pasta de demonstração (abaixo), os estados de cada passo em `privado/projetos/projeto-4/instrutor/passos/e26-p1` a `e26-p4` e `etapas/etapa-3` (fora do git; só na sua máquina), a página do Projeto 4 aberta e o quiz publicado.

## Projeto: sua vez (30 min)

**Enunciado:** o slide "Projeto 4 · Sua vez: desmarcar e contar". Duas mudanças no `App`: clicar de novo desmarca (se o id está na lista, `alternarFavorita` tira com `filter`; se não está, põe com spread; sem `push` nem `splice`) e o cabeçalho conta as favoritas (a prop `totalFavoritas` do `Cabecalho`).

**Organização:** individual, cada um no próprio projeto, sem olhar a tela do vizinho nos primeiros 15 minutos. Depois, quem travou pode pedir ajuda a um colega, que explica sem digitar por ele.

**Marcos:** 3:15, clicar de novo desmarca; 3:25, o cabeçalho conta; 3:35, commit e push.

**O que observar:**

- `if` sem `else`, com dois `setFavoritas` seguidos: o segundo vence, a receita nunca desmarca, e um clique a mais na pizza mostra "2 favoritas".
- `filter` invertido (`item === id`): desmarcar a pizza com o brigadeiro marcado tira o brigadeiro e deixa a pizza ("1 favorita", a pizza ainda cheia).
- `totalFavoritas={favoritas}`, a lista em vez do tamanho: o cabeçalho mostra " favoritas", "1 favoritas" e depois "1,35 favoritas".
- `favoritas.splice(...)` ou `push`: a tela não muda.
- O total escrito dentro do `BotaoFavorito` ou um `useState` novo para o total: "o total sai da lista; dá para calcular, não vira estado".

Pergunta para quem travou: "o `includes` responde o quê para um id que já está na lista? E qual peneira tira só ele?"

:::example Solução de referência
`src/App.jsx` no fim da etapa 3 (o comentário das etapas do kit continua no topo; aqui ele foi omitido):

```jsx
import { useState } from 'react'
import Cabecalho from './components/Cabecalho.jsx'
import CampoBusca from './components/CampoBusca.jsx'
import ListaVazia from './components/ListaVazia.jsx'
import Rodape from './components/Rodape.jsx'
import CartaoReceita from './components/CartaoReceita.jsx'
import { receitas } from './data/receitas.js'

function App() {
  const [busca, setBusca] = useState('')
  const [favoritas, setFavoritas] = useState([])

  function alternarFavorita(id) {
    if (favoritas.includes(id)) {
      setFavoritas(favoritas.filter((item) => item !== id))
    } else {
      setFavoritas([...favoritas, id])
    }
  }

  const visiveis = receitas.filter((receita) =>
    receita.name.toLowerCase().includes(busca.toLowerCase())
  )

  let conteudo
  if (visiveis.length === 0) {
    conteudo = <ListaVazia busca={busca} />
  } else {
    conteudo = (
      <div className="grade">
        {visiveis.map((receita) => (
          <CartaoReceita
            key={receita.id}
            nome={receita.name}
            foto={receita.image}
            cozinha={receita.cuisine}
            minutos={receita.prepTimeMinutes + receita.cookTimeMinutes}
            dificuldade={receita.difficulty}
            porcoes={receita.servings}
            nota={receita.rating}
            favorita={favoritas.includes(receita.id)}
            aoFavoritar={() => alternarFavorita(receita.id)}
          />
        ))}
      </div>
    )
  }

  return (
    <>
      <Cabecalho totalFavoritas={favoritas.length} />
      <main className="conteudo">
        <CampoBusca valor={busca} aoMudar={setBusca} />
        {conteudo}
      </main>
      <Rodape autor="Ana Souza" />
    </>
  )
}

export default App
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| Tela branca; Console: `ReferenceError: useState is not defined` | faltou o `import` | `import { useState } from 'react'` na primeira linha do `App.jsx` |
| Ao digitar, Console: `TypeError: aoMudar is not a function` | `<CampoBusca valor={busca} />` sem o `aoMudar` | `aoMudar={setBusca}` |
| O campo não aceita digitação; Console: ``You provided a `value` prop to a form field without an `onChange` handler`` | só aparece num input próprio, sem `onChange` | o `onChange` com `evento.target.value` |
| `FRANGO` não acha nada, `frango` acha | `toLowerCase` só no nome | `busca.toLowerCase()` também |
| A busca não filtra nada | o `map` ainda percorre `receitas` | `visiveis.map(...)` |
| 16 cartões na tela | a grade foi copiada para o `else`, não recortada | apagar a grade que sobrou no `return` |
| Tela de erro do Vite: `[PARSE_ERROR] Empty parenthesized expression` | `conteudo = (` e `)` sem a grade entre eles | colar a grade dentro dos parênteses |
| Os botões disparam sozinhos; Console: `Cannot update a component (App) while rendering a different component (BotaoFavorito)` (no passo 3, só as 8 linhas `Favoritar ...` ao abrir a página) | `onClick={aoClicar()}` | `onClick={aoClicar}`, sem parênteses |
| Console: ``Invalid event handler property `onclick`. Did you mean `onClick`?``; o clique não faz nada | `onclick` minúsculo | `onClick` |
| O clique não muda nada, sem erro | `favoritas.push(id)` e `setFavoritas(favoritas)` | `setFavoritas([...favoritas, id])` |
| `lamen` não acha "Lámen japonês" | a busca diferencia acentos | digitar com acento; é o esperado (comparar sem acento fica fora do curso) |
