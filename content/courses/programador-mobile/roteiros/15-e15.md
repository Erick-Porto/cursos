## Visão do encontro

**Objetivo:** levar a turma das funções puras às classes da loja: produto e pedido calculam e validam a si mesmos, e os scripts só perguntam. O ponto central, que não se corta: um método que "muda" devolve uma instância nova; para guardar, usam-se os dados simples do `paraJSON()`; para calcular, a classe é recriada a partir deles. No Projeto 3, a classe `Tarefa` nasce com os mesmos recursos, e a lista aparece pela primeira vez na tela, desenhada no DOM pelo aluno (etapa 3).

**Slides de seção:** cada conceito abre com um slide que tem só o nome dele e uma pergunta de gancho, no centro ("Classe e instância", "Getters", "Uma instância nova"). É a hora da conversa: faça a pergunta do gancho, que é a indicada abaixo, ouça duas ou três respostas e explique com a analogia. O slide seguinte, a âncora, ensina o mesmo conceito por escrito, para quem revisa em casa e estuda para as provas; em aula, passe por ele apontando o que acabou de dizer, sem ler tudo. Depois da âncora vem um slide "... na prática", com dois ou três casos de uso e a saída de cada um: peça à turma a saída antes de mostrá-la. As analogias do encontro se encaixam: a classe é a forma de bolo e a instância é o bolo; o estático é o pedido feito à confeitaria; os dados simples do `paraJSON()` são a encomenda escrita, que guarda o pedido para fazer o bolo de novo. Cada aula começa com "Palavras novas de hoje", e o código com sintaxe nova vem traduzido num slide "... em português": leia a tradução em voz alta.

**Resultado ao fim das 4h:** `src/modelos/Produto.js` e `src/modelos/Pedido.js` com pelo menos 10 testes verdes; cada aluno explica por que `pedido.status = 'pago'` estraga o histórico de versões. A `src/scripts/vitrine.js` com o `Produto` (preço, preço no Pix e "[destaque]") fica para casa. No Projeto 3, a etapa 2 conferida e a etapa 3 (classe `Tarefa` e a lista na tela) começada.

**Pré-requisitos:** `lojinha-regras` do E14 com `npm test` e `npm run verificar` verdes (E04); `paraCentavos`, `paraReais` e `precoComPix` em `src/regras/precos.js` e `formatarPreco` em `src/utils/formatar.js` (E05); `subtotal` (E07) e `contarItens` (E09) em `src/regras/carrinho.js`; `this` em objeto literal e `export default` (E11a); referência e cópia rasa (E11b).

**Materiais:** projetor com editor e terminal lado a lado, em fonte grande; quadro com duas cores; branch `e15-solucao` no seu repositório de demonstração; quiz publicado e, para o bloco Projeto, a página do Projeto 3 e o [Guia do DOM](materiais/projeto-3/guia-dom.html).

**Seção "Classe e instância" (5 min).** Faça a pergunta do slide: "com uma forma de bolo, quantos bolos dá para fazer?". E saem todos iguais? Esperado: quantos quiser; todos com o mesmo formato, cada um com o seu recheio. "A classe é a forma, escrita uma vez; cada instância é um bolo feito com ela." "O `new` é a hora de fazer o bolo: pega a classe e entrega uma instância pronta." Leia os quatro passos de "O que o new faz" e continue no `rascunho.js`; os passos 2 e 4 são os de "Cada instância tem os seus dados", o slide de prática da seção:

**Seção "Métodos" (4 min).** Faça a pergunta do slide: "que perguntas um produto deveria saber responder sozinho?". Esperado: a categoria, o preço de várias unidades, se está em destaque. Mostre que não há `function` nem vírgula entre os métodos. Rode o laço de "Métodos na prática: a vitrine pergunta" e peça as duas linhas da saída antes.

**Seção "O this" (9 min).** Faça a pergunta do slide: "quando a Ana diz 'eu' e o Bruno diz 'eu', é a mesma pessoa?". Esperado: não; depende de quem fala. "O `this` é o 'eu' do método: vale a instância que vem antes do ponto." Em "this na prática", chame `fone.precoPara(2)` e `caixa.precoPara(2)` e monte no quadro a tabela chamada, `this`, resultado. Pergunte: "Quem é o `this` em `caixa.precoPara(2)`?" Esperado: a `caixa`, que vem antes do ponto. Mostre o método solto em duas linhas: `const calcular = fone.precoPara;` e `calcular(2)` dão `TypeError: Cannot read properties of undefined (reading 'preco')`. Para quem travou: "Quem é o `this` aqui?" e "Isso é dado ou cálculo?".

:::example Solução de referência
`src/modelos/Produto.js`, primeira parte:

```javascript
import { paraCentavos, paraReais, precoComPix } from '../regras/precos.js';
import { formatarPreco } from '../utils/formatar.js';

export default class Produto {
  constructor({
    id, nome, preco, categoria, imagem, descricao,
    destaque = false, avaliacao = 0,
  }) {
    this.id = id;
    this.nome = nome;
    this.preco = preco;
    this.categoria = categoria;
    this.imagem = imagem;
    this.descricao = descricao;
    this.destaque = destaque;
    this.avaliacao = avaliacao;
  }

  static deJSON(obj) {
    if (!obj || typeof obj.preco !== 'number') {
      throw new Error('Produto inválido no JSON');
    }
    return new Produto(obj);
  }

  static listaDeJSON(lista) {
    return lista.map((obj) => Produto.deJSON(obj));
  }
```

`src/modelos/Produto.js`, segunda parte:

import { contarItens, subtotal as somarItens } from '../regras/carrinho.js';
import { paraCentavos, paraReais } from '../regras/precos.js';
import { formatarPreco } from '../utils/formatar.js';

const STATUS = ['pendente', 'pago', 'enviado', 'entregue', 'cancelado'];

export default class Pedido {
  constructor({ id, itens = [], status = 'pendente', frete = 0, desconto = 0 }) {
    this.id = id;
    this.itens = itens;
    this.status = status; // passa pelo setter, que valida
    this.frete = frete;
    this.desconto = desconto;
  }

  get status() {
    return this._status;
  }

  set status(valor) {
    if (!STATUS.includes(valor)) {
      throw new Error(`Status inválido: ${valor}`);
    }
    this._status = valor;
  }

  get quantidade() {
    return contarItens(this.itens);
  }

  get subtotal() {
    return somarItens(this.itens);
  }

  get total() {
    const centavos = paraCentavos(this.subtotal + this.frete - this.desconto);
    return paraReais(Math.max(centavos, 0));
  }

  comStatus(novo) {
    return new Pedido({ ...this.paraJSON(), status: novo });
  }

  paraJSON() {
    const { id, itens, status, frete, desconto } = this;
    return { id, itens, status, frete, desconto };
  }

  toString() {
    return `Pedido ${this.id}, ${this.status}, ${formatarPreco(this.total)}`;
  }

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `Class constructor Produto cannot be invoked without 'new'` | Faltou `new` | Procurar `Produto(` sem `new` antes; nos scripts, preferir `Produto.deJSON(dados)` |
| `ReferenceError: preco is not defined` dentro de um método | Leu `preco` em vez de `this.preco` | "Quem guarda o preço?" Toda propriedade, dentro da classe, é `this.alguma` |
| `Cannot read properties of undefined (reading 'preco')` | Método passado solto, sem objeto antes do ponto | Chamar com ponto, como no E11 |
| `produto.emDestaque is not a function` | Getter chamado com parênteses, inclusive em script ou teste antigo | Tirar os parênteses em todo lugar que usa o getter |
| `Maximum call stack size exceeded` ao criar o `Pedido` | O setter faz `this.status = valor` | Gravar em `this._status`; o getter lê `this._status` |
| Histórico com o mesmo status em todas as versões | `pedido.status = ...` ou um método que muda `this` | `comStatus` devolve `new Pedido(...)`; quem guardou o antigo não é afetado |
| Pedido pago volta a "pendente" ao ler o arquivo | Gravou `JSON.stringify(pedido)` ou `{ ...pedido }` | Gravar `pedido.paraJSON()` |
| Teste de `precoFormatado` falha com textos que parecem iguais | O `formatarPreco` usa um espaço que não quebra linha depois de "R$" | Comparar com `formatarPreco(199.9)` ou usar `toContain('199,90')` |
| `ERR_MODULE_NOT_FOUND` ao rodar um script | Import relativo sem `.js` | No Node, o import de um arquivo seu leva a extensão: `'../modelos/Produto.js'` |
| `Cannot find module './Produto.js'` só no CI | Arquivo salvo como `produto.js`; o Windows ignora a diferença | Renomear com `git mv produto.js Produto.js` e novo commit |
| Projeto 3: a página mostra o molde e o Console acusa 404 ou CORS | Import sem `.js` no `app.js`, ou a página aberta pelo `file://` | Ler no Console o endereço que falhou; abrir sempre pelo `npx serve .` |
