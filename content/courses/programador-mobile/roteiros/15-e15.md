## Visão do encontro

**Objetivo:** ensinar a mudar dados sem rasurar o original. A turma entende o que é uma referência (o endereço da casa), tira cópias com o spread em listas e em fichas, adiciona, remove e edita sem mutar, e usa o `reduce` com uma ficha no visor para agrupar. Tudo isso construindo a etapa 3 da Agenda de contatos: `proximoId`, `adicionarContato`, `removerContato` e `editarContato` no `edicao.js`, `agruparPorLetra` no `lista.js` e as letras no terminal. A Sua vez é o `aniversariantesDoMes`. É o encontro mais cheio do Projeto 2: o ritmo do Bloco 1 decide se o passo 2 é feito junto ou sozinho (veja "Plano de ritmo do passo 2").

**Como a aula funciona:** cada conceito vem em três slides. A seção (título e gancho) é a hora da conversa: leia o gancho, ouça duas ou três respostas e explique com a analogia indicada abaixo. O slide seguinte é a âncora, o que o aluno lê para revisar. Depois vêm os exemplos "na prática": peça a previsão de uma saída antes de rodar. Todo `reduce` e todo laço tem a sua tabela volta por volta: monte no quadro com a turma **antes** de mostrar a do slide. Os slides **Projeto 2 · Passo K** são feitos juntos, cada um no próprio computador, e só se segue quando o "Pronto quando" aparece em todas as telas. A Sua vez é sozinha, sem a solução no slide.

**As duas analogias do dia** (as do curso inteiro; voltam no quiz e na prova): a **referência** é o endereço de uma casa, e dois papéis com o mesmo endereço levam à mesma casa; o **spread**, e a imutabilidade, é tirar uma cópia e mexer na cópia, sem rasurar o original. O `reduce` continua a calculadora que vai acumulando, da aula 3, e o `import` continua a vitrine, do E07.

**Resultado ao fim das 4h:** cada aluno tem o `agenda-de-contatos` no fim da etapa 3:

- `src/regras/edicao.js` com `import { criarContato } from './contato.js';` e quatro funções: `proximoId`, `adicionarContato`, `removerContato` e `editarContato`
- `src/regras/edicao.test.js`, novo, com 7 testes
- `src/regras/lista.js` com `import { inicial } from './texto.js';` e seis funções (as quatro do E14, `agruparPorLetra` e `aniversariantesDoMes`); `lista.test.js` com 16 testes
- `src/scripts/agenda.js` com a linha em branco e uma linha por letra no fim
- `npm test`: `Test Suites: 4 passed, 4 total` e `Tests: 34 passed, 34 total`; `npm run agenda mar` termina com `H: Helena Martins` e `M: Marcos Teixeira, Mariana Souza`
- na página (`npx serve .`): 13 de 14, com Salvar, Editar, Remover, Desfazer, as letras e os aniversariantes do mês
- o commit `Projeto 2: etapa 3, adicionar, editar, remover e agrupar` no GitHub

**Pré-requisitos:** aula 3 (`filter` e `reduce` com tabelas), E07 (funções, `export`/`import`, a vitrine), E08 (Jest, `toBe`, `toEqual`), E10 (`if`, `null`, `undefined`), E11 (`for...of`, acumulador, `push`), E12 (`join`, `npx serve .`), E13 (fichas, colchetes, campo novo, `Object.keys`/`entries`, `for (const [campo, valor] of ...)`; a `const` lacra a caixa, não a ficha) e E14 (`map`, `find`, `sort` com `localeCompare` e com `(a, b) => a - b`, a cópia com `[...]` e a seta com chaves e `return`). A turma **não** viu: referência pelo nome, spread em fichas, `splice`, `reduce` com ficha no visor, um arquivo de regras importando outro.

**Materiais:** projetor com o VS Code em fonte grande, quadro (as casas, os papéis e as tabelas volta por volta), Wi-Fi para o `git push`, a página do Projeto 2 aberta, quiz publicado. Fora do git, na sua máquina: `privado/projetos/projeto-2/etapa-2/` (o início de hoje), `etapa-3-juntos/` (depois dos quatro passos, 31 testes) e `etapa-3/` (depois da Sua vez, 34 testes).

O `removerContato` que rasura, só para a demonstração (o `findIndex` é do E14; o `splice` está no slide "Sem rasurar"):

```javascript
export function removerContato(contatos, id) {
  const posicao = contatos.findIndex((contato) => contato.id === id);
  contatos.splice(posicao, 1);
  return contatos;
}
```

Conferido no Node, com uma cópia da lista do kit: com o `filter`, a lista nova tem 14 e a guardada continua com 15; com o `splice`, as duas têm 14 e são a mesma lista (`===` dá `true`).

// Quem faz aniversário no mês (de 1 a 12), do dia menor para o maior.
export function aniversariantesDoMes(contatos, mes) {

```javascript
// Etapa 3 (E15): mudanças na agenda, sem rasurar o original.
// Cada função devolve uma lista nova; a lista que ela recebeu fica como estava.
//
// Aqui entram, com export:
//   proximoId(contatos)                     o maior id da lista mais 1
//   adicionarContato(contatos, dados)       uma lista nova, com o contato novo no fim
//   removerContato(contatos, id)            uma lista nova, sem o contato daquele id
//   editarContato(contatos, id, mudancas)   uma lista nova, com aquele contato mudado
//
// O que cada uma recebe e devolve, com exemplos, está no enunciado do Projeto 2.

import { criarContato } from './contato.js';

// O id do próximo contato: o maior id da lista mais 1. Na lista vazia, 1.
export function proximoId(contatos) {
  let maior = 0;
  for (const contato of contatos) {
    if (contato.id > maior) {
      maior = contato.id;
    }
  }
  return maior + 1;
}

// Uma lista nova, com o contato novo no fim. A lista recebida fica como estava.
export function adicionarContato(contatos, dados) {
  const novo = criarContato(proximoId(contatos), dados);
  return [...contatos, novo];
}

// Uma lista nova, sem o contato daquele id.
export function removerContato(contatos, id) {
  return contatos.filter((contato) => contato.id !== id);
}

// Uma lista nova em que o contato daquele id é uma ficha nova, com as mudanças.
// Os outros contatos passam como estão.
export function editarContato(contatos, id, mudancas) {
  return contatos.map((contato) => {
    if (contato.id === id) {
      return { ...contato, ...mudancas };
    }
    return contato;
  });
}
```
