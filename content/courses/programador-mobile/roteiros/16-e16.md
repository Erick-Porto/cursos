## Visão do encontro

**Objetivo:** tirar do checkout os `if` de forma de pagamento com herança e polimorfismo, proteger as regras do cartão com campos `#` e separar "é um" (herança) de "tem um" (composição) no `Pedido`.

**Resultado ao fim das 4h:** `src/modelos/Pagamento.js` com as quatro classes e 8 testes; o `Pedido` com `#status`, `entrega`, `pagamento` e `total` delegado, com 5 testes; o script `src/scripts/formas-de-pagamento.js` imprimindo o total de cada forma para o CEP e as parcelas passados no comando.

**Pré-requisitos:** `lojinha-regras` do E15 com `npm test` verde: `precos.js` (E05), `datas.js` com `preverEntrega` (E06), `carrinho.js` com `subtotal` e `contarItens`, `frete.js` com `calcularFrete` (E13), `Produto` e `Pedido` com `_status`, `paraJSON` e `comStatus` (E15). Nenhum pacote novo.

**A regra do cartão:** até 6x, sem juros; de 7x a 12x, total = valor × 1,0199 elevado ao número de parcelas, arredondado ao centavo (juros compostos de 1,99% ao mês, uma simplificação da Tabela Price). A parcela sai do `parcelar` do E05. R$ 199,90 em 7x: R$ 229,46, parcela de R$ 32,78.

**Materiais:** projetor com editor e terminal lado a lado, quadro com duas cores, calculadora, branch `e16-solucao` e quiz publicado.

## Abertura (15 min)

Retomada (5 min):

1. "Por que o `comStatus` devolve um pedido novo, montado com `paraJSON()`?" Esperado: o original fica intacto, como nas versões imutáveis do carrinho no E09; o `paraJSON` entrega os dados no formato que o `constructor` espera, com `status`. O spread copiaria `_status`, e o pedido novo nasceria pendente.
2. "O que acontece com `new Pedido({ status: 'aprovado' })`?" Esperado: o setter lança "Status inválido", já no `constructor`.
3. "Qual a diferença entre `Produto.deJSON(obj)` e `produto.precoFormatado`?" Esperado: o primeiro é estático, chamado na classe; o segundo é um getter da instância, lido sem parênteses. Gancho: "O `_status` do E15 é só um combinado. Hoje ele vira regra da linguagem."

```javascript
import { PERCENTUAL_PIX, paraCentavos, paraReais, parcelar, precoComPix } from '../regras/precos.js';
import { preverEntrega } from '../utils/datas.js';

const TAXA_MENSAL = 0.0199; // 1,99% ao mês, juros compostos
const LIMITE_SEM_JUROS = 6;
const MAXIMO_DE_PARCELAS = 12;
const DIAS_PARA_PAGAR = 3; // dias úteis até o vencimento do boleto

export class Pagamento {
  #tipo;
  #nome;

  constructor(tipo, nome) {
    this.#tipo = tipo; // 'pix', 'cartao' ou 'boleto': identifica a forma
    this.#nome = nome; // o que o cliente lê
  }

  get tipo() {
    return this.#tipo;
  }

  get nome() {
    return this.#nome;
  }

  get descricao() {
    return this.#nome;
  }

  totalAPagar(valor) {
    return valor; // sem desconto nem juros
  }
}
```

`src/modelos/Pagamento.js`, o cartão:

```javascript
export class PagamentoCartao extends Pagamento {
  #parcelas;

  constructor(parcelas = 1) {
    super('cartao', 'Cartão');
    if (!Number.isInteger(parcelas) || parcelas < 1 || parcelas > MAXIMO_DE_PARCELAS) {
      throw new Error(`Parcelas devem ser de 1 a ${MAXIMO_DE_PARCELAS}`);
    }
    this.#parcelas = parcelas;
  }

  get parcelas() {
    return this.#parcelas;
  }

  get temJuros() {
    return this.#parcelas > LIMITE_SEM_JUROS;
  }

  get descricao() {
    const juros = this.temJuros ? 'com juros' : 'sem juros';
    return `${super.descricao} em ${this.#parcelas}x ${juros}`;
  }

  totalAPagar(valor) {
    if (!this.temJuros) return super.totalAPagar(valor);
    const comJuros = paraCentavos(valor) * (1 + TAXA_MENSAL) ** this.#parcelas;
    return paraReais(Math.round(comJuros));
  }

  valorDaParcela(valor) {
    return parcelar(this.totalAPagar(valor), this.#parcelas).valor;
  }
}
```

`src/modelos/Pedido.js`, primeira parte (o `_status` vira `#status`, o `frete` vira `entrega` e entra o `pagamento`):

```javascript
import { contarItens, subtotal as somarItens } from '../regras/carrinho.js';
import { paraCentavos, paraReais } from '../regras/precos.js';
import { formatarPreco } from '../utils/formatar.js';

const STATUS = ['pendente', 'pago', 'enviado', 'entregue', 'cancelado'];

export default class Pedido {
  #status;

  constructor({ id, itens = [], status = 'pendente', entrega = null, desconto = 0, pagamento = null } = {}) {
    this.id = id;
    this.itens = itens; // [{ ...produto, qtd }]
    this.status = status; // passa pelo setter
    this.entrega = entrega; // { cep, frete } ou null
    this.desconto = desconto;
    this.pagamento = pagamento; // qualquer filha de Pagamento, ou null
  }

  get status() {
    return this.#status;
  }

  set status(valor) {
    if (!STATUS.includes(valor)) {
      throw new Error(`Status inválido: ${valor}`);
    }
    this.#status = valor;
  }

  get quantidade() {
    return contarItens(this.itens);
  }

  get subtotal() {
    return somarItens(this.itens);
  }
  // frete, valorDaCompra, total e os métodos no bloco seguinte
```

`src/modelos/Pedido.js`, segunda parte:

```javascript
  get frete() {
    return this.entrega?.frete ?? 0;
  }

  get valorDaCompra() {
    // o total do E15, com outro nome: em centavos e nunca negativo
    const centavos = paraCentavos(this.subtotal) + paraCentavos(this.frete) - paraCentavos(this.desconto);
    return paraReais(Math.max(centavos, 0));
  }

  get total() {
    if (!this.pagamento) return this.valorDaCompra;
    return this.pagamento.totalAPagar(this.valorDaCompra);
  }

  paraJSON() {
    const { id, itens, status, entrega, desconto } = this;
    return { id, itens, status, entrega, desconto }; // só dados: o pagamento vai à parte
  }

  comStatus(novo) {
    return new Pedido({ ...this.paraJSON(), pagamento: this.pagamento, status: novo });
  }

  comPagamento(pagamento) {
    return new Pedido({ ...this.paraJSON(), pagamento });
  }

  toString() {
    return `Pedido ${this.id}, ${this.status}, ${formatarPreco(this.total)}`;
  }
}
```

```javascript
import Pedido from '../modelos/Pedido.js';
import { PagamentoBoleto, PagamentoCartao, PagamentoPix } from '../modelos/Pagamento.js';
import { subtotal } from '../regras/carrinho.js';
import { calcularFrete } from '../regras/frete.js';
import { formatarPreco } from '../utils/formatar.js';

const itens = [
  { id: 11, nome: 'Livro de Receitas', preco: 59.9, qtd: 1 },
  { id: 12, nome: 'Guia de Viagem', preco: 74.9, qtd: 1 },
];
const cep = process.argv[2] ?? '01310-100';
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| Teste do Pix recebe `199.9` | Nome diferente na filha (`totalApagar`) | Comparar letra a letra com o da mãe |
| `ReferenceError` ao criar a filha | `this` antes do `super(...)` no `constructor` | `super` na primeira linha do `constructor` |
| `Cannot access 'Pagamento' before initialization` | Uma filha declarada acima da mãe em `Pagamento.js` | A mãe primeiro, as filhas depois |
| `SyntaxError` citando `#parcelas` ou `#nome` | Campo não declarado, ou filha lendo o `#` da mãe | Declarar `#parcelas;` no topo da classe; na filha, usar o getter |
| `Maximum call stack size exceeded` ao ler `parcelas` | Getter devolvendo `this.parcelas` | Devolver `this.#parcelas` |
| `TypeError: ... which has only a getter` | Script ou teste fazendo `cartao.parcelas = n` | Criar `new PagamentoCartao(n)` |
| Script para com "Parcelas devem ser de 1 a 12" mesmo com `10` | `process.argv` traz texto; faltou `Number` | `Number(process.argv[3] ?? 1)` |
| Testes do E15 quebram com `frete` | O `constructor` agora recebe `entrega` | Trocar `frete: 19.9` por `entrega: { cep: '01310-100', frete: 19.9 }` |
| Pedido pago volta a pendente após `comPagamento` | `{ ...this }` no lugar de `paraJSON()`: o `#status` não é copiado | Usar `{ ...this.paraJSON(), pagamento }` |
| `ERR_MODULE_NOT_FOUND` só no `node`, com o Jest verde | Import relativo sem `.js` | `'../modelos/Pagamento.js'`, com a extensão |
