## Visão do encontro

**Objetivo:** levar cada equipe do esqueleto do E42 às histórias **Must** do briefing, rodando no celular contra o json-server, com cada tela aprovada pelo checklist de qualidade e cada merge por PR revisado. Depois da pausa, o app passa a lembrar do cliente: um dado do briefing guardado no aparelho e o login numa conta de testes da DummyJSON, com o token no SecureStore.

**Resultado ao fim das 4h:** o fluxo principal de ponta a ponta no celular (agendar e ver em Meus agendamentos; pedir e acompanhar; lançar e ver o saldo), 5 testes de regras, um dado do briefing que volta depois do `r` no terminal do Expo, o login com `emilys` mantido ao reabrir, um PR revisado por outra equipe e o commit `docs: E43 fechamento da sprint 1` na `main`.

**Formato:** duas aulas curtas, uma antes e outra depois da pausa, somando 55 minutos. No resto do tempo você é mentor: pergunta antes de responder e só pega o teclado em último caso.

Do E42, o esqueleto: 5 telas navegáveis, tema, kit de UI, `src/features/`, o `src/api/` do `lojinha-regras` (com `pedir` e `ApiError`) apontando para o json-server pelo IP, o contexto do domínio com `useReducer` e o Jest com o preset `jest-expo`.

Agenda, `src/features/agenda/horarios.js`:

```javascript
const ABRE = 9 * 60; // em minutos desde a meia-noite
const FECHA = 18 * 60;
const BLOCO = 30;

export function paraMinutos(hora) {
  const [h, m] = hora.split(':').map(Number);
  return h * 60 + m;
}

export function paraHora(minutos) {
  const h = String(Math.floor(minutos / 60)).padStart(2, '0');
  const m = String(minutos % 60).padStart(2, '0');
  return h + ':' + m;
}

// ocupados: [{ hora: '14:30', duracaoMin: 30 }] do profissional no dia, sem os cancelados
// agoraMin: minutos de agora quando o dia é hoje; null nos outros dias
export function horariosLivres(duracaoMin, ocupados, agoraMin = null) {
  const livres = [];
  for (let inicio = ABRE; inicio + duracaoMin <= FECHA; inicio += BLOCO) {
    const fim = inicio + duracaoMin;
    const choca = ocupados.some((o) => {
      const inicioOcupado = paraMinutos(o.hora);
      return inicio < inicioOcupado + o.duracaoMin && inicioOcupado < fim;
    });
    const cedoDemais = agoraMin !== null && inicio < agoraMin + 60;
    if (!choca && !cedoDemais) livres.push(paraHora(inicio));
  }
  return livres;
}
```

```javascript
export function inicioDoAgendamento({ data, hora }) {
  const [ano, mes, dia] = data.split('-').map(Number);
  const [h, m] = hora.split(':').map(Number);
  return new Date(ano, mes - 1, dia, h, m); // hora local, sem depender do parser de datas
}

export function podeCancelar(agendamento, agora) {
  const duasHoras = 2 * 60 * 60 * 1000;
  return agendamento.status === 'agendado' && inicioDoAgendamento(agendamento) - agora >= duasHoras;
}
```

```jsx
  const { agendamentos, carregando, erro, recarregar, cancelar } = useAgendamentos();
```

```javascript
export const PEDIDO_MINIMO = 15;
const centavos = (reais) => Math.round(reais * 100);

export function totalDoPedido(itens) {
  return itens.reduce((total, i) => total + centavos(i.preco) * i.qtd, 0) / 100;
}

export function atingiuMinimo(itens) {
  return totalDoPedido(itens) >= PEDIDO_MINIMO;
}

export function previsaoMinutos(itens) {
  const unidades = itens.reduce((soma, i) => soma + i.qtd, 0);
  return Math.min(10 + 2 * unidades, 45);
}
```

```javascript
export function resumoPorCategoria(lancamentos, mes) {
  const saidas = lancamentos.filter((l) => l.tipo === 'saida' && l.data.startsWith(mes));
  const total = saidas.reduce((soma, l) => soma + l.valorCentavos, 0);
  const porCategoria = {};
  for (const l of saidas) {
    porCategoria[l.categoriaId] = (porCategoria[l.categoriaId] ?? 0) + l.valorCentavos;
  }
  return Object.entries(porCategoria)
    .map(([categoriaId, valorCentavos]) => ({
      categoriaId,
      valorCentavos,
      percentual: Math.round((valorCentavos / total) * 100),
    }))
    .sort((a, b) => b.valorCentavos - a.valorCentavos);
}

// devolve o tom do Badge: alerta a partir de 80%, perigo acima de 100%
export function nivelDoLimite(gastoCentavos, limiteCentavos) {
  if (!limiteCentavos) return null;
  const uso = gastoCentavos / limiteCentavos;
  if (uso > 1) return 'perigo';
  if (uso >= 0.8) return 'alerta';
  return 'sucesso';
}
```

`src/features/conta/AuthContext.js`:

```jsx
import { createContext, useContext, useEffect, useState } from 'react';
import { autenticar, buscarUsuario } from '../../api/auth.js';
import { ApiError } from '../../api/cliente.js';
import { apagarToken, guardarToken, lerToken } from '../../servicos/sessao.js';

const AuthContext = createContext(null);

export function AuthProvider({ children }) {
  const [usuario, setUsuario] = useState(null);
  const [carregando, setCarregando] = useState(true);

  useEffect(() => {
    async function restaurarSessao() {
      try {
        const token = await lerToken();
        if (token) setUsuario(await buscarUsuario(token));
      } catch (erro) {
        if (erro instanceof ApiError) await apagarToken(); // vencido ou inválido
      } finally {
        setCarregando(false);
      }
    }
    restaurarSessao();
  }, []);

  async function entrar(nomeDeUsuario, senha) {
    const token = await autenticar(nomeDeUsuario, senha);
    await guardarToken(token);
    setUsuario(await buscarUsuario(token));
  }

  async function sair() {
    await apagarToken();
    setUsuario(null);
  }

  const valor = { usuario, carregando, entrar, sair };
  return <AuthContext.Provider value={valor}>{children}</AuthContext.Provider>;
}

export function useAuth() {
  const valor = useContext(AuthContext);
  if (!valor) throw new Error('useAuth precisa estar dentro do AuthProvider');
  return valor;
}
```

## Plano B

- **Rede que isola os aparelhos:** hotspot do celular de alguém, com o computador nele e o novo IP no `.env`; ou emulador Android, onde o computador é `10.0.2.2`.
- **Sem internet ou DummyJSON fora do ar:** o AsyncStorage funciona sem rede; faça essa parte inteira. Para o login, troque o corpo de `autenticar` por uma Promise com `setTimeout` (E18) que devolve `'token-de-teste'` para `emilys` e rejeita o resto com um `ApiError(400)`, e o de `buscarUsuario` por um usuário fixo. Só o `auth.js` muda: é a regra 7 na prática.
- **Muitos pedidos na mesma rede:** a DummyJSON limita pedidos por endereço. Com a turma no mesmo Wi-Fi, um status 429 é possível: espere alguns segundos ou use o hotspot.
- **GitHub fora do ar:** os commits locais seguem; a revisão cruzada vai para o papel e entra no PR no E44.
- **Equipe desfalcada:** corte o escopo, mantendo o fluxo principal; o login fica para o E44. Quem veio sozinho não tem quem aprove: entre como colaborador e aprove você, depois de rodar no celular.
- **Sem projetor:** as aulas viram roda em volta do seu celular, com o checklist impresso por mesa.
- **Aluno sem celular:** emulador. Na versão web do app o SecureStore não funciona: quem estiver no navegador faz o dado no aparelho e testa o login no celular de um colega.
