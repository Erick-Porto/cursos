## Visão do encontro

**Objetivo**: entender como uma página chega ao navegador, ver HTML, CSS e JavaScript no DevTools, saber onde o JavaScript roda (navegador e Node) e deixar o computador pronto para o E02.

**Resultado ao fim das 4h**: `perfil.html` e `estilo.css` abertos no navegador; Node.js LTS, Git e VS Code (com Prettier, ESLint e Error Lens) instalados e conferidos; Git com nome e e-mail configurados; conta no GitHub com nome apresentável.

**Pré-requisitos**: nenhum. A turma nunca programou. Peça antes, por mensagem, notebook carregado (se houver) e um e-mail pessoal acessível pelo celular.

**Materiais**: projetor, Wi-Fi para cerca de 200 MB por máquina, um computador por aluno (ou duplas), pendrive com instaladores, quiz `quiz-e01` publicado, [folha de acompanhamento](materiais/e01/instrutor/acompanhamento.html) impressa (serve de lista de presença). Para o aluno, ligados pelos slides da aula B: [checklist de instalação](materiais/e01/aluno/checklist-instalacao.html) e [enunciado do laboratório](materiais/e01/aluno/laboratorio-perfil.html).

## Bloco 1 · A web e o JavaScript (50 min)

**Slides "Por que isso importa" a "Front-end e back-end" (8 min)**. Deixe a pergunta do delivery no ar por 30 segundos. Em "Cliente e servidor", o notebook de cada um é o cliente; o servidor do curso está em outro prédio. Em "Front-end e back-end", a linha "Onde roda" resolve qualquer dúvida; leia a frase final: é o trabalho de quem sai deste curso.

**Slides "HTML: a estrutura" a "As três linguagens juntas" (10 min)**. Leia o HTML como lista de peças. No CSS, `h1` e `button` são as palavras do HTML. No JavaScript: encontrar, esperar o clique, rodar; diga com todas as letras que ninguém precisa entender cada símbolo hoje. Feche com a dica: mudou cor, CSS; mudou texto, HTML; aconteceu algo, JavaScript.

**Slides "DevTools: o raio-x da página" a "Demonstração: aba Console" (15 min)**. Todos acompanham no portal de notícias.

:::steps
1. `F12`, aba **Elements**: HTML à esquerda, **Styles** à direita.
2. Seta do canto do painel, depois a manchete: o elemento fica destacado.
3. Dois cliques no texto, troque por "Olá, turma": a manchete muda.
4. Em **Styles**, troque `color` por `red`.
5. Recarregue: tudo volta. "Vocês mudaram a cópia na memória do navegador, o DOM. O servidor nem soube."
6. Aba **Console**: `console.log('Olá, turma!')`, `2 + 2` e `document.title`.
7. `console.log(Olá)` sem aspas: leia o erro vermelho com a turma.
:::

**Slide "Pense" (4 min)**. Esperado: sem JavaScript a página aparece, mas o botão não faz nada; sem CSS, texto preto, links azuis, imagens no tamanho original. Se ninguém responder, faça o teste da dica: "Disable JavaScript" no DevTools, recarregue e pergunte o que parou.

**Slides "Quem define e quem executa o JavaScript" a "Pense: navegador ou Node?" (10 min)**. Na tabela de motores, pergunte que navegador cada um usa: quem usa Chrome ou Edge roda o V8, o mesmo motor do Node. Em "Runtime", a frase que fica: "o motor entende a linguagem; o runtime traz as ferramentas do lugar". Não explique `Alert` nem `Vibration`: são só a prova de que o celular tem as suas.

Demonstração "o mesmo código em dois lugares", na sua máquina, com a turma só olhando (o Node dos alunos chega no laboratório). Divida o quadro em duas colunas, Navegador e Node, e preencha ao vivo.

```javascript
console.log('Olá, turma!')
2 + 2
typeof document
typeof process
```

:::steps
1. Navegador: `F12`, aba Console, uma linha por vez. Saídas: `Olá, turma!`, `4`, `'object'`, `'undefined'`.
2. Node: no terminal, `node` e as mesmas linhas. Saídas: `Olá, turma!` seguido de `undefined`, `4`, `'undefined'`, `'object'`.
3. Pergunte: "O que deu igual e o que mudou?" Esperado: a mensagem e a conta são iguais; `document` só existe no navegador e `process` só no Node.
4. Ainda no Node, `document.title`: leia o erro com a turma (`document is not defined`). Saia com `.exit`.
:::

Explique `typeof` em uma frase: "pergunta que tipo de coisa um nome guarda; `'undefined'` quer dizer que ele não existe aqui". Tipos são do E05. O `undefined` depois do `console.log` no Node fica sem explicação hoje: a aula B avisa que ele é normal.

No "Pense", individual, 1 minuto, depois em voz alta. Esperado: 1 e 2 nos dois, 3 só no navegador, 4 só no Node. Quem erra a 1 costuma achar que `console.log` é do navegador: aponte a coluna Node do quadro.

**Slides "Onde o JavaScript roda neste curso" a "Próximos passos" (3 min)**. Volte à tabela de módulos da Abertura: o `lojinha-regras` vive na coluna Node do quadro; o celular, no E26. Erros comuns e resumo: leia sem comentar; voltam no quiz.

:::tip Ritmo
Atrasado? Pule o passo 7 do DevTools e reduza a tabela de motores a "V8 no Chrome e no Node". Nunca corte a aba Elements nem a demonstração em dois lugares: é dela que a turma lembra no laboratório.
:::

**Enunciado**: `perfil.html` e `estilo.css` com foto, nome e três links, inspecionados no DevTools; instalar Node.js LTS, Git e VS Code com as três extensões; conferir as versões; configurar nome e e-mail no Git; criar a conta no GitHub com um nome que caiba em um currículo. Quem fica alguns minutos sem você continua por ele.

**Organização**: individual; quem não tem computador faz a página em dupla. Nos primeiros 5 minutos, identifique quem não tem permissão de administrador e aplique o plano B. Anote tudo na folha de acompanhamento: presença, marcos e, nas colunas de instalação, a letra do problema (A administrador, R rede, V antivírus, S sem computador, C fica para casa).

**Marcos**: 10 min, `perfil.html` aberto no navegador e downloads em andamento; 25 min, `estilo.css` ligado (sem foto, avatar do GitHub: `https://github.com/SEU-USUARIO.png`); 45 min, Node.js e Git instalados, terminal reaberto, versões na tela; 60 min, Git configurado, GitHub confirmado e VS Code com as três extensões; 70 min, captura e arquivos enviados.

**Onde circular**: fileiras do fundo. Observe se o arquivo virou `.txt` (ative "extensões de nome de arquivo" no Explorador), se a aba Network mostra `estilo.css` em vermelho, se alguém travou em um instalador pedindo senha e se o `git config --global user.name` devolve o nome inteiro.

| Sistema | Terminal | Comandos | Se falhar |
|---|---|---|---|
| Windows | Win + X, "Terminal" | `node -v`, `npm -v`, `git --version`, `git config --global user.name` | "não é reconhecido": feche terminal e VS Code e reabra |
| macOS | Cmd + Espaço, "Terminal" | os mesmos | `git` pede as ferramentas de linha de comando: aceite |
| Linux | Ctrl + Alt + T | os mesmos | `sudo apt install git`; Node.js pelo site ou `nvm`, não pelo `apt` |

**Sem permissão para instalar**: tente as versões sem administrador (Node.js `.zip` em Documentos, Portable Git, User Installer do VS Code). Se antivírus ou proxy continuarem barrando, use uma máquina preparada; sem ela, o aluno cria a conta no GitHub, um repositório `perfil` e escreve os dois arquivos no editor online. A instalação fica para casa; confira no E02.

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `node` "não é reconhecido" após instalar | Terminal aberto antes da instalação | Fechar tudo, inclusive o VS Code, e reabrir |
| Instalador pede senha de administrador | Conta restrita | Node.js `.zip`, Portable Git, User Installer; se bloquear, plano B |
| "O Windows protegeu o computador" ou antivírus apaga o instalador | SmartScreen ou antivírus | "Mais informações", "Executar assim mesmo"; se barrar, pendrive |
| `npm -v`: "a execução de scripts foi desabilitada" | Política do PowerShell | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` ou Prompt de Comando |
| `git config --global user.name` mostra só o primeiro nome | Nome digitado sem aspas | Repetir o comando com o nome entre aspas |
| `code .` "não é reconhecido" | VS Code instalado sem "Add to PATH" | Reinstalar marcando a opção ou abrir a pasta pelo menu File, Open Folder |
| Download parado em 0% | Proxy ou Wi-Fi saturado | Pendrive; escalonar downloads por fileira |
| Página sem estilo | `href` errado, `estilo.css.txt` ou outra pasta | Mostrar extensões; conferir `estilo.css` na aba Network |
| GitHub não confirma ou recusa o nome | E-mail com filtro; nome com espaço ou em uso | E-mail pessoal, conferir spam; só letras, números e hífen |
