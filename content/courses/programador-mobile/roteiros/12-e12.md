Para quem travou: "Quantos Sets existem depois de uma chamada do `alternarFavorito`?". A resposta certa é dois: o recebido, intacto, e o novo.

:::example Solução de referência
`src/regras/favoritos.js`:

```javascript
export function ehFavorito(favoritos, id) {
  return favoritos.has(id);
}

export function alternarFavorito(favoritos, id) {
  const novo = new Set(favoritos); // o Set recebido não muda
  if (novo.has(id)) {
    novo.delete(id);
  } else {
    novo.add(id);
  }
  return novo;
}

export function listarFavoritos(favoritos, produtosPorId) {
  return [...favoritos]
    .map((id) => produtosPorId.get(id))
    .filter((produto) => produto !== undefined);
}
```

`src/regras/favoritos.test.js`, os testes do E08 reescritos:

```javascript
import { alternarFavorito, ehFavorito, listarFavoritos } from './favoritos.js';

describe('favoritos', () => {
  test('alternar acrescenta o id que não está', () => {
    expect(alternarFavorito(new Set([3]), 7)).toEqual(new Set([3, 7]));
  });
  test('alternar tira o id que já está', () => {
    expect(alternarFavorito(new Set([3, 7, 10]), 7)).toEqual(new Set([3, 10]));
  });
  test('alternar não altera o Set recebido e devolve outro', () => {
    const favoritos = new Set([3]);
    const novo = alternarFavorito(favoritos, 7);
    expect(novo).toEqual(new Set([3, 7]));
    expect(favoritos).toEqual(new Set([3]));
    expect(novo).not.toBe(favoritos);
  });
  test('ehFavorito responde se o id está no Set', () => {
    expect(ehFavorito(new Set([3, 7]), 7)).toBe(true);
    expect(ehFavorito(new Set([3, 7]), 10)).toBe(false);
  });
  test('ehFavorito não acha o id escrito como texto', () => {
    expect(ehFavorito(new Set([3, 7]), '7')).toBe(false);
  });
});
```

`rascunhos/tipos.ts`, os tipos e as funções:

```typescript
type Produto = {
  id: number;
  nome: string;
  preco: number;
  categoria: string;
};

type StatusPedido = 'pendente' | 'pago' | 'enviado' | 'entregue' | 'cancelado';

const produtos: Produto[] = [
  { id: 1, nome: 'Fone Bluetooth', preco: 199.9, categoria: 'audio' },
  { id: 7, nome: 'Tênis de Corrida', preco: 349.9, categoria: 'esporte' },
];

function nomeDoProduto(lista: Produto[], id: number): string {
  const produto = lista.find((p) => p.id === id);
  if (produto === undefined) {
    return 'Produto não encontrado';
  }
  return produto.nome;
}

function podeCancelar(status: StatusPedido): boolean {
  return status === 'pendente' || status === 'pago';
}

function ehFavorito(favoritos: Set<number>, id: number): boolean {
  return favoritos.has(id);
}
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `TypeError: favoritos.slice is not a function` ou `favoritos.includes is not a function` | Testes já com `Set`, regra ainda com os métodos de array do E08 | Reescrever com `new Set(favoritos)` e `has` |
| `Expected: Set {3, 7}`, `Received: [3, 7]` | A regra copia com `[...favoritos]` e devolve um array | `new Set(favoritos)` no lugar do spread |
| `TypeError: favoritos.has is not a function` | Regra nova, testes ainda passando arrays | Entradas com `new Set(...)` nos testes |
| "alternar não altera o Set recebido" vermelho, com `+ 7` na diferença | `add` ou `delete` no Set recebido | Trabalhar num `new Set(favoritos)` e devolver o novo |
| `TypeError: favoritos.join is not a function` no script | O `join` do E08 é de array | `[...favoritos].join(', ')` |
| O script lista os ids, mas diz "Nenhum favorito ainda." | Os ids do `process.argv` são texto, e o `get('7')` não acha o número | `Number(texto)` antes de chamar `alternarFavorito` |
| `Unknown file extension ".ts"` | Node 22 até a versão 22.17, sem a opção | `node --experimental-strip-types rascunhos/tipos.ts` |
| `npx tsc --noEmit` mostra a ajuda do tsc | Falta o `tsconfig.json`, ou o terminal está em outra pasta | Criar o arquivo na raiz; `cd` até a pasta do projeto |
| `This is not the tsc command you are looking for` | `npx tsc` sem o `typescript` instalado baixa outro pacote, chamado `tsc` | `npm i -D typescript` antes |
| `error TS18003: No inputs were found in config file` | O `.ts` foi criado fora de `rascunhos/` | Mover o arquivo para `rascunhos/` |
| `Duplicate identifier 'Produto'` | Dois arquivos em `rascunhos/` declaram o mesmo tipo; sem `import` nem `export`, o TypeScript os trata como um escopo só | Um rascunho só, ou `export {};` na primeira linha de cada arquivo |
