## Visão do encontro

**Objetivo:** ensinar a turma a escrever as próprias funções e usar isso para organizar o Racha-conta. As contas que o E06 deixou soltas no `racha.js` viram regras com nome, num arquivo só delas, o `src/regras/conta.js`, que o script importa. A saída do `npm run racha` não muda: o que muda é a organização, e é ela que deixa o E08 testar as regras e o E12 usá-las numa página web.

**Como a aula funciona:** cada conceito vem em três slides, como na aula 3. A seção (título e gancho) é a hora da conversa: leia o gancho, ouça duas ou três respostas e explique com a analogia indicada abaixo. O slide seguinte é a âncora, o que o aluno lê para revisar. Depois dos conceitos que o projeto usa vem um slide **Projeto 1 · Passo K**: a turma faz junto com você, no próprio `racha-conta`, e só segue quando o "Pronto quando" aparece na tela de todos. No fim, a **Sua vez** é feita sozinha, sem a solução no slide.

**Resultado ao fim das 4h:** cada aluno tem, no `racha-conta`, a pasta nova `src/regras` com o `conta.js` e três funções exportadas: `paraCentavos(reais)`, `calcularGorjeta(subtotal, percentual = 10)` e `formatarReais(centavos)`, sem `console.log` e sem `fs`. O `racha.js` importa as três de `'../regras/conta.js'`: `paraCentavos` no subtotal, `calcularGorjeta` na gorjeta e `formatarReais` nas linhas de Subtotal, Gorjeta, Total e Por pessoa. Os dois arquivos passaram pelo Formatar Documento. `npm run racha` mostra exatamente a saída da etapa 3, até `Centavos que sobram: 1`. O commit `Projeto 1: etapa 4, as primeiras regras` está no GitHub. É a etapa 4 do Projeto 1.

**Pré-requisitos:** E06 (tipos, operadores, `%`, `Math.round` e `Math.floor`, centavos, template string), E05 (commit e `git push`), E04 (`npm run racha`) e aula 3 (`filter` e `reduce` com a seta, `import` de um arquivo próprio, `if` sem `else`). A turma **não** viu: `else`, laços, testes, `return`, funções declaradas por ela. O `NaN` aparece hoje com uma frase de explicação; ele é estudado no E09.

**Materiais:** projetor com o VS Code em fonte grande e o terminal integrado, quadro, a pasta `demos-e07` (veja abaixo), o seu `racha-conta` no fim da etapa 3 para fazer os passos ao vivo, a página do Projeto 1 aberta, quiz publicado. Nada é instalado hoje: a internet só é necessária para o `git push`.

## Abertura (10 min)

**Retomada do E06 (5 min):**

1. "Por que o Racha-conta faz as contas em centavos?" Esperado: `0.1 + 0.2` não dá `0.3`; em centavos inteiros, a conta é exata. Peça que alguém diga a linha que converte: `Math.round(subtotal * 100)`. Gancho: "Hoje essa linha ganha um nome."
2. "O que o `${}` faz numa template string?" Esperado: encaixa um valor no texto, entre crases. "Ela volta hoje, dentro de uma função."
3. "Quanto dá `20625 % 4`?" Esperado: 1, o centavo que sobra. "Quem vai levar esse centavo, o E11 resolve."

**Conferência da etapa 3 (3 min).** Todos abrem o `racha-conta` e rodam `git log --oneline` e `npm run racha`. Quem não terminou a etapa 3 copia com você as quatro linhas da Sua vez do E06: as constantes `porPessoa` e `sobra` e as duas linhas no fim da saída. Os passos de hoje partem desse `racha.js`.

## Bloco 1 · Funções e o primeiro módulo (80 min)

**"Palavras novas de hoje" (3 min).** Leia as seis palavras com um exemplo rápido de cada. Não explique ainda: cada uma ganha a sua seção.

**"As contas soltas no racha.js" (5 min).** Abra o seu `racha.js` e aponte as duas linhas com `Math.round`. Faça a pergunta do slide. Esperado: num lugar só. "Hoje elas estão num lugar só. No E08, os testes vão precisar da mesma conta; no E12, a página web também. Se cada um tiver a sua cópia, um dia uma delas fica diferente, e ninguém percebe." Avise: "a saída de hoje é igual à do E06. Se mudar um centavo, alguma coisa deu errado."

**Seção "Funções" (10 min).** Leia o gancho. Esperado: não, o nome já diz tudo; quem sabe a receita faz. "Uma função é uma receita com nome, guardada para usar quando quiser. Você escreve os passos uma vez; depois, só diz o nome." Em "Função: uma receita com nome", abra `demos-e07/funcoes.js` só com a `function saudar` e rode: nada aparece. Pergunte: "por que nada apareceu?". Esperado: ninguém chamou a receita. Acrescente as duas chamadas e rode de novo. Em "Funções na prática", rode a `linha` e depois troque `linha();` por `linha;`: nada acontece, sem erro. Mostre o `[Function: linha]` do `console.log(linha)`: "o Node diz o que é, mas não faz".

**Seção "Parâmetros e argumentos" (10 min).** Leia o gancho. Esperado: o ingrediente muda, o modo de fazer é quase o mesmo. "O parâmetro é o espaço do ingrediente na receita; o argumento, o ingrediente que você põe nele." Escreva no quadro `function saudar(nome)` e, embaixo, `saudar('Ana')`, e desenhe uma seta do `'Ana'` até o `nome`. Em "Parâmetros na prática", rode `demos-e07/parametros.js` e peça a previsão de cada linha antes: `fatiasPorPessoa(4, 8)` costuma surpreender ("a ordem dos argumentos é a ordem dos parâmetros"). No `fatiasPorPessoa(8)`, leia o `NaN` em voz alta: "não é um número. O espaço do ingrediente ficou vazio, e `8 / undefined` não dá conta nenhuma."

**Seção "O return" (15 min).** Leia o gancho. Esperado: o prato; a foto não mata a fome. "O `return` entrega o prato pronto; o `console.log` só mostra a foto do prato." Rode `demos-e07/retorno.js` e mostre o `29 undefined`. Pergunte: "se o 29 apareceu na tela, por que o `b` vale `undefined`?". Esperado: a função mostrou, mas não entregou. Em "O return na prática", peça a previsão das três linhas antes de rodar. Feche: "a partir de hoje, toda regra do Racha-conta tem `return`. Quem mostra é o script."

**"A chamada, passo a passo" (5 min).** Escreva no quadro `const subtotalCentavos = paraCentavos(187.5);` e faça a tabela com a turma: um aluno diz quanto vale `reais`, outro faz a conta, um terceiro diz o que o `return` entrega. Apague `paraCentavos(187.5)` e escreva `18750` no lugar: "a chamada vira o prato". Aponte a última frase do slide: o `Math.round` também é uma função, e eles a chamam desde o E06.

**Seção "Módulos" (8 min).** Leia o gancho. Esperado: na vitrine, o que está à venda; no estoque, o resto, que o cliente não vê. "Cada arquivo é uma loja. O `export` põe na vitrine; o `import` pega de lá." Em "export e import: a vitrine", aponte a palavra `export`, as chaves do `import` ("o nome exato, letra por letra") e o `.js` no fim. Lembre o gerador do catálogo da aula 3: "aquele `import { categorias, produtos }` pegava da vitrine do `produtos.js`."

**"O caminho do import" (5 min).** Desenhe no quadro a pasta `src` com `scripts` e `regras` dentro, e percorra o caminho com o dedo: começa em `scripts`, onde o `racha.js` mora; o `..` sobe para `src`; `regras/conta.js` entra e chega. Pergunte: "e se o caminho fosse `'./regras/conta.js'`?". Esperado: procuraria `regras` dentro de `scripts`, e não acharia. Insista na diferença: "o `fs` parte da pasta do terminal; o `import` parte da pasta do arquivo. As duas regras aparecem no mesmo `racha.js`."

**"Regras puras: a receita só cozinha" (4 min).** Pergunte: "quais linhas do `racha.js` mostram algo na tela ou leem arquivo?". Esperado: a do `readFileSync` e os `console.log`. "Elas ficam no script. O `conta.js` só cozinha: recebe valores e devolve valores." Mostre na página do projeto o critério Qualidade da rubrica: regras sem `console.log` e sem `fs`.

**Projeto · Passo 1 (15 min).** Todos ao mesmo tempo, você no projetor, no seu `racha-conta`. A pasta `regras` pelo painel do VS Code, **dentro de `src`**, ao lado de `data` e `scripts`: confira mesa por mesa antes do `conta.js`. Depois, o `import` e a troca da linha do `subtotalCentavos`. Circule procurando: `regras` criada dentro de `scripts` ou na raiz; `export` esquecido; o `.js` ou o `..` faltando no caminho; `return` esquecido (aparece `R$ NaN` em todas as linhas). Quem tiver erro lê a mensagem em voz alta com você: a tabela "Quando aparece um erro" da aula tem as três primeiras.

## Projeto: sua vez (30 min)

**Enunciado:** o slide "Projeto 1 · Sua vez: formatarReais". No `conta.js`, `export function formatarReais(centavos)`, que devolve o texto em reais, com `R$` e duas casas, montado com template string (`formatarReais(18750)` dá `'R$ 187.50'`; `formatarReais(5)` dá `'R$ 0.05'`). Depois, no `racha.js`, o `import` com as três funções e as quatro linhas de dinheiro (Subtotal, Gorjeta, Total e Por pessoa) usando a função. A saída não muda.

**Organização:** individual, cada um no próprio `racha-conta`, sem olhar a tela do vizinho nos primeiros 15 minutos. Depois disso, quem travou pode pedir ajuda a um colega, que explica sem digitar por ele.

**Marcos:** 3:15, a `formatarReais` escrita no `conta.js` (quem quiser confere com um `console.log(formatarReais(18750));` provisório no `racha.js`, apagado depois); 3:25, as quatro linhas trocadas e a saída igual à da etapa 3; 3:30, Formatar Documento nos dois arquivos; 3:35, commit `Projeto 1: etapa 4, as primeiras regras` e `git push`.

**O que observar:** `console.log` no lugar do `return` dentro da regra (a saída mostra `R$ 187.50` solto e `Subtotal: undefined`); aspas simples no lugar da crase (sai `R$ ${reais}` escrito); o `R$` deixado na linha do script, além do da função (`Total: R$ R$ 206.25`); a `formatarReais` esquecida no `import` (`formatarReais is not defined`, depois da tabela dos itens); a linha de `Centavos que sobram` trocada também (ela é uma contagem, não dinheiro). Pergunta para quem travou: "o que entra nesta função e o que sai dela? Quem mostra na tela?".

:::example Solução de referência
`src/regras/conta.js` no fim da etapa 4:

```javascript
export function paraCentavos(reais) {
  return Math.round(reais * 100);
}

export function calcularGorjeta(subtotal, percentual = 10) {
  return Math.round(subtotal * percentual / 100);
}

export function formatarReais(centavos) {
  const reais = (centavos / 100).toFixed(2);
  return `R$ ${reais}`;
}
```

`src/scripts/racha.js` no fim da etapa 4:

```javascript
import fs from 'node:fs';
import pc from 'picocolors';
import { paraCentavos, calcularGorjeta, formatarReais } from '../regras/conta.js';

const texto = fs.readFileSync('src/data/conta.json', 'utf-8');
const conta = JSON.parse(texto);
const subtotal = conta.itens.reduce((total, item) => total + item.preco * item.quantidade, 0);
const unidades = conta.itens.reduce((total, item) => total + item.quantidade, 0);
const caros = conta.itens.filter((item) => item.preco > 50);

const subtotalCentavos = paraCentavos(subtotal);
const gorjetaCentavos = calcularGorjeta(subtotalCentavos, conta.gorjeta);
const totalCentavos = subtotalCentavos + gorjetaCentavos;
const porPessoa = Math.floor(totalCentavos / conta.pessoas);
const sobra = totalCentavos % conta.pessoas;

console.log(pc.bold('Racha-conta:'), conta.restaurante);
console.log('Pessoas na mesa:', conta.pessoas);
console.log('Itens na conta:', conta.itens.length);
console.table(conta.itens);
console.log('Unidades pedidas:', unidades);
console.log('Itens acima de R$ 50:', caros.length);
console.log(`Subtotal: ${formatarReais(subtotalCentavos)}`);
console.log(`Gorjeta (${conta.gorjeta}%): ${formatarReais(gorjetaCentavos)}`);
console.log(`Total: ${formatarReais(totalCentavos)}`);
console.log(`Por pessoa: ${formatarReais(porPessoa)}`);
console.log(`Centavos que sobram: ${sobra}`);
```

O `package.json`, o `conta.json`, o `.gitignore` e o README não mudam. O Formatar Documento (recuo de 2) não muda nenhuma linha dos dois arquivos acima.
