:::steps

**"Pratique" e "Máscaras em cadeia" (6 min).** Individual. Esperado: a resposta do slide. Quem juntar com `slice` e `'-'` mostra `01310-` com cinco dígitos: peça para testar com `'01310'`. `src/utils/validar.js` (se o arquivo já existe, acrescente abaixo do que está lá):

```javascript
const CEP = /^\d{5}-?\d{3}$/;
const CPF = /^\d{3}\.?\d{3}\.?\d{3}-?\d{2}$/;

// conferem só o formato: um CPF com formato certo ainda pode não existir
export function ehCepValido(texto) {
  return CEP.test(texto.trim());
}

export function ehCpfValido(texto) {
  return CPF.test(texto.trim());
}

export function mascararCep(texto) {
  const d = texto.replace(/\D/g, '').slice(0, 8);
  return d.replace(/^(\d{5})(\d)/, '$1-$2');
}

export function mascararTelefone(texto) {
  const d = texto.replace(/\D/g, '').slice(0, 11);
  return d
    .replace(/^(\d{2})(\d)/, '($1) $2')
    .replace(/(\d{5})(\d)/, '$1-$2');
}

export function mascararCpf(texto) {
  const d = texto.replace(/\D/g, '').slice(0, 11);
  return d
    .replace(/^(\d{3})(\d)/, '$1.$2')
    .replace(/^(\d{3})\.(\d{3})(\d)/, '$1.$2.$3')
    .replace(/^(\d{3})\.(\d{3})\.(\d{3})(\d)/, '$1.$2.$3-$4');
}

export function semAcentos(texto) {
  return texto.normalize('NFD').replace(/[̀-ͯ]/g, '');
}
```

`src/utils/datas.js`:

```javascript
export function somarDias(data, dias) {
  // a cópia à meia-noite não altera a data recebida e ignora a hora
  const nova = new Date(data.getFullYear(), data.getMonth(), data.getDate());
  nova.setDate(nova.getDate() + dias);
  return nova;
}

const UM_DIA = 24 * 60 * 60 * 1000; // um dia em milissegundos

export function diasEntre(inicio, fim) {
  return Math.round((fim - inicio) / UM_DIA);
}

export function ehDiaUtil(data) {
  const dia = data.getDay(); // 0 = domingo, 6 = sábado
  return dia !== 0 && dia !== 6;
}

// de domingo (0) a sábado (6): quantos dias até o próximo dia útil
const DIAS_ATE_O_PROXIMO_UTIL = [1, 1, 1, 1, 1, 3, 2];

export function proximoDiaUtil(data) {
  return somarDias(data, DIAS_ATE_O_PROXIMO_UTIL[data.getDay()]);
}

// versão pronta: o for repete o bloco diasUteis vezes (você escreve laços no E07)
export function preverEntrega(diasUteis, hoje = new Date()) {
  let data = hoje;
  for (let i = 0; i < diasUteis; i++) {
    data = proximoDiaUtil(data);
  }
  return data;
}

const formatoCurto = new Intl.DateTimeFormat('pt-BR', {
  weekday: 'short',
  day: 'numeric',
  month: 'short',
});

export function formatarData(data) {
  return formatoCurto.format(data);
}
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| Teste de `formatarPreco` falha com o texto igual ao do terminal | Espaço não separável depois do `R$` | Escrever `'R$\u00a0189,90'` no teste |
| Data aparece um dia antes | `new Date('AAAA-MM-DD')` lido em UTC | Montar com `new Date(ano, mes - 1, dia)` |
| Previsão um mês depois do esperado | Mês contado a partir de 1 | O mês vai de 0 a 11 |
| Teste passa hoje e falha amanhã | `preverEntrega` sem `hoje` no teste | Passar sempre uma data fixa |
| `toBe` falha com duas datas iguais | `toBe` compara se é o mesmo objeto | Usar `toEqual` |
| CPF colado vira `123456.789-01` | `replace` sem a flag `g`, ou com `'.'` no lugar da regex | `replace(/\D/g, '')` |
| `TypeError: Cannot read properties of null (reading '1')` | `match` que não casou | Conferir com `test` antes; no E07, com `if` |
| `ERR_MODULE_NOT_FOUND` ao rodar o script ou o teste | `import` de arquivo próprio sem a extensão | `'../utils/datas.js'`, com o `.js` |
| `pedido.json` aparece no `git status` | Arquivo gerado fora do `.gitignore` | Acrescentar `pedido.json` ao `.gitignore` |
| Projeto: `lerValor('R$ 187,50')` dá `null` | `$` sem barra na regex, ou o `R$` tirado depois do teste do formato | `R\$` na regex; limpar primeiro e conferir o formato no texto já limpo |
