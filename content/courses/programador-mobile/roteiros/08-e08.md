## Visão do encontro

**Objetivo:** o Racha-conta passa a se conferir sozinho. A turma aprende o que é um teste automatizado, instala o Jest e o Babel, escreve o primeiro teste da `calcularGorjeta`, quebra a função de propósito para ver o vermelho, transforma os casos da gorjeta numa tabela com `test.each` e, sozinha, escreve os testes de `paraCentavos` e `formatarReais`. O `toEqual` aparece com listas do `filter`, para o E11 só retomar. Não há laboratório à parte: os passos do projeto são a prática do dia.

**Como a aula funciona:** cada conceito vem em três slides, como na aula 3. A seção (título e gancho) é a hora da conversa: leia o gancho, ouça duas ou três respostas e explique com a analogia indicada abaixo. O slide seguinte é a âncora, o que o aluno lê para revisar. Depois do conceito vem um slide **Projeto 1 · Passo K**: a turma faz junto com você, no próprio computador, e só segue quando o "Pronto quando" aparece na tela de todos. No fim, a **Sua vez** é feita sozinho, sem a solução no slide.

**Resultado ao fim das 4h:** cada aluno tem no `racha-conta` o `babel.config.json` na raiz, o `package.json` com `"test": "jest"` e `jest`, `babel-jest` e `@babel/preset-env` (versão 7) em `devDependencies`, e `src/regras/conta.test.js` com 11 testes: o primeiro da gorjeta, a tabela da gorjeta com 4 linhas, o "sem o percentual", a tabela de `paraCentavos` com 2 linhas, o teste do `0.1 + 0.2` e a tabela de `formatarReais` com 2 linhas. `npm test` termina com `Tests: 11 passed, 11 total`. O `conta.js` e o `racha.js` não mudam: `npm run racha` mostra a mesma saída da etapa 4. O commit `Projeto 1: etapa 5, os primeiros testes` está no GitHub. É a etapa 5 do Projeto 1.

**Pré-requisitos:** E07: `src/regras/conta.js` com `paraCentavos`, `calcularGorjeta` (com `percentual = 10`) e `formatarReais`, todas com `export`; `return`, valor padrão, função seta, `import` e `export`, regra pura. E06: tipos, `typeof`, o `0.1 + 0.2`, centavos e `Math.round`. E05: commit e push. Aula 3: listas, comparações e `filter`. A turma **não** viu `if`/`else` (E10), laços (E11) nem métodos de texto (E09): nenhum código de hoje usa esses recursos.

**Materiais:** projetor com o terminal do VS Code em fonte grande, quadro, Wi-Fi para o `npm i` (371 pacotes por máquina), a página do Projeto 1 aberta (página do curso, seção **Projetos**), quiz publicado.

**Estado no início** (o fim da etapa 4). Quem não terminou a Sua vez do E07 precisa do `formatarReais` antes da Sua vez de hoje. `src/regras/conta.js`:

```javascript
export function paraCentavos(reais) {
  return Math.round(reais * 100);
}

export function calcularGorjeta(subtotal, percentual = 10) {
  return Math.round(subtotal * percentual / 100);
}

export function formatarReais(centavos) {
  const reais = (centavos / 100).toFixed(2);
  return `R$ ${reais}`;
}
```

## Projeto: sua vez (30 min)

**Enunciado:** o slide "Projeto 1 · Sua vez: os testes das outras duas". No `conta.test.js`, testes para `paraCentavos` (`187.5` dá `18750`, `72.9` dá `7290` e `0.1 + 0.2` dá `30`) e para `formatarReais` (`18750` dá `'R$ 187.50'` e `5` dá `'R$ 0.05'`). Pronto quando `npm test` termina com `Tests: 11 passed, 11 total`.

**Organização:** individual, cada um no próprio computador, sem olhar a tela do vizinho nos primeiros 15 minutos. Depois disso, quem travou pode pedir ajuda a um colega, que explica sem digitar por ele.

**Marcos:** 3:15, o `import` com as três funções e a tabela de `paraCentavos` verde (8 testes); 3:25, o `0.1 + 0.2` e a tabela de `formatarReais` (11 testes); 3:30, o Formatar Documento no `conta.test.js`, o commit `Projeto 1: etapa 5, os primeiros testes` e o `git push`; 3:35, todos com a etapa pronta.

**O que observar:**

- O `import` sem as duas funções novas: `ReferenceError: paraCentavos is not defined`
- O `%i` no nome do `paraCentavos`: o teste passa, mas o nome sai `paraCentavos(187) dá 18750`. Pergunte: "o nome diz o que o teste confere?". O certo é `%d`
- O gabarito com aspas num número, `toBe('18750')`: vermelho com `Expected: "18750"` e `Received: 18750`. "As aspas dizem: é texto"
- O gabarito do `formatarReais` com vírgula, `'R$ 187,50'`: vermelho com `Expected: "R$ 187,50"` e `Received: "R$ 187.50"`. A vírgula chega no E09; hoje o gabarito é o que a função promete agora
- O gabarito sem o espaço, `'R$187.50'`: os dois textos parecem iguais na tela; leia letra por letra
- O `0.1 + 0.2` como linha da tabela, `[0.1 + 0.2, 30]`: vale. O nome sai `paraCentavos(0.30000000000000004) dá 30`, e a contagem continua 11
- Para todo teste novo: "você já viu esse teste vermelho?". Quem diz que não troca o gabarito, vê o vermelho e volta

Pergunta para quem travou: "qual é a questão e qual é o gabarito? Escreva uma linha da tabela antes de escrever o resto."

:::example Solução de referência
`src/regras/conta.test.js` no fim da etapa 5:

```javascript
import { calcularGorjeta, paraCentavos, formatarReais } from './conta.js';

test('gorjeta de 10% sobre R$ 187,50 é R$ 18,75', () => {
  expect(calcularGorjeta(18750, 10)).toBe(1875);
});

test.each([
  [18750, 10, 1875],
  [3330, 15, 500],
  [18755, 10, 1876],
  [8000, 0, 0],
])('calcularGorjeta(%i, %i) dá %i', (subtotal, percentual, esperado) => {
  expect(calcularGorjeta(subtotal, percentual)).toBe(esperado);
});

test('sem o percentual, a gorjeta é de 10%', () => {
  expect(calcularGorjeta(18750)).toBe(1875);
});

test.each([
  [187.5, 18750],
  [72.9, 7290],
])('paraCentavos(%d) dá %i', (reais, esperado) => {
  expect(paraCentavos(reais)).toBe(esperado);
});

test('paraCentavos acerta a conta de 0.1 + 0.2', () => {
  expect(paraCentavos(0.1 + 0.2)).toBe(30);
});

test.each([
  [18750, 'R$ 187.50'],
  [5, 'R$ 0.05'],
])('formatarReais(%i) dá %s', (centavos, esperado) => {
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `npm i` parado por minutos | a turma toda baixando ao mesmo tempo, ou proxy | esperar em ondas de 3 ou 4 máquinas; sem rede, o Plano B |
| `"Error: no test specified"` | o `test` ainda é o do `npm init`, ou o `package.json` não foi salvo | `"test": "jest"` e <kbd>Ctrl</kbd> + <kbd>S</kbd> |
| `No tests found, exiting with code 1` com o arquivo criado | o nome não termina em `.test.js` (`conta.teste.js`, `conta-test.js`) | renomear para `conta.test.js` |
| `Must use import to load ES Module` e `The file contains ESM syntax` | `babel.config.json` ausente, fora da raiz ou com outro nome | criar ao lado do `package.json`, com o nome exato |
| `Error while parsing config - JSON5: invalid character '}' at 1:75` | um colchete faltando na linha do `babel.config.json` | comparar com o slide: `[[` no começo, `]]` no fim |
| `Cannot find module 'conta.js' from 'src/regras/conta.test.js'` | o `import` sem o `./` | `'./conta.js'` |
| `Cannot find module './conta.js'` | o `conta.test.js` foi criado fora de `src/regras` | mover para ao lado do `conta.js` |
| `ReferenceError: paraCentavos is not defined` | a função não está no `import` | acrescentar o nome nas chaves |
| 3 testes em vez de 4, com `NaN` e `%i` no nome e `Expected: undefined` | faltou a vírgula entre duas linhas da tabela | uma vírgula no fim de cada linha, `[18750, 10, 1875],` |
| `Received: serializes to the same string` | `toBe` com lista | `toEqual` |
| o nome sai `paraCentavos(187) dá 18750` | `%i` com número que tem casas | `%d` |
| `Expected: "18750"` e `Received: 18750` | gabarito com aspas num número | tirar as aspas |
| `jest` em `^25.1.0` no `package.json` | alguém rodou `npm audit fix --force` | `npm i -D jest@30 babel-jest@30`; confira que volta para `^30.5.2` |
| 15 linhas de `npm warn ERESOLVE overriding peer dependency` | instalação sem o `@7` num Node 24 ou mais novo | funciona assim; para ficar igual aos slides, `npm i -D @babel/preset-env@7` |
| `npm` recusado pelo PowerShell | política de execução do Windows | o comando do checklist do E01 ou o Prompt de Comando |
