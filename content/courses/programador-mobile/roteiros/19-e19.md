## Visão do encontro

**Objetivo:** trocar o `then` por `async`/`await` no checkout do E18 e conectar o `lojinha-regras` a uma API de verdade pelo terminal, com erros de rede e de resposta tratados, a camada `src/api/`, testes com `fetch` simulado e uma busca que cancela o pedido velho.

**Materiais:** projetor, Wi-Fi testado, terminal com fonte grande, [demos-e19.zip](materiais/e19/demos-e19.zip) com as demonstrações do Bloco 1, solução de referência na branch `e19-solucao` do seu `lojinha-regras` de demonstração, quiz publicado.

## Bloco 1 · Async e await no checkout (50 min)

**"A variável de fora do checkout" (5 min).** Aponte o `let reserva` do lado de fora da corrente e faça a pergunta do slide. Esperado: "uma linha por etapa, como uma receita". Anote a resposta no quadro sem explicar.

**"async" e "await" (8 min).** No REPL do Node (`node`), com a turma:

:::steps
1. `async function f() { return 19.9; }` e `f()`: aparece `Promise { 19.9 }`. "Devolvi um número e recebi uma Promise."
2. `await f()`: aparece `19.9`. O REPL aceita `await` solto; num arquivo, só dentro de `async` ou no nível de cima de um módulo, que vocês veem no slide do script.
3. `async function g() { throw new Error('Cupom inválido'); }` e `g()`: Promise rejeitada. "O `throw` virou rejeição."
:::

**"then e await lado a lado" e "try e catch com await" (8 min).** Na pasta `demos-e19`, abra o `pontinhos.js` e rode `node pontinhos.js 01310-100`: pontinhos e o frete. Rode `node pontinhos.js 123`: pontinhos, "CEP inválido" e o programa termina. Agora apague o `finally` e ponha o `clearInterval` logo depois do `await`, como muita gente escreve. Rode com `123`: a mensagem aparece, mas os pontinhos não param e o terminal não volta. "Um timer ligado mantém o Node vivo. No app, no E30, isso é a rodinha girando para sempre." Pare com <kbd>Ctrl</kbd> + <kbd>C</kbd> e devolva o `finally`.

**"Pense" (4 min).** Individual, 1 minuto. Esperado: "Pedido confirmado!" aparece logo depois da etapa 1, antes de qualquer etapa terminar. Se alguém disser "aparece o erro", pergunte quando o `console.log` roda. No `lojinha-regras` de demonstração, com `CHANCE_DE_FALHA = 1`, escreva num arquivo provisório o `finalizar` do slide sem o `await`, usando o `mostrarEtapa` do `finalizar.js`, e rode: a etapa 1, "Pedido confirmado!" e, 800 ms depois, o Node para com o `FalhaNoCheckoutError` de uma Promise rejeitada sem tratamento. Ponha o `await` e rode de novo: "Não deu: ...". Volte o `CHANCE_DE_FALHA` para 0.2.

**"Em sequência" a "A soma ou a mais lenta" (7 min).** Rode `node tempo.js`: cerca de 1800 ms em sequência e 800 ms em paralelo, medidos com `console.time`. Projete a animação: quando a linha do tempo cruza 800 ms, o paralelo já terminou e a sequência ainda está no prazo; compare com os números do terminal. Pergunte se o checkout pode ir em paralelo. Esperado: não, cobrar sem reserva quebra a regra (é a questão 10 do quiz).

**"await dentro de laços" e "Pratique" (7 min).** Rode `node lacos.js`: o `for...of` leva cerca de 900 ms, o `Promise.all` cerca de 300 ms e o `forEach` "termina" em menos de 1 ms, antes de consultar qualquer item, que aparecem depois. Três minutos para o desafio. Esperado: `for...of` no lugar do `forEach`. Se alguém propuser `Promise.all`, aceite e pergunte o que muda: os pedidos saem juntos, mas o array de resultados mantém a ordem.

**"O checkout reescrito" a "Testes assíncronos" (8 min).** O momento mais importante do bloco, no `lojinha-regras` de demonstração:

:::steps

`src/api/cliente.js`:

```javascript
import { ErroDeNegocio } from '../modelos/erros.js';

export const URL_BASE = 'https://dummyjson.com';

export class ApiError extends ErroDeNegocio {
  constructor(status) {
    super(status === 404 ? 'Não encontramos esse produto.' : 'A loja não respondeu. Tente de novo.', 'API_' + status);
    this.name = 'ApiError';
    this.status = status;
  }
}

export async function pedir(caminho, opcoes = {}) {
  let resposta;
  try {
    resposta = await fetch(URL_BASE + caminho, {
      ...opcoes,
      headers: { 'Content-Type': 'application/json', ...opcoes.headers },
    });
  } catch (erro) {
    if (erro.name === 'AbortError') throw erro; // cancelado de propósito
    throw new ErroDeNegocio('Sem conexão. Confira a internet e tente de novo.', 'SEM_CONEXAO');
  }
  if (!resposta.ok) throw new ApiError(resposta.status);
  return resposta.json();
}
```

`src/api/produtos.js`:

import { pedir } from './cliente.js';

export function traduzirProduto(p) {
  return {
    id: p.id,
    nome: p.title,
    preco: p.price, // em dólar: a API é de testes
    categoria: p.category,
    imagem: p.thumbnail,
    avaliacao: p.rating,
    descricao: p.description,
    destaque: p.rating >= 4.5,
  };
}

export async function listarProdutos({ limite = 20, pular = 0, sinal } = {}) {
  const dados = await pedir(`/products?limit=${limite}&skip=${pular}`, { signal: sinal });
  return dados.products.map(traduzirProduto);
}

export async function buscarProduto(id) {
  return traduzirProduto(await pedir('/products/' + id));
}

export async function pesquisar(termo, sinal) {
  const caminho = '/products/search?q=' + encodeURIComponent(termo.trim());
  const dados = await pedir(caminho, { signal: sinal });
  return dados.products.map(traduzirProduto);
}

async function buscarAoDigitar(termo) {

// troca o fetch por uma função que responde na hora, sem rede
function responder(status, corpo) {

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| "Sem conexão" com a internet funcionando | `URL_BASE` digitado errado (sem `https://`, barra sobrando) ou rede da sala bloqueando o domínio | `console.log(URL_BASE + caminho)` antes do `fetch`; abrir o endereço impresso no navegador |
| `Cannot read properties of undefined (reading 'map')` | `resposta.json()` sem `await`, ou `.products` lido numa rota de um produto só | Conferir os dois `await`; abrir a URL no navegador para ver a forma da resposta |
| `ERR_MODULE_NOT_FOUND` no `node`, mas `npm test` verde | Import relativo sem `.js`: o Jest acha o arquivo, o Node não | `from './cliente.js'`, com a extensão |
| `SyntaxError: await is only valid in async functions and the top level bodies of modules` | `await` numa função sem `async`, ou `package.json` sem `"type": "module"` | `async` na função; conferir o `package.json` do E02 |
| `SyntaxError: Unexpected token '<'` | `.json()` numa página HTML de erro, como a de uma rota errada | Conferir `resposta.ok` antes do `.json()`; imprimir o caminho |
| `digitar.js` imprime "cancelada" para os dois termos | `controleAtual = controle` antes do `abort()`: a busca cancela a si mesma | Primeiro `controleAtual?.abort()`, depois o controle novo |
| Teste verde mesmo com o esperado errado | `expect(...).rejects` sem `await` | `await expect(...)`, e conferir que fica vermelho com o esperado errado |
| "A loja não respondeu" em várias mesas juntas | Status 429: a DummyJSON limita os pedidos por endereço, e a sala sai por um endereço só | Esperar 10 segundos; não rodar scripts em laço; testes com `fetch` simulado |
| `fetch is not defined` | Node anterior ao 18 | `node -v`; instalar a versão LTS, como no E01 |
