## Visão do encontro

## Laboratório (55 min)

**Enunciado (slide "No laboratório"):** array do E22 renomeado para `tarefasIniciais` e passado ao `useState` no `App`; `FormularioTarefa.jsx` recebendo `onAdicionar`; `adicionarTarefa`, `alternarConcluida` e `removerTarefa` no `App`, passadas até `CartaoTarefa`, que ganha Concluir e Remover; `pendentes` no `Cabecalho`; tarefa vazia bloqueada e campo limpo; commit "E23: estado e formulário" e push.

**Organização:** individual; quem não entregou o E22 faz dupla com quem entregou, no projeto do colega.

**Marcos (no quadro):** 12 min, Concluir riscando o cartão; 28 min, `FormularioTarefa` adicionando; 40 min, `removerTarefa` e contador; 48 min, validação, campo limpo, console sem avisos; 55 min, push e link entregue. Quem chegar aos 40 minutos sem o contador de pendentes faz o commit sem ele e termina em casa (Plano B, "Turma atrasada").

**Onde circular:** duplas primeiro, depois o fundo da sala. Quatro pontos: arrow function no `onClick`; nenhum `push`; `event.preventDefault()` na primeira linha de `enviar`; `value` e `onChange` juntos. Extra para quem terminar cedo: botão "Limpar concluídas" com `filter`.

:::example Solução de referência
`src/App.jsx`:

```jsx
import { useState } from 'react'
import Cabecalho from './components/Cabecalho.jsx'
import FormularioTarefa from './components/FormularioTarefa.jsx'
import ListaTarefas from './components/ListaTarefas.jsx'
import Rodape from './components/Rodape.jsx'

const tarefasIniciais = [
  { id: 1, titulo: 'Estudar React', prioridade: 'alta', concluida: false },
  { id: 2, titulo: 'Fazer compras', prioridade: 'baixa', concluida: true },
]

function App() {
  const [tarefas, setTarefas] = useState(tarefasIniciais)
  const pendentes = tarefas.filter((t) => !t.concluida).length

  function adicionarTarefa(titulo, prioridade) {
    const nova = { id: Date.now(), titulo, prioridade, concluida: false }
    setTarefas([...tarefas, nova])
  }

  function alternarConcluida(id) {
    setTarefas(tarefas.map((t) => (t.id === id ? { ...t, concluida: !t.concluida } : t)))
  }

  function removerTarefa(id) {
    setTarefas(tarefas.filter((t) => t.id !== id))
  }

  return (
    <>
      <Cabecalho pendentes={pendentes} />
      <FormularioTarefa onAdicionar={adicionarTarefa} />
      <ListaTarefas tarefas={tarefas} onAlternar={alternarConcluida} onRemover={removerTarefa} />
      <Rodape />
    </>
  )
}

export default App
```

`src/components/FormularioTarefa.jsx`:

```jsx
import { useState } from 'react'

function FormularioTarefa({ onAdicionar }) {
  const [titulo, setTitulo] = useState('')
  const [prioridade, setPrioridade] = useState('media')

  function enviar(event) {
    event.preventDefault()
    if (titulo.trim() === '') return
    onAdicionar(titulo, prioridade)
    setTitulo('')
  }

  return (
    <form onSubmit={enviar}>
      <input
        value={titulo}
        onChange={(e) => setTitulo(e.target.value)}
        placeholder="O que precisa fazer?"
      />
      <select value={prioridade} onChange={(e) => setPrioridade(e.target.value)}>
        <option value="alta">Alta</option>
        <option value="media">Média</option>
        <option value="baixa">Baixa</option>
      </select>
      <button type="submit">Adicionar</button>
    </form>
  )
}

export default FormularioTarefa
```

`src/components/CartaoTarefa.jsx`:

```jsx
import estilos from './CartaoTarefa.module.css'

export default function CartaoTarefa({ id, titulo, prioridade, concluida, onAlternar, onRemover }) {
  const classeAlta = prioridade === 'alta' ? estilos.alta : ''
  const classeConcluida = concluida ? estilos.concluida : ''

  return (
    <div className={`${estilos.cartao} ${classeAlta} ${classeConcluida}`}>
      <h3>{titulo}</h3>
      <p>Prioridade: {prioridade}</p>
      <button onClick={() => onAlternar(id)}>{concluida ? 'Reabrir' : 'Concluir'}</button>
      <button onClick={() => onRemover(id)}>Remover</button>
    </div>
  )
}
```

`ListaTarefas.jsx` repassa as funções; `Cabecalho.jsx` ganha `pendentes`:

```jsx
import CartaoTarefa from './CartaoTarefa.jsx'

export default function ListaTarefas({ tarefas, onAlternar, onRemover }) {
  return (
    <section>
      {tarefas.length === 0 && <p>Nenhuma tarefa por aqui</p>}
      {tarefas.map((t) => (
        <CartaoTarefa key={t.id} id={t.id} titulo={t.titulo} prioridade={t.prioridade}
          concluida={t.concluida} onAlternar={onAlternar} onRemover={onRemover} />
      ))}
    </section>
  )
}
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| Ação dispara ao carregar a página, ou "Too many re-renders" | `onClick={funcao()}` com parênteses | Tire os parênteses ou embrulhe: `() => funcao(id)` |
| Concluir não muda a tela, mas o `console.log` mostra o valor novo | Mutação (`push`, `t.concluida = true`) ou variável comum | "O array entregue ao `setTarefas` é novo? O que o `Object.is` responde?"; refaça com as receitas |
| "useState is not defined" | Falta o `import` | `import { useState } from 'react'` |
| Ao adicionar, a página pisca e a lista volta ao início | Sem `event.preventDefault()`, ou `onClick` no botão em vez de `onSubmit` | `preventDefault` na primeira linha de `enviar`; botão `type="submit"` |
| Campo não aceita digitação | `value` sem `onChange` | `onChange={(e) => setTitulo(e.target.value)}` |
| Tarefa entra, mas o campo não limpa | Input sem `value` | `value={titulo}` |
| "onAlternar is not a function" ou aviso de `key` na tarefa nova | Prop não repassada pelo `ListaTarefas`; `id` esquecido em `nova` | Siga a cadeia `App`, `ListaTarefas`, `CartaoTarefa`; confira `Date.now()` |
| Salva e nada muda; terminal parado | `npm run dev` caiu ou roda em outra pasta ("Missing script: dev") | `cd minhas-tarefas` e `npm run dev` |
| Projeto 4: a busca funciona, mas o filtro de dificuldade apaga a busca (ou o contrário) | Cada filtro aplicado sobre a lista original, e só o último vai para a tela | Encadear: o resultado de `buscarPorNome` entra no `filtrarPorDificuldade` |

- **Sem projetor:** a turma segue os slides no notebook; a demonstração do contador vira exercício guiado, cada um digitando o que você dita.
- **Aluno sem computador:** dupla, trocando quem digita a cada marco; quiz pelo celular.
- **Projeto do E21 perdido ou quebrado:** editor online com modelo Vite + React (StackBlitz ou CodeSandbox) e entrega do link do projeto online; reserve 10 min do laboratório para recriar o projeto com `npm create vite@latest` no Node instalado no E01.
- **Celular:** não é usado neste encontro.
- **Turma atrasada:** o contador de pendentes no `Cabecalho` (passo 4 do laboratório) vai para casa, até o E24; adicionar, concluir, remover e a validação ficam na aula. No bloco de projeto, mantenha o check-in e a apresentação da etapa 3 e mande o trabalho para casa.
