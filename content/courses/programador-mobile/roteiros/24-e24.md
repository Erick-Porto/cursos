## Visão do encontro

**Objetivo:** o `minhas-tarefas` passa a buscar as tarefas numa API com `useEffect` (carregando, erro e limpeza), e a lógica sai do `App` para hooks próprios: `useTituloDaAba`, `useDebounce` e `useTarefas`, com um campo de busca. No Projeto 4, a etapa 4 leva o `livro-de-receitas` para a DummyJSON, com `useReceitas`, `useDebounce` e as favoritas salvas pelo `useFavoritos`.

**Resultado ao fim das 4h:** app no GitHub que abre com 10 tarefas da JSONPlaceholder, mostra "Carregando..." e, sem rede, a mensagem de erro com "Tentar de novo", busca pelo título com uma requisição por pausa e continua adicionando, concluindo e removendo. Commit "E24: efeitos e hooks próprios". O `useTituloDaAba` (passo 3 do laboratório) e a etapa 4 do Projeto 4 terminam em casa, até o E25.

**Como os slides foram escritos:** para quem nunca programou. Cada aula tem um slide "Palavras novas de hoje", cada termo técnico é explicado na primeira vez que aparece, e o código novo vem com uma tabela "em português" que o traduz linha por linha (`carregarTarefas`, a limpeza, o primeiro hook, o `useDebounce`). Em aula, leia a tradução em voz alta, apontando cada linha no código.

**Slides de seção:** cada conceito abre com um slide que só tem o nome dele e uma frase de gancho, no centro ("A limpeza": "O que você faz com a luz quando sai do quarto?"). É a hora da conversa: faça a pergunta do gancho, indicada abaixo, ouça duas ou três respostas e explique com a analogia. As analogias são as do curso inteiro: o `useEffect` é o bilhete "depois de desenhar a tela, faça isto", a API é o garçom, a Promise é a senha da lanchonete, o hook próprio é uma receita sua. O slide seguinte, a âncora, ensina o mesmo conceito por escrito, e o próximo, "... na prática", mostra dois ou três casos com a saída; em aula, passe pelos dois apontando o que acabou de dizer, sem ler tudo.

**Pré-requisitos (E23):** `App` com `useState(tarefasIniciais)`, `FormularioTarefa` com `onAdicionar`, `adicionarTarefa`, `alternarConcluida`, `removerTarefa` e `pendentes` no `Cabecalho`; commit "E23: estado e formulário". Do JavaScript, a turma já tem `fetch`, `async`/`await`, `resposta.ok` e `AbortController` (E19), `try/catch/finally` (E17), closures e `debounce` (E10a) e módulos (E11a): no encontro, são lembretes de um minuto, não aulas.

**Materiais:** projetor, Wi-Fi estável, um notebook por aluno (sem celular), projeto de demonstração no estado do fim do E23, `public/tarefas.json` de reserva, solução de referência testada, `quiz-e24` publicado.

## Bloco 1 · Efeitos e dados externos (50 min)

**"O que você vai aprender", "Palavras novas de hoje", "As tarefas somem ao recarregar" e "Quando o componente nasce" (7 min).** Leia as cinco palavras em voz alta, com um exemplo rápido de cada uma. Pergunte: "se o app busca as tarefas toda vez que desenha a tela, e a resposta da busca muda a tela, o que acontece?". Esperado: ele desenha de novo e busca de novo, sem parar. "Montar é encaixar a peça de Lego na tela, na primeira vez; cada `set` desenha de novo. Buscar no corpo da função é buscar a cada desenho." Com "Quando o componente nasce", monte o laço no quadro até a turma ver que `setTarefas` chama `App()` de novo.

**Seção "useEffect" (3 min).** Pergunte, como no gancho: "o que você faz logo depois de abrir a porta de casa, à noite?". Esperado: acender a luz, largar a mochila. "O `useEffect` é um bilhete: 'depois de desenhar a tela, faça isto'. O React desenha primeiro e só então roda o efeito." Em "useEffect: código que roda depois de renderizar" e "useEffect na prática":

:::steps
1. Importe `useEffect` e escreva `useEffect(() => { console.log('App apareceu') }, [])` no `App`. Salve e recarregue: a linha aparece **duas vezes**. Diga só "guardem essa dúvida: ela volta no fim do bloco".

**Seção "Dependências" (7 min).** Pergunte, como no gancho: "como o app da loja sabe a hora de avisar que o preço baixou?". Esperado: você marca o produto, e ele avisa quando o preço muda. **"Pratique: busca no corpo da função" (5 min).** Dois minutos no caderno, depois em voz alta. Respostas: (1) `setTarefas` faz o React executar `App()` de novo e a busca dispara outra vez; (2) sem parar; (3) não: sem o segundo argumento, o efeito roda após toda renderização e o laço continua. :::steps

## Laboratório (55 min)

**Organização:** individual; quem não entregou o E23 faz dupla com quem entregou, no projeto do colega.

**Marcos (no quadro):** 13 min, dez tarefas da API na tela (ou do `/tarefas.json`); 23 min, "Carregando...", erro sem rede e a limpeza; 40 min, `useTarefas` com "Tentar de novo" e o `App` sem `useEffect`; 50 min, `useDebounce` e a busca; 55 min, lint, push e link entregue.

**Onde circular:** duplas primeiro, depois o fundo da sala. Cinco pontos: o array de dependências de cada efeito; o `finally` com a guarda do `aborted`; todos os hooks no topo do `App`, antes de qualquer `return`; o `useTarefas` recebendo `buscaAtrasada`, não `busca`; `tentativa` nas dependências. Extra para quem terminar cedo: botão "Limpar busca", que chama `setBusca('')`, e a frase "Nada encontrado para ..." quando a busca não acha nada.

const URL_API = 'https://jsonplaceholder.typicode.com/todos'

export async function carregarTarefas(busca, sinal) {
  const endereco = `${URL_API}?_limit=10&q=${encodeURIComponent(busca.trim())}`
  const resposta = await fetch(endereco, { signal: sinal })
  if (!resposta.ok) throw new Error('A API respondeu ' + resposta.status)
  const dados = await resposta.json()
  return dados.map((item) => ({
    id: item.id, titulo: item.title, concluida: item.completed, prioridade: 'media',
  }))
}

import { useEffect, useState } from 'react'

export function useDebounce(valor, espera = 300) {
  const [atrasado, setAtrasado] = useState(valor)

  useEffect(() => {
    const temporizador = setTimeout(() => setAtrasado(valor), espera)
    return () => clearTimeout(temporizador)
  }, [valor, espera])

  return atrasado
}

`src/hooks/useTarefas.js`:

```javascript
import { useEffect, useState } from 'react'
import { carregarTarefas } from '../api/tarefas.js'

export function useTarefas(busca = '') {
  const [tarefas, setTarefas] = useState([])
  const [carregando, setCarregando] = useState(true)
  const [erro, setErro] = useState(null)
  const [tentativa, setTentativa] = useState(0) // conta os "Tentar de novo"

  useEffect(() => {
    const controle = new AbortController()
    async function buscar() {
      try {
        setTarefas(await carregarTarefas(busca, controle.signal))
        setErro(null)
      } catch (e) {
        if (e.name !== 'AbortError') setErro('Não foi possível carregar as tarefas.')
      } finally {
        if (!controle.signal.aborted) setCarregando(false)
      }
    }
    buscar()
    return () => controle.abort()
  }, [busca, tentativa])

  function recarregar() {
    setCarregando(true)
    setErro(null)
    setTentativa(tentativa + 1) // muda a dependência: o efeito roda de novo
  }

  function adicionarTarefa(titulo, prioridade) {
    const nova = { id: Date.now(), titulo, prioridade, concluida: false }
    setTarefas([...tarefas, nova])
  }

  function alternarConcluida(id) {
    setTarefas(tarefas.map((t) => (t.id === id ? { ...t, concluida: !t.concluida } : t)))
  }

  function removerTarefa(id) {
    setTarefas(tarefas.filter((t) => t.id !== id))
  }

  return { tarefas, carregando, erro, recarregar,
    adicionarTarefa, alternarConcluida, removerTarefa }
}
```

`src/App.jsx`:

```jsx
import { useState } from 'react'
import Cabecalho from './components/Cabecalho.jsx'
import FormularioTarefa from './components/FormularioTarefa.jsx'
import ListaTarefas from './components/ListaTarefas.jsx'
import Rodape from './components/Rodape.jsx'
import { useDebounce } from './hooks/useDebounce.js'
import { useTarefas } from './hooks/useTarefas.js'
import { useTituloDaAba } from './hooks/useTituloDaAba.js'

function App() {
  const [busca, setBusca] = useState('')
  const buscaAtrasada = useDebounce(busca, 300)
  const { tarefas, carregando, erro, recarregar, adicionarTarefa, alternarConcluida, removerTarefa } =
    useTarefas(buscaAtrasada)
  const pendentes = tarefas.filter((t) => !t.concluida).length
  useTituloDaAba(`(${pendentes}) Minhas Tarefas`)

  return (
    <>
      <Cabecalho pendentes={pendentes} />
      <FormularioTarefa onAdicionar={adicionarTarefa} />
      <input value={busca} onChange={(e) => setBusca(e.target.value)} placeholder="Buscar tarefa" />
      {busca !== buscaAtrasada && <p>Buscando...</p>}
      {erro && (
        <p className="erro">
          {erro} <button onClick={recarregar}>Tentar de novo</button>
        </p>
      )}
      {carregando ? (
        <p>Carregando...</p>
      ) : (
        <ListaTarefas tarefas={tarefas} onAlternar={alternarConcluida} onRemover={removerTarefa} />
      )}
      <Rodape />
    </>
  )
}

export default App
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `dados.map is not a function` | Faltou `await` antes de `fetch` ou de `resposta.json()` | `console.log(dados)` mostra uma Promise; adicione os dois `await` |
| Tela pisca; aba Rede com dezenas de requisições | `useEffect` sem o `[]` (ou sem o array de dependências) | Olhe o fim do efeito e complete o array |
| Aviso "useEffect must not return anything besides a function" | `useEffect(async () => ...)` | Crie `iniciar` (ou `buscar`) dentro do efeito e chame-a |
| "Carregando..." para sempre, sem erro | `setCarregando(false)` dentro do `try` e a requisição falhou, ou URL errada | Mova para o `finally`; veja o status na aba Rede |
| "Nenhuma tarefa por aqui" pisca antes da lista, só no dev | `finally` sem a guarda `if (!controle.signal.aborted)` | O pedido cancelado pelo `StrictMode` desliga o `carregando`; recoloque a guarda |
| Cartões sem título ou prioridade | `setTarefas(dados)` sem o `map` de tradução | Compare o JSON da API com as props do `CartaoTarefa` |
| `Failed to fetch` com Wi-Fi funcionando | API fora do ar ou bloqueada pela rede da escola | Troque `URL_API` por `'/tarefas.json'` |
| `Rendered more hooks than during the previous render` | Hook depois de um `return` antecipado ou dentro de `if` | Todos os hooks no topo; os `return` depois deles |
| Lint: `React Hook ... is called in function ...` | Hook numa função de evento ou numa função comum, ou hook sem `use` no nome | Chame o hook no topo do componente e use o que ele devolve no evento |
| Página em branco e `does not provide an export named 'default'` no console | Import sem chaves de um export nomeado | `import { useTarefas } from './hooks/useTarefas.js'` |
| Cada letra da busca vira uma requisição | `useTarefas(busca)` em vez de `useTarefas(buscaAtrasada)` | Siga a cadeia: campo, `busca`, `useDebounce`, `buscaAtrasada`, `useTarefas` |
| "Tentar de novo" liga o "Carregando..." e nada acontece | `tentativa` fora das dependências do efeito | `}, [busca, tentativa])` |
| Projeto 4: as favoritas somem a cada F5 no `npm run dev` | `useState([])` e a leitura do `localStorage` num efeito; o efeito que salva grava `[]` antes | Ler no valor inicial: `useState(lerFavoritas())`; o efeito só salva |
