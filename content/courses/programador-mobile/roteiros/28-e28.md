## Visão do encontro

**Objetivo:** dar estado, lista e remoção confirmada à tela estática do `minhas-tarefas-mobile` e ensinar a ler o que o Expo diz quando o app quebra.

**Resultado:** app que adiciona, conclui e remove tarefas no celular do aluno, trata a lista vazia, e `README.md` com 3 bugs descritos.

**Pré-requisitos:** `minhas-tarefas-mobile` do E27 rodando no Expo Go (`SafeAreaView`, `CartaoTarefa`, `StyleSheet`); `useState` com eventos e formulário controlado (E23); spread, `map` e `filter` (E09); breakpoints no VS Code (E03).

**Materiais:** projetor espelhando o celular do instrutor, Wi-Fi comum a celulares e notebooks, repositórios no GitHub, `quiz-e28` publicado.

## Bloco 1 · Estado e FlatList no React Native (50 min)

**"Uma tela bonita que não faz nada" a "Eventos: web e React Native" (10 min).** No celular espelhado, digite "Comprar pão" e toque em Adicionar: nada. Pergunte o que deu vida à lista web; esperado: `useState`. Na tabela de eventos, martele: "`onChangeText` recebe o texto pronto; não existe `e.target` porque não existe DOM".

**"TextInput controlado" a "Adicionando no App com spread" (15 min).** Ao vivo:

:::steps
1. Crie `src/components/FormularioTarefa.js` com `TextInput` controlado e `Pressable` Adicionar; digite no celular e o texto aparece letra a letra.
2. Em `App.js`, troque os 3 cartões fixos por `useState` com 3 tarefas renderizadas com `map`.
3. Escreva `adicionarTarefa` com `[...tarefas, nova]`, passe `onAdicionar` e adicione "Comprar pão": o campo limpa e o cartão aparece.
4. Troque o spread por `tarefas.push(nova)`: nada aparece. Volte. "Guardem esse sintoma."
:::

**"FlatList: a lista que só desenha o visível" a "Pense" (15 min).** Com 3 itens, substitua o `map` por `FlatList`: a tela fica igual. Cole o gerador de 1.000 itens no estado inicial e volte ao `ScrollView` com `map`: o app demora a abrir e rola engasgado; peça para contarem os segundos. Troque pela `FlatList`: abre na hora e rola liso. Só então projete "ScrollView ou FlatList?". No "Pense", esperado: `FlatList` para as mensagens, `ScrollView` para as 8 opções fixas. Se ninguém responder: "Quantas mensagens cabem na tela? Dez? Por que desenhar 10.000?"

**"Lista vazia, cabeçalho e separador" a "Próximos passos" (10 min).** Volte às 3 tarefas. Acrescente separador e `ListEmptyComponent`; esvazie o array para mostrar "Nenhuma tarefa". Leia o aviso: `FlatList` dentro de `ScrollView`, nunca. Escreva `alternarConcluida`, ligue ao `onPress` do cartão e toque: ele esmaece. Digite `confirmarRemocao` e toque: a turma vê a caixa nativa.

:::tip Ritmo
Se atrasar, não digite o `Alert`: mostre o código e demonstre no celular. Pule `ListHeaderComponent`. Não corte os 1.000 itens.

**Onde circular:** olhe os terminais, não só as telas. Procure `e.target.value`, `onClick`, `push`, `keyExtractor` devolvendo número e `onPress: removerTarefa(id)` sem arrow function. Para quem travou no bug 3: "o que o terminal imprimiu? Então `item` é o quê?"

:::example Solução de referência
`src/components/FormularioTarefa.js`:

```jsx
import { useState } from 'react';
import { Pressable, StyleSheet, Text, TextInput, View } from 'react-native';

export default function FormularioTarefa({ onAdicionar }) {
  const [texto, setTexto] = useState('');

  function adicionar() {
    if (texto.trim() === '') return;
    onAdicionar(texto.trim());
    setTexto('');
  }

  return (
    <View style={estilos.formulario}>
      <TextInput
        style={estilos.campo}
        placeholder="Nova tarefa"
        value={texto}
        onChangeText={setTexto}
      />
      <Pressable style={estilos.botao} onPress={adicionar}>
        <Text style={estilos.textoBotao}>Adicionar</Text>
      </Pressable>
    </View>
  );
}

const estilos = StyleSheet.create({
  formulario: { flexDirection: 'row', paddingHorizontal: 16, marginBottom: 12, gap: 8 },
  campo: { flex: 1, backgroundColor: '#ffffff', borderRadius: 8, paddingHorizontal: 12, paddingVertical: 10 },
  botao: { backgroundColor: '#0ea5e9', borderRadius: 8, paddingHorizontal: 16, justifyContent: 'center' },
  textoBotao: { color: '#ffffff', fontWeight: 'bold' },
});
```

`App.js`, estado e funções:

```jsx
import { useState } from 'react';
import { Alert, FlatList, StyleSheet, Text, View } from 'react-native';
import { SafeAreaProvider, SafeAreaView } from 'react-native-safe-area-context';
import CartaoTarefa from './src/components/CartaoTarefa';
import FormularioTarefa from './src/components/FormularioTarefa';

export default function App() {
  const [tarefas, setTarefas] = useState([]);
  const pendentes = tarefas.filter((t) => !t.concluida).length;

  function adicionarTarefa(titulo) {
    const nova = { id: Date.now(), titulo, prioridade: 'media', concluida: false };
    setTarefas([...tarefas, nova]);
  }

  function alternarConcluida(id) {
    setTarefas(tarefas.map((t) => (t.id === id ? { ...t, concluida: !t.concluida } : t)));
  }

  function removerTarefa(id) {
    setTarefas(tarefas.filter((t) => t.id !== id));
  }

  function confirmarRemocao(id) {
    Alert.alert('Remover?', 'Esta ação não pode ser desfeita', [
      { text: 'Cancelar' },
      { text: 'Remover', onPress: () => removerTarefa(id) },
    ]);
  }
  // o return vem no bloco seguinte
```

`App.js`, tela e estilos (`contentContainerStyle` dá a margem lateral da lista):

```jsx
  return (
    <SafeAreaProvider>
      <SafeAreaView style={estilos.tela}>
        <View style={estilos.cabecalho}>
          <Text style={estilos.titulo}>Minhas Tarefas</Text>
          <Text style={estilos.contador}>{pendentes} pendentes</Text>
        </View>
        <FormularioTarefa onAdicionar={adicionarTarefa} />
        <FlatList
          data={tarefas}
          keyExtractor={(item) => String(item.id)}
          renderItem={({ item }) => (
            <CartaoTarefa
              titulo={item.titulo}
              prioridade={item.prioridade}
              concluida={item.concluida}
              onAlternar={() => alternarConcluida(item.id)}
              onRemover={() => confirmarRemocao(item.id)}
            />
          )}
          contentContainerStyle={estilos.lista}
          ItemSeparatorComponent={() => <View style={estilos.separador} />}
          ListEmptyComponent={<Text style={estilos.vazio}>Nenhuma tarefa</Text>}
        />
      </SafeAreaView>
    </SafeAreaProvider>
  );
}

const estilos = StyleSheet.create({
  tela: { flex: 1, backgroundColor: '#f1f5f9' },
  cabecalho: { padding: 16, flexDirection: 'row', justifyContent: 'space-between', alignItems: 'center' },
  titulo: { fontSize: 24, fontWeight: 'bold', color: '#0f172a' },
  contador: { fontSize: 14, color: '#475569' },
  lista: { paddingHorizontal: 16 },
  separador: { height: 8 },
  vazio: { textAlign: 'center', color: '#64748b', marginTop: 32 },
});
```

`src/components/CartaoTarefa.js`: a `View` raiz vira `Pressable`, o botão Concluir vira um `Text` de dica, os estilos ganham `concluida: { opacity: 0.5 }` e `dica: { fontSize: 12, color: '#64748b', marginTop: 8 }`, e o `marginBottom` do cartão sai.

```jsx
export default function CartaoTarefa({ titulo, prioridade, concluida, onAlternar, onRemover }) {
  return (
    <Pressable
      onPress={onAlternar}
      onLongPress={onRemover}
      style={[estilos.cartao, prioridade === 'alta' && estilos.alta, concluida && estilos.concluida]}
    >
      <View style={estilos.linha}>
        <Text style={estilos.titulo}>{titulo}</Text>
        <Text style={estilos.prioridade}>{prioridade}</Text>
      </View>
      <Text style={estilos.dica}>{concluida ? 'Toque para reabrir' : 'Toque para concluir, segure para remover'}</Text>
    </Pressable>
  );
}
```

**Os 3 bugs:**

1. `{pendentes} pendentes` solto na `View` do cabeçalho: derruba o app com `Text strings must be rendered within a <Text> component`. Correção: envolver em `Text`.
2. `tarefas.push({...})`: muta o array sem `setTarefas`; o React não redesenha. Silencioso: o `console.log` mostra o array crescendo e a tela parada. Correção: `setTarefas([...tarefas, nova])`.
3. `renderItem={(item) => ...}`: `renderItem` recebe `{ item, index, separators }`, então `item.titulo` é `undefined` e o cartão sai sem título. Silencioso. Correção: `renderItem={({ item }) => ...}`.
:::

**Entrega:** adicionar, concluir e remover funcionando; "Nenhuma tarefa" com a lista vazia; seção "E28: caça aos bugs" no `README.md` com sintoma, onde apareceu (tela vermelha ou terminal), causa e correção de cada bug; commit "E28: lista funcional e bugs". O aluno cola o link do repositório na entrega do laboratório E28 no sistema; você confere pelo README no GitHub.

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| Tela vermelha `Cannot read property 'value' of undefined` | `e.target.value` no `onChangeText` | O parâmetro já é a string: `onChangeText={setTexto}` |
| A tarefa só aparece ao salvar um arquivo | `push` muta o array; o Fast Refresh redesenha | `console.log` em `adicionarTarefa`; trocar por spread |
| Ao remover, outro cartão esmaece | `keyExtractor` pelo índice ou faltando | `keyExtractor={(item) => String(item.id)}` |
| Faixa amarela `VirtualizedLists should never be nested` | `FlatList` dentro de `ScrollView` | Tirar a `ScrollView`; usar `ListHeaderComponent` |
| `Can't find variable: Alert` | Falta no import de `react-native` | Completar o import; `useState` vem de `react` |
| Salva e nada muda no celular | Editando o `App.jsx` do projeto web, ou cache | Conferir a pasta no terminal; `r` e `npx expo start -c` |
| QR lê, mas "Something went wrong" | Dados móveis ou outra rede | Mesmo Wi-Fi; senão `npx expo start --tunnel` |
| A tecla `j` não abre nada | App desconectado, ou sem Chrome nem Edge | `r` no terminal e `j` de novo; ou Open JS debugger no menu do celular |
| O app parou de responder ao toque | Breakpoint ativo, com o app pausado | <kbd>F8</kbd> no DevTools e limpar os breakpoints da aba Sources |
