## Visão do encontro

**Objetivo:** dar estado, lista e remoção confirmada à tela estática do `minhas-tarefas-mobile`, ensinar a ler o que o Expo diz quando o app quebra e aplicar os dois no Projeto 5, etapa 3.

**Resultado:** app que adiciona, conclui e remove tarefas no celular do aluno, trata a lista vazia, e `README.md` com 3 bugs descritos. No `gota`, a etapa 3 começada em aula (registros com `useState` e os botões de copo somando) e terminada em casa: `FlatList`, remoção com `Alert`, meta validada e o bug do enunciado explicado no README, com o commit `Projeto 5: etapa 3, estado, lista e bug`.

**Slides de seção:** cada conceito abre com um slide que só tem o nome dele e uma pergunta de gancho, no centro ("FlatList", "Tela vermelha"). É a hora da conversa: faça a pergunta do gancho, ouça duas ou três respostas e explique com a analogia indicada abaixo. O slide seguinte, a âncora, ensina o mesmo conceito por escrito, para quem revisa em casa e estuda para as provas; em aula, passe por ele apontando o que acabou de dizer, sem ler tudo. Depois vem o "... na prática", com casos de uso. As analogias do encontro voltam no resto do curso: o placar, a campainha, o espelho, a cópia que não rasura o original, a esteira, a linha de produção, a luz vermelha e a amarela do painel do carro, o raio X, o filme que pausa, o jornal de ontem e a consulta médica.

**Pré-requisitos:** `minhas-tarefas-mobile` do E27 rodando no Expo Go (`SafeAreaView`, `CartaoTarefa`, `StyleSheet`); `useState` com eventos e formulário controlado (E23); spread, `map` e `filter` (E09); breakpoints no VS Code (E03).

:::example Solução de referência
`src/components/FormularioTarefa.js`:

```jsx
import { useState } from 'react';
import { Pressable, StyleSheet, Text, TextInput, View } from 'react-native';

export default function FormularioTarefa({ onAdicionar }) {
  const [texto, setTexto] = useState('');

  function adicionar() {
    if (texto.trim() === '') return;
    onAdicionar(texto.trim());
    setTexto('');
  }

  return (
    <View style={estilos.formulario}>
      <TextInput
        style={estilos.campo}
        placeholder="Nova tarefa"
        value={texto}
        onChangeText={setTexto}
      />
      <Pressable style={estilos.botao} onPress={adicionar}>
        <Text style={estilos.textoBotao}>Adicionar</Text>
      </Pressable>
    </View>
  );
}

const estilos = StyleSheet.create({
  formulario: { flexDirection: 'row', paddingHorizontal: 16, marginBottom: 12, gap: 8 },
  campo: { flex: 1, backgroundColor: '#ffffff', borderRadius: 8, paddingHorizontal: 12, paddingVertical: 10 },
  botao: { backgroundColor: '#0ea5e9', borderRadius: 8, paddingHorizontal: 16, justifyContent: 'center' },
  textoBotao: { color: '#ffffff', fontWeight: 'bold' },
});
```

`App.js`, estado e funções:

```jsx
import { useState } from 'react';
import { Alert, FlatList, StyleSheet, Text, View } from 'react-native';
import { SafeAreaProvider, SafeAreaView } from 'react-native-safe-area-context';
import CartaoTarefa from './src/components/CartaoTarefa';
import FormularioTarefa from './src/components/FormularioTarefa';

export default function App() {
  const [tarefas, setTarefas] = useState([]);
  const pendentes = tarefas.filter((t) => !t.concluida).length;

  function adicionarTarefa(titulo) {
    const nova = { id: Date.now(), titulo, prioridade: 'media', concluida: false };
    setTarefas([...tarefas, nova]);
  }

  function alternarConcluida(id) {
    setTarefas(tarefas.map((t) => (t.id === id ? { ...t, concluida: !t.concluida } : t)));
  }

  function removerTarefa(id) {
    setTarefas(tarefas.filter((t) => t.id !== id));
  }

  function confirmarRemocao(id) {
    Alert.alert('Remover?', 'Esta ação não pode ser desfeita', [
      { text: 'Cancelar' },
      { text: 'Remover', onPress: () => removerTarefa(id) },
    ]);
  }
  // o return vem no bloco seguinte
```

`App.js`, tela e estilos (`contentContainerStyle` dá a margem lateral da lista):

```jsx
  return (
    <SafeAreaProvider>

}
```

`src/components/CartaoTarefa.js`: a `View` raiz vira `Pressable`, o botão Concluir vira um `Text` de dica, os estilos ganham `concluida: { opacity: 0.5 }` e `dica: { fontSize: 12, color: '#64748b', marginTop: 8 }`, e o `marginBottom` do cartão sai.

```jsx
export default function CartaoTarefa({ titulo, prioridade, concluida, onAlternar, onRemover }) {
  return (
    <Pressable
      onPress={onAlternar}
      onLongPress={onRemover}
      style={[estilos.cartao, prioridade === 'alta' && estilos.alta, concluida && estilos.concluida]}
    >
      <View style={estilos.linha}>
        <Text style={estilos.titulo}>{titulo}</Text>
        <Text style={estilos.prioridade}>{prioridade}</Text>
      </View>
      <Text style={estilos.dica}>{concluida ? 'Toque para reabrir' : 'Toque para concluir, segure para remover'}</Text>
    </Pressable>
  );
}
```

**Os 3 bugs:**

1. `{pendentes} pendentes` solto na `View` do cabeçalho: derruba o app com `Text strings must be rendered within a <Text> component`. Correção: envolver em `Text`.
2. `tarefas.push({...})`: muta o array sem `setTarefas`; o React não redesenha. Silencioso: o `console.log` mostra o array crescendo e a tela parada. Correção: `setTarefas([...tarefas, nova])`.
3. `renderItem={(item) => ...}`: `renderItem` recebe `{ item, index, separators }`, então `item.titulo` é `undefined` e o cartão sai sem título. Silencioso. Correção: `renderItem={({ item }) => ...}`.
:::

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| Tela vermelha `Cannot read property 'value' of undefined` | `e.target.value` no `onChangeText` | O parâmetro já é a string: `onChangeText={setTexto}` |
| A tarefa só aparece ao salvar um arquivo | `push` muta o array; o Fast Refresh redesenha | `console.log` em `adicionarTarefa`; trocar por spread |
| Ao remover, outro cartão esmaece | `keyExtractor` pelo índice ou faltando | `keyExtractor={(item) => String(item.id)}` |
| Faixa amarela `VirtualizedLists should never be nested` | `FlatList` dentro de `ScrollView` | Tirar a `ScrollView`; usar `ListHeaderComponent` |
| `Property 'Alert' doesn't exist` (ou `Can't find variable: Alert`) | Falta no import de `react-native` | Completar o import; `useState` vem de `react` |
| Salva e nada muda no celular | Editando o `App.jsx` do projeto web, ou cache | Conferir a pasta no terminal; `r` e `npx expo start -c` |
| QR lê, mas "Something went wrong" | Dados móveis ou outra rede | Mesmo Wi-Fi; senão `npx expo start --tunnel` |
| A tecla `j` não abre nada | App desconectado, ou sem Chrome nem Edge | `r` no terminal e `j` de novo; ou Open JS debugger no menu do celular |
| O app parou de responder ao toque | Breakpoint ativo, com o app pausado | <kbd>F8</kbd> no DevTools e limpar os breakpoints da aba Sources |
| No `gota`, tela vermelha "Maximum update depth exceeded" ao abrir | `onPress={onAdicionar(ml)}` chama a função ao desenhar, e cada desenho adiciona um copo | `onPress={() => onAdicionar(ml)}` |
