## Visão do encontro

**Objetivo:** levar a turma da repetição de tags a um componente que recebe props e é gerado a partir de um array. No Projeto 4, o mesmo caminho no `livro-de-receitas`: a etapa 2 troca o cartão fixo por uma lista de receitas com props e CSS Modules.

**Slides de seção:** cada conceito vem em três slides. O primeiro, a seção, tem só o nome do conceito e uma frase de gancho, no centro ("A key" e "Num evento com cem pessoas, como a organização sabe quem é quem?"). É a hora da conversa: leia o gancho, ouça duas ou três respostas e explique com a analogia indicada abaixo. O segundo explica o que é e como usar, por escrito, para quem estuda para as provas; em aula, passe por ele apontando o que acabou de dizer. O terceiro, "... na prática", mostra casos de uso com o resultado: rode um deles ao vivo ou leia o resultado do slide. As analogias são as do curso inteiro: o componente é a peça de Lego, as props são o pedido feito à peça, a `key` é o crachá, o `map` é a linha de produção e o `filter`, a peneira. Duas são novas e ficam: o `children` é a foto dentro da moldura, e o CSS Module dá um sobrenome a cada classe.

**Resultado esperado:** o `minhas-tarefas` de cada aluno mostra 5 tarefas de um array, com `ListaTarefas`, `CartaoTarefa` em CSS Modules, `key` sem avisos e estado vazio, publicado no GitHub. A etapa 2 do Projeto 4 começa na aula e termina em casa, até o E23.

**Pré-requisitos (E21):** projeto `minhas-tarefas` rodando com `npm run dev`, `Cabecalho` e `Rodape` em `src/components`, as três regras do JSX, expressões entre chaves e o ciclo `add`, `commit`, `push`.

**O JavaScript já é da turma.** Tudo o que o encontro usa foi visto do E07 ao E13: arrow function e parâmetros padrão (E07b), arrays e objetos (E08), `map` e `filter` (E09a), desestruturação, rest e spread (E09b), `export default` (E11a), referência e `Object.freeze` (E11b), `&&` e truthy/falsy (E13a), ternário e guard clauses (E13b). Não reensine: cite o encontro e a analogia em uma frase ("é o `map` do E09, a linha de produção") e gaste o tempo no que é React. Se alguém travar, projete 30 segundos do slide de origem e volte.

**Materiais:** projetor, Wi-Fi (push e quiz), um computador por aluno com o projeto do E21, painel do instrutor com as entregas. Sem celulares.

## Bloco 1 · Componentes e props (50 min)

Ritual do dia: você digita, para antes de salvar e pergunta **"o que vai aparecer?"**. Duas respostas, salve, compare.

**"O que você vai aprender", "Palavras novas de hoje" e "Três cartões iguais, três textos diferentes" (3 min).** Leia as seis palavras, com um exemplo de cada. Cole no `App.jsx` as três `<div className="cartao">` do slide: "e se forem 50?".

**Seção "Componentes" (3 min).** Leia o gancho: uma peça de Lego que só vem numa cor serve para qualquer montagem? Esperado: serve, mas sai sempre igual. "O componente é a peça; hoje ela aprende a receber pedidos." Crie `src/components/CartaoTarefa.jsx` com texto fixo e use `<CartaoTarefa />` três vezes, como em "Componentes na prática": três "Estudar React". "Falta o que toda função do `lojinha-regras` tinha: parâmetros, o espaço do ingrediente na receita."

**Seção "Props" (17 min).** Leia o gancho: o mesmo cartão, três textos, como avisar a cada um o que mostrar? Esperado: passar o texto para ele, como o argumento de uma função. "Props são o pedido feito à peça: o pai diz como quer cada uma." A demonstração mais lenta do dia: é a parte que o JavaScript não ensinou.

:::steps
1. `function CartaoTarefa(props)` com `console.log(props)` antes do `return`. Salve: objetos vazios no console. Se aparecerem em dobro, é o `StrictMode` do `main.jsx`, que desenha duas vezes em desenvolvimento; não é erro.
2. No `App.jsx`, `<CartaoTarefa titulo="Estudar React" />` na primeira tag. Pergunte; salve: `{ titulo: 'Estudar React' }`.
3. Troque o `<h3>` fixo por `<h3>{props.titulo}</h3>`. "E nos outros dois?" Salve: `<h3>` vazio, sem erro. "Prop que não chega vale `undefined`, e o React não desenha `undefined`." Preencha as três tags e projete "Props na prática".
4. Troque `(props)` por `({ titulo, prioridade })` e apague os `props.`. "Mudou algo na tela?" Nada. Uma frase só: "é o `aplicarFiltros(lista, { categoria, ordem })` do E09". Remova o `console.log`.
:::

Em "Props de vários tipos": `pontos="10"` na tag e `<p>{pontos + 1} pontos</p>` no componente; a turma espera 11 e vê **101**, a concatenação do E05; corrija para `pontos={10}`. Escreva `concluida` sozinho numa tag e `console.log(concluida)` no componente: chega `true`.

**Seção "Valores padrão" (6 min).** Leia o gancho: num cadastro, que país já vem marcado quando vocês não escolhem nenhum? Esperado: o Brasil. "Valor padrão é isso: o que entra quando ninguém escolhe." Apague `prioridade` de uma tag, mostre o texto vazio e escreva `prioridade = 'media'` no parâmetro. Depois passe `prioridade={null}`: o padrão não entra. "O mesmo que o E07 mostrou: padrão só cobre `undefined`." Confira com a tabela de "Valores padrão na prática".

**Seção "children" (3 min).** Leia o gancho: numa loja de molduras, a moldura muda conforme a foto? Esperado: não; a mesma moldura serve para qualquer foto. "O `Card` é a moldura; o `children`, a foto." Leia "children: o que vai dentro da tag" e "children na prática", sem digitar.

**"Pense" (4 min).** Esperado: duas props, o texto por `children` e uma `variante` com padrão `'primario'`. Se ninguém responder: "o texto 'Salvar' é conteúdo ou configuração?". Revele a resposta do slide.

**Seção "Rest e spread" (5 min).** Leia o gancho: no E09, o que os três pontinhos faziam com um objeto? Esperado: copiavam e espalhavam; do lado esquerdo, juntavam o resto. Digite o `Botao` do slide com `console.log(resto)` e use `<Botao type="submit" disabled>Salvar</Botao>`. Pergunte antes de salvar: "o que fica no `resto`?" Salve: `{ type: 'submit', disabled: true }`. Na aba Elements, o `<button>` saiu com `type` e `disabled`. "O rest junta, o spread espalha: o `Botao` aceita qualquer atributo de botão sem você listar." Em "Rest e spread na prática", peça o `resto` das outras duas linhas antes de mostrar.

**Seção "Composição" (3 min).** Leia o gancho: como peças de Lego viram um carrinho inteiro? Esperado: encaixando umas nas outras. "Composição é encaixar componentes." Crie `src/components/ListaTarefas.jsx` com as três tags em uma `<section>` e use `<ListaTarefas />` entre `Cabecalho` e `Rodape`. Projete a animação de "Composição na prática": os dados descem pelas props.

**Seção "Somente leitura" (6 min).** Leia o gancho: receberam um documento original, vocês rasuram ou tiram uma cópia? Esperado: tiram uma cópia. "As props são o original: o componente lê; para outro valor, cria uma variável nova, a sua cópia." Volte ao `(props)`, digite `props.titulo = 'Outro'` e salve: tela em branco e `TypeError: Cannot assign to read only property 'titulo' of object`. "É o `Object.freeze` do E11: em desenvolvimento, o React congela as props." Desfaça e mostre "Somente leitura na prática". Feche com "Nomeação e organização" e "Quando aparece um erro".

:::tip Ritmo
Atrasou? Mostre `concluida` sozinho e `prioridade={null}` só pelas tabelas e leia "Nomeação e organização" sem digitar. Nunca corte o `console.log(props)` nem o `TypeError` das props congeladas: eles sustentam o laboratório e a questão do quiz.
:::

## Bloco 2 · Listas, keys e estilos (50 min)

**"O que você vai aprender", "Palavras novas de hoje" e "Uma tag por tarefa não escala" (3 min).** Leia as palavras. Leia a pergunta do terceiro slide. Esperado: o `map`. Se ninguém responder: "como vocês geravam as linhas do resumo do pedido no E09?"

**Seção "Listas com map" (8 min).** Leia o gancho: numa linha de produção, o que entra e o que sai? Esperado: entra a matéria-prima, sai o produto pronto, na mesma quantidade. "O `map` é a linha de produção: entra tarefa, sai cartão." Segunda demonstração lenta:

:::steps
1. Cole o array `tarefas` do slide no `App.jsx`, acima da função `App`, e passe `<ListaTarefas tarefas={tarefas} />`. No `ListaTarefas`, parâmetro `({ tarefas })`.
2. Apague as três tags e digite devagar `{tarefas.map((t) => (` e `))}` com `<CartaoTarefa titulo={t.titulo} prioridade={t.prioridade} concluida={t.concluida} />` dentro. "Quantos cartões?" Salve: três.
:::

Projete "Listas na prática": a animação repete o `map` volta a volta; aponte qual item do array vira qual cartão e use a última linha do slide para puxar o aviso de `key`.

**Seção "A key" (6 min).** Leia o gancho: num evento com cem pessoas, como a organização sabe quem é quem? Esperado: pelo crachá. "A `key` é o crachá de cada item: único, e o React reconhece cada um por ele."

:::steps
1. Leia o aviso em voz alta: `Each child in a list should have a unique "key" prop`. Adicione `key={t.id}`: o aviso some. Mova a `key` para a `<div>` de dentro do `CartaoTarefa` e salve: o aviso volta. Devolva a `key` ao `<CartaoTarefa>`.
2. Acrescente uma quarta tarefa ao array e salve: quatro cartões sem tocar no `ListaTarefas`. O momento de convencimento do dia.
:::

Em "Por que o id, e não o índice", comente o diagrama: removida a primeira tarefa, com `key={t.id}` as outras guardam a key e com `key={i}` todas mudam. "O índice é o lugar na fila, não o crachá." Regra: "`key` é o `id` do dado".

**Seção "Preparar os dados" (8 min).** Leia o gancho: para fazer um bolo, vocês peneiram a farinha antes ou depois de assar? Esperado: antes. "O `filter` é a peneira: os dados se preparam antes do `return`." Digite `pendentes`, `concluidas` e `ordenadas` antes do `return`, troque o `map` para `ordenadas` e acrescente `<p>Pendentes: {pendentes.length}</p>`, como em "Preparar os dados na prática". No array, marque a primeira tarefa como `concluida: true` e salve: ela desce e o contador muda, sem tocar no JSX. "É o contador do E21 que podia mentir: aqui ele sai dos mesmos dados." Lance o desafio do "Pratique" (2 min, no caderno ou no editor) e revele a resposta. Desfaça a ordenação: o laboratório usa a lista na ordem do array, e ordenar fica como desafio.

**Seção "Mostrar ou esconder" (8 min).** Leia o gancho: numa bifurcação da estrada, quem escolhe o caminho? Esperado: quem dirige, conforme o destino. "Na tela, a condição escolhe o caminho: mostrar, esconder ou trocar." Leia a tabela de "Renderização condicional". Adicione `{tarefas.length === 0 && <p>Nenhuma tarefa por aqui</p>}`, troque o array por `[]` no `App` e pergunte. Agora apague o `=== 0` e salve: um `0` solto na tela. "A armadilha do zero do E13, agora visível." Volte o `=== 0`. No `CartaoTarefa`, `<p>{concluida ? 'Concluída' : 'Pendente'}</p>`: só "Fazer compras" fica concluída. Do "Return antecipado", projete o código sem digitar: "a guard clause do E13, agora devolvendo JSX".

**Seção "Estilos" (4 min).** Leia o gancho: onde vocês guardam o estilo de um cartão, num arquivo da casa toda ou junto dele? Ouça duas respostas sem corrigir. Leia "Três formas de estilizar" e "Estilos na prática". "Pense": esperado, junto do componente, porque duas `.cartao` no CSS global colidem e o inline não aceita `:hover`. Se ninguém responder: "se dois arquivos CSS declaram `.cartao` com cores diferentes, qual vence?".

**Seção "CSS Modules" (5 min).** Leia o gancho: na turma há duas Anas, como vocês sabem de qual estão falando? Esperado: pelo sobrenome. "O CSS Module dá um sobrenome a cada classe." Crie `CartaoTarefa.module.css` com `cartao`, `alta` e `concluida`. No componente, `import estilos from './CartaoTarefa.module.css'` e `className={estilos.cartao}`. Na aba Elements, a classe real é `_cartao_p62cn_1`, como na tabela de "CSS Modules na prática: o componente"; o número do fim é a linha da classe no arquivo.

**Seção "Classes dinâmicas" (3 min).** Leia o gancho: como o cartão concluído sabe que precisa ficar riscado? Esperado: por uma condição sobre o `concluida`. Mostre `const classeAlta = prioridade === 'alta' ? estilos.alta : ''` e a template string na `className`, e leia a tabela de "Classes dinâmicas na prática".

**"Quando aparece um erro" a "No laboratório" (2 min).** Leia em voz alta e projete "No laboratório".

**Desafio (3 min):** "Sem escrever nenhuma tag nova, faça aparecer uma quinta tarefa com prioridade alta e borda vermelha. Depois troque o array por `[]`." Quem conseguir já começa o laboratório.

:::tip Ritmo
Reduza "Por que o id, e não o índice" à regra prática, mostre só a primeira forma da classe dinâmica e passe pelo "Return antecipado" só com a tabela da seção. Não corte o passo da quarta tarefa nem o `0` solto na tela.

:::example Solução de referência
`src/components/CartaoTarefa.jsx`:

```jsx
import estilos from './CartaoTarefa.module.css'

export default function CartaoTarefa({ titulo, prioridade = 'media', concluida = false }) {
  const classeAlta = prioridade === 'alta' ? estilos.alta : ''
  const classeConcluida = concluida ? estilos.concluida : ''

  return (
    <div className={`${estilos.cartao} ${classeAlta} ${classeConcluida}`}>
      <h3>{titulo}</h3>
      <p>Prioridade: {prioridade}</p>
      <p>{concluida ? 'Concluída' : 'Pendente'}</p>
    </div>
  )
}
```

`src/components/CartaoTarefa.module.css`:

```css
.cartao {
  border: 1px solid #ccc;
  border-radius: 8px;
  padding: 12px;
  margin-bottom: 8px;
}

.alta {
  border-left: 4px solid #d33;
}

.concluida {
  opacity: 0.6;
  text-decoration: line-through;
}
```

`src/components/ListaTarefas.jsx`:

```jsx
import CartaoTarefa from './CartaoTarefa.jsx'

export default function ListaTarefas({ tarefas }) {
  return (
    <section>
      {tarefas.length === 0 && <p>Nenhuma tarefa por aqui</p>}
      {tarefas.map((t) => (
        <CartaoTarefa
          key={t.id}
          titulo={t.titulo}
          prioridade={t.prioridade}
          concluida={t.concluida}
        />
      ))}
    </section>
  )
}
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `<h3>` vazio, sem erro | `titulo=` na tag e `props.title` dentro, ou `function CartaoTarefa(titulo)` sem chaves | `console.log(props)` e comparar com a tag |
| Aviso de `key` mesmo com `key` | a `key` foi na `<div>` do `CartaoTarefa`, não na tag que o `map` devolve | mover a `key` para o `<CartaoTarefa>` do `ListaTarefas` |
| Nada estiliza; `estilos.cartao` é `undefined` | arquivo salvo sem `.module`, ou caminho do `import` errado | renomear para `.module.css`; conferir o `./` |
| Um `0` acima da lista vazia | `{tarefas.length && ...}` | comparar com `=== 0` |
| `tarefas.map is not a function` | faltou `tarefas={tarefas}` no `ListaTarefas`, ou `tarefas="tarefas"` entre aspas | chaves, não aspas, na tag do `App.jsx` |
| "101 pontos" ou todas "Concluída" | número ou booleano entre aspas; `"false"` é uma string truthy | chaves em tudo que não é texto |
| Tela em branco e `Cannot assign to read only property` | atribuição a uma prop dentro do componente | variável nova com o valor derivado |
| `console.log(props)` aparece duas vezes | `StrictMode` do `main.jsx` desenha duas vezes em desenvolvimento | não é erro; deixe o `StrictMode` |
| `Missing script: dev` ou push recusado | terminal fora de `minhas-tarefas`; GitHub sem credencial neste computador | `cd minhas-tarefas`; autenticar pelo navegador quando o Git pedir |
| Projeto 4: tela em branco e "does not provide an export named 'default'" | `import receitas from './data/receitas.js'`, sem chaves | o arquivo exporta com nome: `import { receitas } from './data/receitas.js'` |
