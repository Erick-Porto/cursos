## Visão do encontro

**Objetivo:** apresentar classes à turma construindo a classe `Tarefa` do Projeto 3. A turma aprende a forma e os bolos (classe e instância, `class`, `new`), o `constructor` com a ficha de dados e o `??` do E17, o `this`, os métodos e o `get`, e escreve, junto com você, a `Tarefa` com `constructor`, `concluir()` e `get rotuloDaPrioridade`. Na Sua vez, cada um completa a classe com `get peso`, `situacao(hoje)` e `prazoEmTexto(hoje)`. Não há laboratório à parte: os passos do projeto são a prática do dia.

**Como a aula funciona:** cada conceito vem em três slides, como na aula 3. A seção (título e gancho) é a hora da conversa: leia o gancho, ouça duas ou três respostas e explique com a analogia indicada abaixo. O slide seguinte é a âncora, o que o aluno lê para revisar. Depois vem o "na prática": peça a saída de cada caso antes de mostrar. Os conceitos de método, `this` e `get` são mostrados primeiro num cofrinho (uma classe do dia a dia, fora do projeto) e depois aplicados à `Tarefa` nos slides **Projeto 3 · Passo K**: a turma faz junto com você, no próprio computador, e só segue quando o "Pronto quando" aparece na tela de todos. No fim, a **Sua vez** é feita sozinho, sem a solução no slide. Depois de cada tema há um slide **Exercícios** com 3 a 5 exercícios e as respostas. Em aula, faça o primeiro em voz alta com a turma; os outros ficam para a revisão em casa.

**Resultado ao fim das 4h:** cada aluno tem, no repositório `lista-de-tarefas`, o `src/modelos/Tarefa.js` com `export default class Tarefa`, o `constructor(dados)` (com `'media'`, `null` e `false` de quando não vêm), o `concluir()`, os gets `rotuloDaPrioridade` e `peso` e os métodos `situacao(hoje)` e `prazoEmTexto(hoje)`, que importam `pesoDaPrioridade`, `situacaoDoPrazo` e `textoDoPrazo` de `../regras/prazos.js`. O `src/modelos/Tarefa.test.js` tem 11 testes. `npm test` mostra `Tests: 42 passed, 42 total` e `Test Suites: 3 passed`. Na tela, as tarefas de demonstração são instâncias da classe do aluno: cada pendente tem o botão **Concluir**, que risca a tarefa e escreve "Concluída", e "O que a página usa" mostra a Etapa 2 em 6 de 6. O aviso amarelo passa a pedir a Etapa 3 (`TarefaRecorrente.js`); o formulário continua desligado. O commit é `Projeto 3: etapa 2, classe Tarefa`, seguido do `git push`.

**Pré-requisitos:** a etapa 1 pronta (E17): `src/regras/prazos.js` com `pesoDaPrioridade`, `situacaoDoPrazo`, `proximoPrazo` e `textoDoPrazo`, 31 testes verdes, e a tela com a Etapa 1 em 4 de 4. Do curso: objetos como ficha (E13), referência (E15), `export default` e `import` (E16), funções com parâmetro e `return` (E07), template string (E06), Jest com `test.each` (E08), `new Date(...)` (E12), e o `switch`, o retorno antecipado e o `??` do E17. A turma **não** viu classes, `this`, métodos próprios nem `get`. Métodos estáticos, setters, campos com `#` e protótipos ficam fora do curso: não cite.

**Materiais:** projetor com o VS Code e o terminal lado a lado, em fonte grande; quadro com duas cores; o seu `lista-de-tarefas` no fim da etapa 1; a página do Projeto 3 (página do curso, seção **Projetos**) e o guia de correção; quiz publicado.

## Projeto: sua vez (30 min)

**Enunciado:** o slide "Projeto 3 · Sua vez: peso, situação e prazo em texto". **Organização:** individual, cada um no próprio computador, sem olhar a tela do vizinho nos primeiros 15 minutos. Depois disso, quem travou pode pedir ajuda a um colega, que explica sem digitar por ele.

**Marcos:** 3:12, o `import` no topo e o `get peso` verde; 3:22, a `situacao(hoje)` com os dois testes; 3:32, o `prazoEmTexto(hoje)` e o botão Concluir na tela; 3:35, todos com a Etapa 2 em 6 de 6.

**O que observar:**

- `prazo` sem o `this.` dentro do método: `ReferenceError: prazo is not defined`. Pergunte: "de quem é esse prazo?"
- `get situacao(hoje)`: o Jest recusa com `A 'get' accessor must not have any formal parameters`. "O `get` não recebe nada; quem precisa do hoje é método"
- `luz.situacao()` sem o `HOJE` no teste: o kit avisa `diasAte precisa de hoje, um Date; chegou undefined. Você passou o hoje adiante?`
- `peso() { ... }` sem a palavra `get`: os testes com `luz.peso` falham com `Received: [Function peso]`, e a tela avisa "peso precisa ser um get"
- import com o caminho errado (`'./prazos.js'`): `Cannot find module './prazos.js'`. O `..` sobe de `modelos` para `src`
- o `switch` do `pesoDaPrioridade` copiado para dentro do `get peso`: funciona, mas a regra fica em dois lugares. Peça para chamar a função: se o peso mudar, muda num lugar só
- `'Concluida'` sem acento no `prazoEmTexto`, ou `'Concluída'` com acento na `situacao`: o teste e a tela comparam letra por letra

Pergunta para quem travou: "o que a tarefa responde se estiver concluída? E se não estiver, qual função da etapa 1 já sabe a resposta?"

Variações que valem: o ternário do E10 (`return this.concluida ? 'concluida' : situacaoDoPrazo(this.prazo, hoje);`); `if`/`else` no lugar do retorno antecipado; outros nomes de teste e outras tarefas nos testes, desde que os resultados sejam os da tabela.

:::example Solução de referência
`src/modelos/Tarefa.js` no fim da etapa 2:

```javascript
import { pesoDaPrioridade, situacaoDoPrazo, textoDoPrazo } from '../regras/prazos.js';

// Etapa 2 (E18). A forma de todas as tarefas da lista.
export default class Tarefa {
  constructor(dados) {
    this.titulo = dados.titulo;
    this.prioridade = dados.prioridade ?? 'media';
    this.prazo = dados.prazo ?? null;
    this.concluida = dados.concluida ?? false;
  }

  concluir() {
    this.concluida = true;
  }

  get rotuloDaPrioridade() {
    switch (this.prioridade) {
      case 'alta':
        return 'Alta';
      case 'media':
        return 'Média';
      case 'baixa':
        return 'Baixa';
      default:
        return 'Sem prioridade';
    }
  }

  get peso() {
    return pesoDaPrioridade(this.prioridade);
  }

  situacao(hoje) {
    if (this.concluida) {
      return 'concluida';
    }
    return situacaoDoPrazo(this.prazo, hoje);
  }

  prazoEmTexto(hoje) {
    if (this.concluida) {
      return 'Concluída';
    }
    return textoDoPrazo(this.prazo, hoje);
  }
}
```

`src/modelos/Tarefa.test.js` no fim da etapa 2 (os quatro primeiros testes são os dos passos; os cinco últimos, a Sua vez, com o `HOJE` logo abaixo do `import`):

```javascript
import Tarefa from './Tarefa.js';

const HOJE = new Date(2026, 10, 10); // 10 de novembro de 2026 (o mês começa em 0)

test('a tarefa guarda o que recebeu', () => {
  const luz = new Tarefa({
    titulo: 'Pagar a conta de luz',
    prioridade: 'alta',
    prazo: '2026-11-12',
  });
  expect(luz.titulo).toBe('Pagar a conta de luz');
  expect(luz.prioridade).toBe('alta');
  expect(luz.prazo).toBe('2026-11-12');
  expect(luz.concluida).toBe(false);
});

test('sem prioridade nem prazo, a tarefa é média, sem prazo e pendente', () => {
  const racao = new Tarefa({ titulo: 'Comprar ração do gato' });
  expect(racao.prioridade).toBe('media');
  expect(racao.prazo).toBe(null);
  expect(racao.concluida).toBe(false);
});

test('concluir marca a tarefa como concluída', () => {
  const regar = new Tarefa({ titulo: 'Regar as plantas' });
  regar.concluir();
  expect(regar.concluida).toBe(true);
});

test.each([
  ['alta', 'Alta'],
  ['media', 'Média'],
  ['baixa', 'Baixa'],
])('o rótulo da prioridade %s é %s', (prioridade, rotulo) => {
  const prova = new Tarefa({ titulo: 'Estudar para a prova', prioridade: prioridade });
  expect(prova.rotuloDaPrioridade).toBe(rotulo);
});

test('o peso vem da prioridade', () => {
  const luz = new Tarefa({ titulo: 'Pagar a conta de luz', prioridade: 'alta' });
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `TypeError: Class constructor Tarefa cannot be invoked without 'new'` | `Tarefa({ ... })` sem o `new` | Ler a mensagem em voz alta: ela diz o que falta |
| `TypeError: _Tarefa.default is not a constructor` (Jest) | `class Tarefa` sem `export`, ou `export class` sem o `default` | `export default class Tarefa`; o `import` fica sem chaves |
| `Expected: "Pagar a conta de luz"`, `Received: undefined` em todos os campos | `constructor` escrito errado (`contructor`, `Constructor`): vira um método comum, que ninguém chama | Conferir a grafia letra por letra, lado a lado com o slide |
| `Cannot read properties of undefined (reading 'titulo')` | `new Tarefa()` sem a ficha | `new Tarefa({ titulo: '...' })` |
| Teste do `concluir` vermelho com `Expected: true`, `Received: false`; na tela, "concluida is not defined" | `concluida = true` sem o `this.` (no Jest não aparece o `ReferenceError`; no navegador, sim) | `this.concluida = true;`: "de quem é esse campo?" |
| `Jest encountered an unexpected token` e, nos detalhes, `Unexpected token (linha:coluna)` | vírgula entre os métodos, ou `function` antes do nome do método | Ir na linha e na coluna da mensagem: entre métodos não há vírgula, e o método não leva `function` |
| `Jest encountered an unexpected token` e, nos detalhes, `Missing semicolon (linha:coluna)` | o método ou o `get` foi colado depois da última chave, fora da classe | Mover para antes da chave que fecha a classe; o Formatar Documento do E07 mostra o recuo certo |
| `TypeError: prova.rotuloDaPrioridade is not a function` | o `get` foi lido com parênteses | `prova.rotuloDaPrioridade`, sem `()` |
| `Received: [Function situacao]` | o método foi lido sem parênteses | `luz.situacao(HOJE)` |
| `ReferenceError: situacaoDoPrazo is not defined` | o método chama a função sem o `import` | `import { pesoDaPrioridade, situacaoDoPrazo, textoDoPrazo } from '../regras/prazos.js';` no topo |
| a tela diz "Failed to fetch dynamically imported module" | um `import` sem o `.js` (o Jest aceita, o navegador não) | `'../regras/prazos.js'`, com o `.js` |
| Testes verdes, mas a tela não mostra o botão Concluir | falta um dos 6 itens (a tela só usa a classe completa), ou a página não foi recarregada | Ler "O que a página usa": o primeiro item sem verde é o que falta |
