## Visão do encontro

**Objetivo:** ensinar a repetir, com o `for...of`, o acumulador, o `for` com índice e o `push`, construindo as duas últimas regras de conta do Racha-conta: `somarItens`, que soma a conta já em centavos, e `dividirConta`, que reparte o total em partes que sempre fecham. Os passos do projeto são a prática do dia; a Sua vez são os testes da divisão.

**Como a aula funciona:** cada conceito vem em três slides, como na aula 3. A seção (título e gancho) é a hora da conversa: leia o gancho, ouça duas ou três respostas e explique com a analogia indicada abaixo. O slide seguinte é a âncora, o que o aluno lê para revisar. Todo laço tem a sua tabela volta por volta: monte no quadro com a turma **antes** de mostrar a do slide. Depois do conceito vem um slide **Projeto 1 · Passo K**: a turma faz junto com você, no próprio computador, e só segue quando o "Pronto quando" aparece em todas as telas.

**Resultado ao fim das 4h:** cada aluno tem o `racha-conta` no fim da etapa 8. O `src/regras/conta.js` tem sete funções (as cinco do E10, mais `somarItens` e `dividirConta`), sem `console.log`. O `src/regras/conta.test.js` tem 41 testes verdes. O `src/scripts/racha.js` importa `calcularGorjeta`, `formatarReais`, `lerValor`, `lerPessoas`, `somarItens` e `dividirConta`; o subtotal nasce do `somarItens`; no `else`, um `for` escreve `Pessoa 1: R$ 51,57` e três `R$ 51,56` no lugar de "Por pessoa" e "Centavos que sobram". O commit `Projeto 1: etapa 8, somar e dividir` está no GitHub.

**Pré-requisitos:** aula 3 (`filter`, `reduce` com a tabela volta por volta, `if`, `let`), E04 a E10: o Racha-conta com `npm run racha`, Git e GitHub, centavos, `Math.floor` e `%` (Sua vez do E06), funções com `export`, Jest com `test.each`, métodos de texto, `if`/`else`/`else if`, `null` e `return` antecipado. A turma **não** viu laços, `i++`, `push`, `toEqual` (só citado no E08) nem o `%j`. O `join` fica para o E12, e o `while` para o E17.

**Materiais:** projetor com o VS Code em fonte grande, quadro (as tabelas volta por volta), Wi-Fi para o `git push`, a página do Projeto 1 aberta, quiz publicado. Fora do git, na sua máquina: `privado/projetos/projeto-1/etapa-7/` (o início de hoje), `etapa-8-juntos/` (depois dos três passos) e `etapa-8/` (depois da Sua vez).

## Projeto: sua vez (30 min)

**Enunciado:** o slide "Projeto 1 · Sua vez: os testes da divisão". No `conta.test.js`, `dividirConta` no `import`, um `test.each` com as cinco linhas da tabela (com `toEqual` e o `%j` no nome) e um teste que soma as partes de `dividirConta(20625, 4)` com um `for...of` e confere que dá `20625`.

**Organização:** individual, cada um no próprio computador, sem olhar a tela do vizinho nos primeiros 15 minutos. Depois, quem travou pode pedir ajuda a um colega, que explica sem digitar por ele.

**Marcos:** 3:15, o `test.each` com as cinco linhas verde (40 testes); 3:25, o teste da soma verde (41); 3:30, para quem terminou: troque no `conta.js` o `<` por `<=`, rode, leia o vermelho e volte; 3:35, `treino.js` apagado, commit e `git push`.

**O que observar:**

- `toBe` no lugar do `toEqual`: os cinco falham com `serializes to the same string`
- a lista desmontada na linha, `[10000, 3, 3334, 3333, 3333]`: o `esperado` vira `3334`, e o Jest mostra `Expected: 3334` e a lista inteira em `Received`
- `%i` no lugar do `%j`: os testes passam, mas o nome mostra só o primeiro número (`dividirConta(10000, 3) dá 3334`). Peça o `%j`: o nome do teste precisa dizer o que ele confere
- `dividirConta` fora do `import`: `ReferenceError: dividirConta is not defined`
- o acumulador dentro do `for` no teste da soma (`soma is not defined`), ou a soma com `reduce`. O `reduce` funciona; peça o `for...of`, que é o laço do dia
- quem escreveu `const soma = 0`: `TypeError: Assignment to constant variable.`

Pergunta para quem travou: "quantas colunas tem cada linha da tabela? O que entra em `total`, em `pessoas` e em `esperado`?". Para o teste da soma: "como o `somarItens` somava os itens?".

As duas funções novas do `src/regras/conta.js`, no fim do arquivo:

```javascript
export function somarItens(itens) {
  let soma = 0;
  for (const item of itens) {
    soma = soma + paraCentavos(item.preco) * item.quantidade;
  }
  return soma;
}

export function dividirConta(total, pessoas) {
  const parte = Math.floor(total / pessoas);
  const sobra = total % pessoas;
  const partes = [];
  for (let i = 0; i < pessoas; i++) {
    if (i < sobra) {
      partes.push(parte + 1);
    } else {
      partes.push(parte);
    }
  }
  return partes;
}
```

O `src/scripts/racha.js` inteiro, no fim do passo 3:

```javascript
import fs from 'node:fs';
import pc from 'picocolors';
import {
  calcularGorjeta,
  formatarReais,
  lerValor,
  lerPessoas,
  somarItens,
  dividirConta,
} from '../regras/conta.js';

const texto = fs.readFileSync('src/data/conta.json', 'utf-8');
const conta = JSON.parse(texto);
const unidades = conta.itens.reduce((total, item) => total + item.quantidade, 0);
const caros = conta.itens.filter((item) => item.preco > 50);

let subtotalCentavos = somarItens(conta.itens);
if (process.argv[2]) {
  subtotalCentavos = lerValor(process.argv[2]);
}
let pessoas = conta.pessoas;
if (process.argv[3]) {
  pessoas = lerPessoas(process.argv[3]);
}

if (subtotalCentavos === null) {
  console.log(`Valor inválido: "${process.argv[2]}". Digite como 187,50 ou "R$ 187,50".`);
} else if (pessoas === null) {
  console.log(`Número de pessoas inválido: "${process.argv[3]}". Digite um número inteiro de 1 a 50.`);
} else {
  const gorjetaCentavos = calcularGorjeta(subtotalCentavos, conta.gorjeta);
  const totalCentavos = subtotalCentavos + gorjetaCentavos;
  const partes = dividirConta(totalCentavos, pessoas);

  console.log(pc.bold('Racha-conta:'), conta.restaurante);
  console.log('Pessoas na mesa:', pessoas);
  console.log('Itens na conta:', conta.itens.length);
  console.table(conta.itens);
  console.log('Unidades pedidas:', unidades);
  console.log('Itens acima de R$ 50:', caros.length);
  console.log(`Subtotal: ${formatarReais(subtotalCentavos)}`);
  console.log(`Gorjeta (${conta.gorjeta}%): ${formatarReais(gorjetaCentavos)}`);
  console.log(`Total: ${formatarReais(totalCentavos)}`);
  for (let i = 0; i < partes.length; i++) {
    console.log(`Pessoa ${i + 1}: ${formatarReais(partes[i])}`);
  }
}
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `TypeError: Assignment to constant variable.` apontando para o `for` | `for (const i = 0; ...)`: o `i++` tenta mudar uma `const` | `let i = 0`; lembrar a caixa lacrada e a que deixa trocar |
| `Received: 7290` no teste da conta e `Received: undefined` no da lista vazia | o `return soma;` dentro das chaves do `for` | Formatar Documento: o recuo mostra que o `return` está dentro; levar para depois da `}` |
| `Received: NaN` no `somarItens` | `for (const item in itens)`, com `in`: o `item` vira a posição (`'0'`, `'1'`), sem `preco` | trocar `in` por `of`; um `console.log(item)` dentro do laço mostra o que chega |
| `somarItens` dá `187.5` | somou os preços em reais, sem o `paraCentavos` | `paraCentavos(item.preco) * item.quantidade` |
| `dividirConta(11000, 3)` dá `[3668, 3666, 3666]` | a sobra toda na primeira pessoa (`if (i === 0)` com `parte + sobra`) | montar a tabela volta por volta no papel: um centavo para cada uma das primeiras, com `i < sobra` e `parte + 1` |
| `Pessoa 5: R$ NaN`, ou uma parte a mais no Jest | `<=` na condição do `for` | `<`: as gavetas vão do 0 a `length - 1` |
| o terminal enche de `Pessoa 1: R$ 51,57`, ou `RangeError: Invalid array length` depois de uns segundos | laço sem fim: faltou o `i++` (no `racha.js` ou no `dividirConta`) | <kbd>Ctrl</kbd> + <kbd>C</kbd> e conferir as três partes do `for` |
| `ReferenceError: subtotal is not defined` ou `paraCentavos is not defined` no `npm run racha` | passo 3 pela metade: saiu o `reduce` ou o `import`, mas a linha antiga do `subtotalCentavos` ficou | `let subtotalCentavos = somarItens(conta.itens);` |
