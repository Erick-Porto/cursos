**Seção "memoize" (11 min).** Pergunte, com o gancho: "alguém pergunta a mesma conta duas vezes. Vocês calculam de novo ou olham a anotação?". Esperado: olham a anotação. Rode `memoize.mjs`, em que o `calcularFrete` imprime "calculando" toda vez que roda de verdade:

```plaintext

9.9
9.9
  calculando 80 20040020
19.9
--- memoize criado a cada chamada

  calculando 80 01001000
```

Três chamadas, dois "calculando": a segunda veio do cache. A parte de baixo é o erro comum do `memoize` criado dentro de uma função: cache novo a cada chamada, nada lembrado. :::example Solução de referência
`src/utils/funcoes.js`:

```javascript
export function memoize(fn) {
  const cache = {}; // um por função memoizada
  return (...args) => {
    const chave = JSON.stringify(args); // [80,"01001000"]
    if (chave in cache) return cache[chave];
    const resultado = fn(...args);
    cache[chave] = resultado;
    return resultado;
  };
}

export function debounce(fn, espera = 300) {
  let temporizador; // guardado na closure
  return (...args) => {
    clearTimeout(temporizador);
    temporizador = setTimeout(() => fn(...args), espera);
  };
}
```

`src/utils/funcoes.test.js`:

```javascript
import { memoize } from './funcoes.js';

describe('memoize', () => {
  test('roda a original uma vez para os mesmos argumentos', () => {
    const freteFalso = jest.fn(() => 9.9);
    const comCache = memoize(freteFalso);
    expect(comCache(80, '01001000')).toBe(9.9);
    expect(comCache(80, '01001000')).toBe(9.9);
    expect(freteFalso).toHaveBeenCalledTimes(1);
  });

  test('argumentos diferentes calculam de novo', () => {
    const freteFalso = jest.fn(() => 9.9);
    const comCache = memoize(freteFalso);
    comCache(80, '01001000');
    comCache(80, '20040020');
    comCache(120, '01001000');
    expect(freteFalso).toHaveBeenCalledTimes(3);
  });

  test('guarda também o 0 do frete grátis', () => {
    const freteFalso = jest.fn(() => 0);
    const comCache = memoize(freteFalso);
    comCache(200, '01001000');
    expect(comCache(200, '01001000')).toBe(0);
    expect(freteFalso).toHaveBeenCalledTimes(1);
  });

  test('repassa os argumentos para a original', () => {
    const freteFalso = jest.fn(() => 9.9);
    memoize(freteFalso)(80, '01001000');
    expect(freteFalso).toHaveBeenCalledWith(80, '01001000');
  });
});
```

```javascript
export const FRETE_GRATIS_A_PARTIR_DE = 150;

// versão simples: o E13 acrescenta a validação do CEP e a tabela por região
export function calcularFrete(subtotal, cep) {
  if (subtotal >= FRETE_GRATIS_A_PARTIR_DE) {
    return 0;
  }
  if (cep[0] === '0' || cep[0] === '1') {
    return 9.9; // CEP de São Paulo
  }
  return 19.9; // resto do país
}

export const calcularFreteComCache = memoize(calcularFrete);
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |

| `TypeError: undefined is not a function` no `filter` | `daCategoria` sem `return` | Perguntar o que `daCategoria('audio')` devolve; `console.log` dela mostra `undefined` |
