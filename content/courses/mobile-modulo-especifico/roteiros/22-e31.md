## Visão do encontro

**Objetivo:** tirar da tela os `if` de forma de pagamento com herança e polimorfismo, proteger as regras do cartão com campos `#` e separar "é um" (herança) de "tem um" (composição) no `Pedido`.

**Resultado ao fim das 4h:** as quatro classes de `src/modelos/pagamentos/` com 8 testes; o `Pedido` com `#status`, `entrega`, `pagamento` e `total` delegado, com 5 testes; o Checkout aberto pelo Carrinho, recalculando o total a cada escolha.

**Pré-requisitos:** `lojinha` do E30 com `npm test` verde: `precos.js` (E25), `frete.js` e o CEP no Carrinho (E26), `carrinho.js` (E27), `Produto` e `Pedido` com `_status` e `paraJSON` (E30). Nenhum pacote novo.

**A regra do cartão:** até 6x, sem juros; de 7x a 12x, total = valor × 1,0199 elevado ao número de parcelas, arredondado ao centavo (juros compostos de 1,99% ao mês, uma simplificação da Tabela Price). A parcela sai do `parcelar` do E25. R$ 199,90 em 7x: R$ 229,46, parcela de R$ 32,78.

**Materiais:** projetor com editor e terminal lado a lado, celular espelhado, quadro com duas cores, calculadora, branch `e31-solucao` e quiz publicado.

## Abertura (15 min)

Retomada (5 min):

1. "Por que a instância de `Pedido` não vai para o `useState`?" Esperado: o estado guarda dados simples (o `paraJSON`); mudar a instância não avisa o React, e a classe é recriada a cada renderização.
2. "O que acontece com `new Pedido({ status: 'aprovado' })`?" Esperado: o setter lança "Status inválido", já no `constructor`.
3. "Qual a diferença entre `Produto.deJSON(obj)` e `produto.precoFormatado`?" Esperado: o primeiro é estático, chamado na classe; o segundo é um getter da instância, lido sem parênteses. Gancho: "O `_status` do E30 é só um combinado. Hoje ele vira regra da linguagem."

```javascript
import Pagamento from './Pagamento';

const DIAS_UTEIS = 3;

export default class PagamentoBoleto extends Pagamento {
  constructor() {
    super('boleto', 'Boleto');
  }

  vencimento(hoje = new Date()) {
    const data = new Date(hoje); // cópia: não altera a data recebida
    let faltam = DIAS_UTEIS;
    while (faltam > 0) {
      data.setDate(data.getDate() + 1);
      const dia = data.getDay(); // 0 = domingo, 6 = sábado
      if (dia !== 0 && dia !== 6) faltam--;
    }
    return data;
  }
}
```

`src/modelos/pagamentos/PagamentoCartao.js`, primeira parte:

```javascript
import { paraCentavos, paraReais, parcelar } from '../../regras/precos';
import Pagamento from './Pagamento';

const TAXA_MENSAL = 0.0199; // 1,99% ao mês, juros compostos
const LIMITE_SEM_JUROS = 6;
const MAXIMO_DE_PARCELAS = 12;

export default class PagamentoCartao extends Pagamento {
  #parcelas;

  constructor(parcelas = 1) {
    super('cartao', 'Cartão');
    if (!Number.isInteger(parcelas) || parcelas < 1 || parcelas > MAXIMO_DE_PARCELAS) {
      throw new Error(`Parcelas devem ser de 1 a ${MAXIMO_DE_PARCELAS}`);
    }
    this.#parcelas = parcelas;
  }

  get parcelas() {
    return this.#parcelas;
  }

  get temJuros() {
    return this.#parcelas > LIMITE_SEM_JUROS;
  }
  // descricao, totalAPagar e valorDaParcela no bloco seguinte
```

`src/modelos/pagamentos/PagamentoCartao.js`, segunda parte:

```javascript
  get descricao() {
    const juros = this.temJuros ? 'com juros' : 'sem juros';
    return `${super.descricao} em ${this.#parcelas}x ${juros}`;
  }

  totalAPagar(valor) {
    if (!this.temJuros) return super.totalAPagar(valor);
    const comJuros = paraCentavos(valor) * (1 + TAXA_MENSAL) ** this.#parcelas;
    return paraReais(Math.round(comJuros));
  }

  valorDaParcela(valor) {
    return parcelar(this.totalAPagar(valor), this.#parcelas).valor;
  }
}
```

`src/modelos/Pedido.js`, primeira parte (o `_status` vira `#status`, o `frete` vira `entrega` e entra o `pagamento`):

```javascript
import { contarItens, subtotal as somarItens } from '../regras/carrinho';
import { paraCentavos, paraReais } from '../regras/precos';
import { formatarPreco } from '../utils/formatar';

const STATUS = ['pendente', 'pago', 'enviado', 'entregue', 'cancelado'];

export default class Pedido {
  #status;

  constructor({ id, itens = [], status = 'pendente', entrega = null, desconto = 0, pagamento = null } = {}) {
    this.id = id;
    this.itens = itens; // [{ ...produto, qtd }]
    this.status = status; // passa pelo setter
    this.entrega = entrega; // { cep, frete } ou null
    this.desconto = desconto;
    this.pagamento = pagamento; // qualquer filha de Pagamento, ou null
  }

  get status() {
    return this.#status;
  }

  set status(valor) {
    if (!STATUS.includes(valor)) {
      throw new Error(`Status inválido: ${valor}`);
    }
    this.#status = valor;
  }

  get quantidade() {
    return contarItens(this.itens);
  }

  get subtotal() {
    return somarItens(this.itens);
  }
  // frete, valorDaCompra, total e os métodos no bloco seguinte
```

`src/modelos/Pedido.js`, segunda parte:

```javascript
  get frete() {
    return this.entrega?.frete ?? 0;
  }

  get valorDaCompra() {
    // o total do E30, com outro nome: em centavos e nunca negativo
    const centavos = paraCentavos(this.subtotal) + paraCentavos(this.frete) - paraCentavos(this.desconto);
    return paraReais(Math.max(centavos, 0));
  }

  get total() {
    if (!this.pagamento) return this.valorDaCompra;
    return this.pagamento.totalAPagar(this.valorDaCompra);
  }

  paraJSON() {
    const { id, itens, status, entrega, desconto } = this;
    return { id, itens, status, entrega, desconto }; // só dados: o pagamento vai à parte
  }

  comStatus(novo) {
    return new Pedido({ ...this.paraJSON(), pagamento: this.pagamento, status: novo });
  }

  comPagamento(pagamento) {
    return new Pedido({ ...this.paraJSON(), pagamento });
  }

  toString() {
    return `Pedido ${this.id}, ${this.status}, ${formatarPreco(this.total)}`;
  }
}
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| Teste do Pix recebe `199.9` | Nome diferente na filha (`totalApagar`) | Comparar letra a letra com o da mãe |
| `ReferenceError` ao criar a filha | `this` antes do `super(...)` no `constructor` | `super` na primeira linha do `constructor` |
| Erro de compilação citando `#parcelas` ou `#nome` | Campo não declarado, ou filha lendo o `#` da mãe | Declarar `#parcelas;` no topo; na filha, usar o getter |
| `Maximum call stack size exceeded` ao ler `parcelas` | Getter devolvendo `this.parcelas` | Devolver `this.#parcelas` |
| `TypeError` ao tocar numa parcela | `onPress` fazendo `cartao.parcelas = n` | `setParcelas(n)` e o cartão criado a partir do estado |
| Total não muda ao trocar a parcela | `formas` fora do componente ou instância no `useState` | Criar as instâncias no corpo do componente |
| Testes do E30 quebram com `frete` | O `constructor` agora recebe `entrega` | Trocar `frete: 19.9` por `entrega: { cep: '01310-100', frete: 19.9 }` |
| Pedido pago volta a pendente após `comPagamento` | `{ ...this }` no lugar de `paraJSON()`: o `#status` não é copiado | Usar `{ ...this.paraJSON(), pagamento }` |
