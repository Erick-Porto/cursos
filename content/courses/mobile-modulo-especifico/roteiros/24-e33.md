## Visão do encontro

**Objetivo:** abrir a unidade Linguagem JavaScript com os textos, números e datas de toda tela de compra: regex para CEP e CPF, `Intl` para preço e data, `Date` para o prazo em dias úteis, tudo testado com datas fixas.

**Resultado ao fim das 4h:** o Detalhe mostra "Chega até" com a data de hoje mais 5 dias úteis, como "qui., 16 de out."; o Checkout formata CEP e CPF digitados ou colados; os testes passam em qualquer dia; o CI segue verde.

**Pré-requisitos:** Lojinha do E32 com o checkout completo, 20 testes ou mais, script `verificar` e workflow do E24, `formatarPreco` em `src/utils/formatar.ts` (E23) e `mascararTelefone` em `src/utils/mascaras.js` (E15).

**Materiais:** projetor espelhando celular e terminal, quadro, solução de referência na branch `e33-solucao`, quiz publicado. Nenhum pacote novo hoje.

## Bloco 1 · Strings e expressões regulares (50 min)

**"O que você vai aprender" e "O texto do usuário chega sujo" (4 min).** Leia a pergunta sem responder: ela volta no slide do `test`. Três alunos ditam o próprio CEP; escreva no quadro como cada um ditou.

**"Strings: imutáveis e indexadas" e "Limpar e comparar" (8 min).** No REPL do Node (E21):

:::steps
1. `node` no terminal; `const nome = 'Fone Bluetooth'` e `nome.toUpperCase()`: sai em maiúsculas.
2. `nome` de novo. Pergunte: "por que não mudou?". Esperado: o método devolve uma string nova.
3. `'  Maria@Email.com '.trim().toLowerCase()`, montado um método por vez.
4. `nome.includes('blue')` dá `false`; com `toLowerCase()` antes, `true`. Pergunte onde a Lojinha já faz isso. Esperado: no `buscarProdutos` do E27.

**"Recortar" e "Montar" (7 min).** No REPL, `'Maria Souza'.split(' ')` e depois `[0]`. Mostre o `split` de um nome com espaço duplo e sem `trim`: surgem textos vazios no array. Monte o número do pedido com `padStart` e pergunte o que ele faz com `123456`. Esperado: nada, já passa de 5 caracteres.

**"Pense" (5 min).** Individual. Esperado: `' frete10 '`, `'FRETE10'`, `'Paula'` e `'07:30'`. Quem errou o primeiro não entendeu a imutabilidade: volte ao passo 2.

**"Expressão regular" e "test" (9 min).** Construa a regex do CEP no REPL, uma peça por vez:

:::steps
1. `/\d{5}/` testado com `'01310'` dá `true`, e com `'CEP 01310-100'` também. Pergunte por quê.
2. Com `^` e `$`, o texto com `CEP ` falha.
3. Chegue em `/^\d{5}-?\d{3}$/` e teste os CEPs ditados e um com espaço na frente, que falha: "quem limpa isso antes?". Esperado: `trim` ou `replace`.
4. Volte à pergunta do slide 3. Esperado: limpar e conferir com hífen opcional; `0131-0100` não tem cinco dígitos antes do hífen.
:::

No `:::tip`, mostre que `000.000.000-00` passa na regex do CPF.

**"replace com regex" a "CPF" (8 min).** No REPL, o `replace('.', '')` do CPF e depois com `/\D/g`. Projete o `mascararTelefone` do E15: a primeira linha é a mesma. No `match` do CEP, o Node mostra também `index`, `input` e `groups`; por ora, só interessam as posições 0, 1 e 2. Com `'0131'`, mostre o `null` e o `TypeError` de ler `[1]`: no app, seria a tela vermelha.

**"Pratique" (5 min).** Individual. Esperado: a resposta do slide. Quem juntar com `slice` e `'-'` mostra `01310-` com cinco dígitos: peça para testar com `'01310'`. A função entra no laboratório.

**"Remover acentos" a "Próximos passos" (4 min).** No celular espelhado, busque no Início um produto com acento, digitando sem acento: o `buscarProdutos` do E27 encontra. Vale o motor do celular, não o Node. "Erros comuns" e "Resumo" em leitura rápida.

:::tip Ritmo
Se atrasar, fale o "Recortar" sem o espaço duplo. A regex peça por peça e o `null` do `match` não se cortam: são os erros mais comuns no laboratório.

:::example Solução de referência
`src/utils/datas.js`:

```javascript
export function ehDiaUtil(data) {
  const dia = data.getDay(); // 0 = domingo, 6 = sábado
  return dia !== 0 && dia !== 6;
}

export function preverEntrega(diasUteis, hoje = new Date()) {
  // cópia à meia-noite: não altera hoje e ignora a hora do pedido
  const data = new Date(hoje.getFullYear(), hoje.getMonth(), hoje.getDate());
  let contados = 0;
  while (contados < diasUteis) {
    data.setDate(data.getDate() + 1);
    if (ehDiaUtil(data)) contados++;
  }
  return data;
}

const formatoCurto = new Intl.DateTimeFormat('pt-BR', {
  weekday: 'short',
  day: 'numeric',
  month: 'short',
});

export function formatarData(data) {
  return formatoCurto.format(data);
}
```

const QUINTA = new Date(2025, 9, 9); // quinta, 9 de outubro de 2025

describe('preverEntrega', () => {
  test('5 dias úteis a partir de quinta chegam na quinta seguinte', () => {
    expect(preverEntrega(5, QUINTA)).toEqual(new Date(2025, 9, 16));
  });
  test('pedido na sexta pula o fim de semana', () => {
    expect(preverEntrega(1, new Date(2025, 9, 10))).toEqual(new Date(2025, 9, 13));
  });
  test('pedido no sábado conta a partir de segunda', () => {
    expect(preverEntrega(1, new Date(2025, 9, 11))).toEqual(new Date(2025, 9, 13));
  });
  test('vira o mês', () => {
    expect(preverEntrega(2, new Date(2025, 9, 30))).toEqual(new Date(2025, 10, 3));
  });
  test('ignora a hora do pedido', () => {
    expect(preverEntrega(5, new Date(2025, 9, 9, 18, 45))).toEqual(new Date(2025, 9, 16));
  });
  test('não altera a data recebida', () => {
    const hoje = new Date(2025, 9, 9);
    preverEntrega(5, hoje);
    expect(hoje).toEqual(new Date(2025, 9, 9));

`src/utils/mascaras.js`, abaixo do `mascararTelefone`:

```javascript
export function mascararCep(texto) {
  const d = texto.replace(/\D/g, '').slice(0, 8);
  return d.replace(/^(\d{5})(\d)/, '$1-$2');
}

export function mascararCpf(texto) {
  const d = texto.replace(/\D/g, '').slice(0, 11);
  if (d.length <= 3) return d;
  if (d.length <= 6) return `${d.slice(0, 3)}.${d.slice(3)}`;
  if (d.length <= 9) return `${d.slice(0, 3)}.${d.slice(3, 6)}.${d.slice(6)}`;
  return `${d.slice(0, 3)}.${d.slice(3, 6)}.${d.slice(6, 9)}-${d.slice(9)}`;
}
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| Teste de `formatarPreco` falha com o texto igual ao da tela | Espaço não separável depois do `R$` | Copiar a saída do console para o teste ou escrever `'R$\u00a0189,90'` |
| Data aparece um dia antes no celular | `new Date('AAAA-MM-DD')` lido em UTC | Montar com `new Date(ano, mes - 1, dia)` |
| Previsão um mês depois do esperado | Mês contado a partir de 1 | O mês vai de 0 a 11 |
| Teste passa hoje e falha amanhã | `preverEntrega` sem `hoje` no teste | Passar sempre uma data fixa |
| `toBe` falha com duas datas iguais | `toBe` compara se é o mesmo objeto | Usar `toEqual` |
| CEP para em `01310-10`, ou o texto colado vira `013` | `maxLength={8}` do E32 conta o hífen e corta antes da máscara | Tirar o `maxLength`: a máscara já limita |
| Tela vermelha `Cannot read property '1' of null` | `match` sem conferir `null` | `if (!partes) return null;` ou `partes?.[1]` |
| Data no celular com pontuação diferente do teste | `Intl` do Hermes no celular, do Node no Jest | Manter o teste com o texto do Node; conferir a tela no Expo Go |
