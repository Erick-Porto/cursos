## Bloco 1 · Lint, formatação e depuração (50 min)

**"A semana antes da entrega" (3 min).** Esperado: o hook depois do `return`. Escreva no quadro linter, formatador e depurador, até o fechamento.

**O caminho de cada bug:**

1. **`adicionar`:** breakpoint em `const existe`, segundo toque em "Adicionar". <kbd>F10</kbd>: `existe` preenchido, o `if` está certo. <kbd>F11</kbd> no `setItens` entra no callback do `map`: `i.id` e `produto.id` valem `5`, e o Watch `i.id !== produto.id` dá `false`.
2. **`total`:** breakpoint na linha, <kbd>F10</kbd>: `total: 80.9`, e o Watch `itens[0].preco * itens[0].qtd` dá `79.9`. Soma em vez de multiplicar.
3. **`aplicarFiltros`:** breakpoint condicional `ordem !== 'nome'` no primeiro `if` do comparador. Com `ordem: "preco"`, o <kbd>F10</kbd> pula o `return` e cai no `localeCompare`; o Watch `ordem === 'precos'` dá `false`.

```typescript
type Ordem = 'nome' | 'preco' | 'avaliacao';

type Produto = {
  id: number;
  nome: string;
  preco: number;
  categoria: string;
  avaliacao: number;
};

type Filtros = { categoria: string | null; ordem: Ordem };

export function aplicarFiltros(lista: Produto[], { categoria, ordem }: Filtros): Produto[] {
  const filtrada = lista.filter((p) => !categoria || p.categoria === categoria);
  return filtrada.sort((a, b) => {
    if (ordem === 'preco') return a.preco - b.preco;
    if (ordem === 'avaliacao') return b.avaliacao - a.avaliacao;
    return a.nome.localeCompare(b.nome);
  });
}
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `git apply` diz `patch does not apply` | arquivo diferente da referência | aplicar à mão, sem o aluno ver, ou a branch `e23-bugs` |
| A tecla <kbd>j</kbd> não abre nada | app desconectado, ou sem Chrome nem Edge | recarregar com <kbd>r</kbd> e tentar de novo |
| O breakpoint nunca para | linha fora do caminho, ou outro arquivo aberto | abrir o arquivo de `src/` pelo <kbd>Ctrl</kbd> + <kbd>P</kbd>; testar com `debugger;` |
| O app parece travado | pausado num breakpoint esquecido | <kbd>F8</kbd> e remover todos no painel Breakpoints |
| O esqueleto do Início volta sem parar | `carregar` nas dependências | tirar da lista; `eslint-disable-next-line` com motivo |
| `Unable to resolve path to module` num import que funciona | maiúsculas diferentes das do arquivo: o Windows aceita, o lint não | corrigir o import |
| `Cannot find module 'typescript'` | instalação recusada ou interrompida | `npx expo install typescript @types/react -- --save-dev` |
| Salvar não formata o arquivo | extensão Prettier ausente ou outro formatador padrão | instalar a extensão e conferir o `.vscode/settings.json` |
