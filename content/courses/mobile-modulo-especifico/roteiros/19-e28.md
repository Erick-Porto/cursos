## Visão do encontro

**Objetivo:** escrever funções com intenção (forma, parâmetros, retorno, escopo) e separar o que calcula do que tem efeito. A recursão entra como ferramenta para dados em árvore, não como truque.

**Resultado ao fim das 4h:** `adicionarItem`, `removerItem` e `alterarQuantidade` puras e testadas em `src/regras/carrinho.js`; o `CarrinhoContext` só chama regras e expõe `alterar(id, qtd)`; cada item do Carrinho tem − e +. Pelo menos 7 testes novos passando.

:::example Solução de referência
`src/regras/carrinho.js`, abaixo das funções do E27:

```javascript
export function adicionarItem(itens, produto) {
  const existente = itens.find((item) => item.id === produto.id);
  if (existente) {
    return alterarQuantidade(itens, produto.id, existente.qtd + 1);
  }
  return [...itens, { ...produto, qtd: 1 }];
}

export function removerItem(itens, id) {
  return itens.filter((item) => item.id !== id);
}

export function alterarQuantidade(itens, id, qtd) {
  if (qtd <= 0) return removerItem(itens, id);
  return itens.map((item) => (item.id === id ? { ...item, qtd } : item));
}
```

import { adicionarItem, alterarQuantidade, removerItem } from './carrinho';

const fone = { id: 1, nome: 'Fone Bluetooth', preco: 199.9 };
const caneca = { id: 7, nome: 'Caneca Térmica', preco: 59.9 };

describe('adicionarItem', () => {
  test('produto novo entra com qtd 1', () => {
    expect(adicionarItem([], fone)).toEqual([{ ...fone, qtd: 1 }]);
  });

  test('produto repetido soma 1 na qtd, sem duplicar', () => {
    const novos = adicionarItem([{ ...fone, qtd: 1 }], fone);
    expect(novos).toHaveLength(1);
    expect(novos[0].qtd).toBe(2);
  });

  test('não altera o carrinho original', () => {
    const itens = [{ ...fone, qtd: 1 }];
    const novos = adicionarItem(itens, fone);
    expect(novos).not.toBe(itens);
    expect(itens[0].qtd).toBe(1);
  });
});

describe('removerItem', () => {
  test('tira só o item do id informado', () => {
    const itens = [{ ...fone, qtd: 1 }, { ...caneca, qtd: 2 }];
    expect(removerItem(itens, 1)).toEqual([{ ...caneca, qtd: 2 }]);
  });

  test('id inexistente devolve os mesmos itens', () => {
    const itens = [{ ...fone, qtd: 1 }];
    expect(removerItem(itens, 99)).toEqual(itens);
  });

`src/contexts/CarrinhoContext.js`:

```jsx
import { createContext, useContext, useState } from 'react';
import {
  adicionarItem,
  alterarQuantidade,
  contarItens,
  removerItem,
  subtotal,
} from '../regras/carrinho';

const CarrinhoContext = createContext(null);

export function CarrinhoProvider({ children }) {
  const [itens, setItens] = useState([]);

  function adicionar(produto) {
    setItens(adicionarItem(itens, produto));
  }

  function remover(id) {
    setItens(removerItem(itens, id));
  }

  function alterar(id, qtd) {
    setItens(alterarQuantidade(itens, id, qtd));
  }

  const quantidade = contarItens(itens);
  const total = subtotal(itens);
  const valor = { itens, adicionar, remover, alterar, quantidade, total };

  return <CarrinhoContext.Provider value={valor}>{children}</CarrinhoContext.Provider>;
}

export function useCarrinho() {
  const valor = useContext(CarrinhoContext);
  if (!valor) throw new Error('useCarrinho fora do CarrinhoProvider');
  return valor;
}
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `alterarQuantidade is not defined` ao repetir um produto | Função não escrita, sem `export` ou com outro nome | Conferir grafia e `export` |
| `Identifier 'alterarQuantidade' has already been declared` | Função do contexto com o nome da regra importada | Renomear a do contexto para `alterar` |
| Toque no + não muda a tela | Regra que muda o item recebido, ou `alterar` sem `setItens` | Teste do carrinho original; conferir o `setItens` |
| Item fica com "0 x" no carrinho | Falta a guarda `qtd <= 0` | `if (qtd <= 0) return removerItem(itens, id);` |
| A quantidade muda sozinha ao abrir o Carrinho | `onPress={alterar(item.id, item.qtd + 1)}` sem arrow | `onPress={() => alterar(...)}` |
| `Cannot access '...' before initialization` | Arrow chamada antes da linha que a cria | Mover a chamada ou usar declaração |
| `Cannot use import statement outside a module` no `npm test` | Jest sem o preset `jest-expo` | Conferir `"jest": { "preset": "jest-expo" }` no `package.json` |
