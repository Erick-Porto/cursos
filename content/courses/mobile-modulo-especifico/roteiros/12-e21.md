## Visão do encontro

**Objetivo:** mostrar onde o JavaScript roda e pôr o Node para trabalhar a favor do app.

**Resultado ao fim das 4h:** `src/data/catalogo.json` gerado por script, `src/data/produtos.js` com duas linhas de reexportação e o app idêntico ao da v1; `node scripts/relatorio-catalogo.mjs` imprime produtos por categoria, preço médio e produtos sem imagem, com o filtro opcional `--categoria=`.

## Bloco 1 · JavaScript por dentro: motores e runtimes (50 min)

**"O código que funcionava no site" (5 min).** Faça a pergunta do slide e anote as hipóteses no quadro sem corrigir; você volta a elas na demonstração.

**"ECMAScript" e "Uma edição por ano" (5 min).** Pergunte quais recursos da tabela a turma já usou. Esperado: `const`, arrow function, `import`, o spread do `CarrinhoContext`.

**"Motores" e "Hermes" (6 min).** No Hermes, insista em uma frase: "o app chega ao celular já compilado, e por isso abre mais rápido". O Expo Go é a exceção do desenvolvimento: recebe texto do Metro.

**Demonstração: o mesmo código em três lugares (10 min).** É o centro do bloco. Preencha ao vivo, no quadro, uma tabela com as colunas Navegador, Node e App.

```javascript
const carrinho = [199.9, 89.9];
const total = carrinho.reduce((soma, preco) => soma + preco, 0);
console.log('total', total.toFixed(2));
console.log('document', typeof document);
console.log('Hermes', typeof HermesInternal);
```

:::steps
1. Navegador: <kbd>F12</kbd>, aba Console, cole as 5 linhas. Saída: `total 289.80`, `document object`, `Hermes undefined`.
2. Node: digite `node` no terminal, cole as linhas no REPL e saia com `.exit`. Saída: `total 289.80`, `document undefined`, `Hermes undefined`.
3. App: cole no topo de `src/telas/Inicio.js`, fora do componente, e salve. No terminal do Expo: `total 289.80`, `document undefined`, `Hermes object`.
4. Pergunte: "O que mudou e o que não mudou?" Esperado: a conta, que é da linguagem, deu igual; o que cada lugar oferece mudou.
5. Acrescente `localStorage.getItem('carrinho');` no `Inicio.js` e salve: tela vermelha com `Property 'localStorage' doesn't exist`. Volte às hipóteses e feche a pergunta de abertura.
6. Apague as linhas de demonstração e confira que o Início voltou ao normal.
:::

## Bloco 2 · Node na prática: scripts para o app (50 min)

**"A pergunta da reunião" (3 min).** Esperado: ler o catálogo, filtrar, contar, somar e dividir. As três perguntas da dona da loja vão para o quadro: são o enunciado do laboratório.

**"O REPL" (4 min).** Todos no próprio computador, no terminal do VS Code aberto na raiz do `lojinha`: `node -v`, o REPL e os comandos do slide. Peça que expliquem o `undefined` depois do `const`.

**"Rodando um arquivo" (3 min).** Crie `scripts/ola.mjs` ao vivo e rode da raiz. Depois, `cd scripts` e `node ola.mjs`: funciona, porque o script não lê arquivo nenhum. Volte com `cd ..`: "guardem isso para daqui a pouco".

**"Módulos ES e CommonJS" e "Por que .mjs" (5 min).** Renomeie para `ola.js`, acrescente `import path from 'node:path';` e rode. Conforme a versão do Node, aparece o erro `Cannot use import statement outside a module` ou o aviso `MODULE_TYPELESS_PACKAGE_JSON`, que sugere `"type": "module"`. A sugestão vale para o projeto inteiro: volte para `.mjs`.

**"process.argv" (4 min).** `console.log(process.argv)` no `ola.mjs`, rodando com `--categoria=audio`. Aponte as duas primeiras posições e o `slice(2)`.

**"Pratique" (5 min).** Individual. Esperado: `['01310-100', '150']` e as duas linhas com desestruturação e `Number`. Se alguém responder `150` sem aspas, rode `'150' + 10` no REPL e deixe a turma ver `'15010'`.

**"path" e "fs" (7 min).** No REPL, `process.cwd()` e `path.join(process.cwd(), 'src', 'data')`: no Windows aparecem as barras invertidas. Depois, `JSON.parse(fs.readFileSync('package.json', 'utf-8')).name` devolve `'lojinha'`; no REPL, `fs` e `path` dispensam `import`.

**"JSON" (4 min).** `JSON.stringify` e `JSON.parse` do slide no REPL. Depois, `JSON.parse("{'a': 1}")` lança `SyntaxError`. Pergunte por quê. Esperado: aspas simples.

**"O catálogo vira JSON" e "Gerando o JSON com um script" (6 min).** Ao vivo no `lojinha` de demonstração, com a turma só olhando: copie `produtos.js` para `scripts/produtos-antigos.mjs`, escreva o gerador, rode, abra o JSON, apague os dois temporários, troque o `produtos.js` pelas duas linhas e mostre o app igual. Aponte que `4.0` virou `4`: em JSON, número é número.

**"Ida e volta: disco, texto e objeto" e "O relatório: ler e filtrar" (2 min).** No diagrama, aponte o caminho de baixo, que o gerador acabou de fazer, e o de cima, que o relatório vai fazer. Cole o código do slide em `scripts/relatorio-catalogo.mjs` e rode com e sem `--categoria=audio`: só o título e a contagem aparecem. O resto é o laboratório.

**"Erros comuns" a "No laboratório" (2 min).** Faça o primeiro erro ao vivo: `cd scripts` e rode o relatório. O `ENOENT` aponta para `scripts\src\data`: era isso que o `ola.mjs` preparava.

**Desafio que prepara o laboratório (5 min).** Em duplas, no papel, sem rodar nada: "Escrevam a saída exata do relatório completo para `--categoria=casa`." Esperado: título com `casa`, `Produtos: 3`, `Casa: 3`, `Preço médio: R$ 209,90` (89,90, 79,90 e 459,90) e `Sem imagem: nenhum`. Copie a resposta no quadro: é a saída esperada para conferir o script, ideia que volta nos testes do E24.

:::tip Ritmo
Se atrasar, só conte o que acontece com o `ola.js` em vez de renomear. O gerador ao vivo e o desafio da saída esperada não se cortam: sem eles, o laboratório trava no passo 2.
:::

`scripts/gerar-catalogo.mjs`, temporário: roda uma vez e é apagado junto com `scripts/produtos-antigos.mjs`, a cópia de `src/data/produtos.js`.

```javascript
import fs from 'node:fs';
import path from 'node:path';
import { categorias, produtos } from './produtos-antigos.mjs';

const destino = path.join(process.cwd(), 'src', 'data', 'catalogo.json');
const texto = JSON.stringify({ categorias, produtos }, null, 2);

fs.writeFileSync(destino, texto + '\n');
```

`src/data/produtos.js`, o arquivo inteiro:

```javascript
import catalogo from './catalogo.json';
```

`scripts/relatorio-catalogo.mjs`:

```javascript
import fs from 'node:fs';
import path from 'node:path';

const arquivo = path.join(process.cwd(), 'src', 'data', 'catalogo.json');
const { categorias, produtos } = JSON.parse(fs.readFileSync(arquivo, 'utf-8'));

const opcao = process.argv.slice(2).find((a) => a.startsWith('--categoria='));
const filtro = opcao ? opcao.split('=')[1] : null;

if (filtro && !categorias.some((c) => c.slug === filtro)) {
  console.log(`Categoria "${filtro}" não existe.`);
  console.log(`Use uma destas: ${categorias.map((c) => c.slug).join(', ')}`);
  process.exit(1); // encerra o script com código de erro
}
const lista = filtro ? produtos.filter((p) => p.categoria === filtro) : produtos;

console.log(`Relatório do catálogo: ${filtro ? filtro : 'todas as categorias'}`);
console.log(`Produtos: ${lista.length}`);

for (const categoria of categorias) {
  const total = lista.filter((p) => p.categoria === categoria.slug).length;
  if (total > 0) console.log(`  ${categoria.nome}: ${total}`);
}

const soma = lista.reduce((acumulado, p) => acumulado + p.preco, 0);
const media = lista.length > 0 ? soma / lista.length : 0;
const mediaFormatada = media.toLocaleString('pt-BR', { style: 'currency', currency: 'BRL' });
console.log(`Preço médio: ${mediaFormatada}`);

const semImagem = lista.filter((p) => !p.imagem).map((p) => p.nome);
console.log(`Sem imagem: ${semImagem.length > 0 ? semImagem.join(', ') : 'nenhum'}`);
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `ENOENT` apontando para `scripts\src\data\catalogo.json` | Terminal aberto dentro de `scripts/` | `cd ..` e rodar da raiz; mostrar `process.cwd()` no REPL |
| `Cannot use import statement outside a module` ou aviso `MODULE_TYPELESS_PACKAGE_JSON` | Script salvo como `.js` | Renomear para `.mjs`, sem mexer no `"type"` do `package.json` |
| `Cannot find module` ao rodar o gerador | `import` sem extensão ou cópia com outro nome | Importar `'./produtos-antigos.mjs'` e conferir o nome da cópia |
| Metro acusa erro de sintaxe no `catalogo.json` | JSON digitado à mão, com vírgula sobrando ou aspas simples | Gerar pelo script ou baixar `material/catalogo.json` |
| `Cannot read property 'filter' of undefined` no Início | `produtos.js` com `export default`, ou chave diferente no JSON | Conferir as duas linhas e as chaves `categorias` e `produtos` |
| `Unable to resolve module` apontando para `fs` ou `node:fs` | `fs` importado num arquivo de `src/` | No app, o JSON entra por `import`; `fs` só nos scripts |
| `typeof window` dá `object` no app | O React Native cria `window` como apelido do objeto global | Não há página: o teste que vale é `typeof document` |
