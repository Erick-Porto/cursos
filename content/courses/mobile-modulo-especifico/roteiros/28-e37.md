## Visão do encontro

**Objetivo:** a turma entende por que o app não pode esperar parado, prevê a ordem de execução com o event loop e usa Promises para o checkout esperar quatro etapas sem travar a tela.

**Resultado ao fim das 4h:** o `finalizar` do Checkout mostra "Etapa 1 de 4: Conferindo o estoque..." até a 4 e abre a confirmação do E32; com `CHANCE_DE_FALHA = 1`, aparece o `EstadoErro` com "Tentar novamente". `npm test` verde com 6 testes novos, sem depender da sorte.

**Pré-requisitos:** Lojinha do E36 com o checkout do E32 (`finalizar` que monta o pedido, registra em "Meus pedidos" e vai para `/confirmacao`), `ErroDeNegocio` em `src/modelos/erros.js`, Jest do E24 e Node no computador.

**Materiais:** projetor espelhando o celular, terminal com fonte grande, pasta `e37-exemplos/` com os `.mjs` das duas aulas, solução de referência na branch `e37-solucao`, quiz publicado.

:::example Solução de referência
`src/modelos/erros.js`, no fim do arquivo, depois dos erros do E32:

```javascript
export class FalhaNoCheckoutError extends ErroDeNegocio {
  constructor(etapa, mensagem) {
    super(mensagem, 'FALHA_' + etapa.toUpperCase());
    this.name = 'FalhaNoCheckoutError';
    this.etapa = etapa;
  }
}

export class TempoEsgotadoError extends ErroDeNegocio {
  constructor(ms) {
    super(`A operação passou de ${ms / 1000} s. Tente de novo.`, 'TEMPO_ESGOTADO');
    this.name = 'TempoEsgotadoError';
    this.ms = ms;
  }
}
```

`src/servicos/checkout.js`, primeira parte:

```javascript
import { FalhaNoCheckoutError, TempoEsgotadoError } from '../modelos/erros';

export const CHANCE_DE_FALHA = 0.2; // 1 força a falha; volte para 0.2
const ATRASO = 800;

export function esperar(ms) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

function gerarCodigo() {
  return String(Date.now()).slice(-6);
}

function simularEtapa(chave, mensagem, valor, opcoes = {}) {
  const { sortear = Math.random, atraso = ATRASO, aoMudarEtapa = () => {} } = opcoes;
  aoMudarEtapa(chave);
  return esperar(atraso).then(() => {
    if (sortear() < CHANCE_DE_FALHA) throw new FalhaNoCheckoutError(chave, mensagem);
    return valor;
  });
}

export function comTempoLimite(promessa, ms) {
  let id;
  const limite = new Promise((resolve, reject) => {
    id = setTimeout(() => reject(new TempoEsgotadoError(ms)), ms);
  });
  return Promise.race([promessa, limite]).finally(() => clearTimeout(id));
}
```

`src/servicos/checkout.js`, segunda parte:

```javascript
export function validarEstoque(itens, opcoes) {
  return simularEtapa('estoque', 'Um produto do carrinho acabou de esgotar.', itens, opcoes);
}

export function reservar(itens, opcoes) {
  return simularEtapa('reserva', 'Não conseguimos reservar seus produtos.', { codigo: 'RES-' + gerarCodigo() }, opcoes);
}

// pagamento: a forma escolhida no E31; a simulação não precisa dela
export function cobrar(total, pagamento, opcoes) {
  const mensagem = 'O pagamento foi recusado. Confira os dados ou escolha outra forma.';
  return simularEtapa('pagamento', mensagem, { codigo: 'PAG-' + gerarCodigo(), valor: total }, opcoes);
}

export function confirmar(reserva, cobranca, opcoes) {
  const pedido = { numero: gerarCodigo(), status: 'pago', reserva: reserva.codigo, valor: cobranca.valor };
  return simularEtapa('confirmacao', 'Não conseguimos confirmar o pedido.', pedido, opcoes);
}

export function finalizarCompra(pedido, aoMudarEtapa = () => {}, opcoes = {}) {
  const config = { ...opcoes, aoMudarEtapa }; // cada etapa avisa a tela quando começa
  let reserva; // guardada fora: a confirmação precisa dela
  return validarEstoque(pedido.itens, config)
    .then(() => reservar(pedido.itens, config))
    .then((resultado) => {
      reserva = resultado;
      return comTempoLimite(cobrar(pedido.total, pedido.pagamento, config), 5000);
    })
    .then((cobranca) => confirmar(reserva, cobranca, config));
}
```

`src/telas/Checkout.js`, só o que muda. `fecharPedido`, `mostrarErro` e `registrar` vêm do `finalizar` da aula 45; se o seu E32 usa outros nomes, mantenha os seus. O estado `enviando` sai: `etapa` diferente de `null` já significa "enviando". O `erro` novo não é o `erros` dos campos.

```jsx
// novos imports
import { EstadoCarregando, EstadoErro } from '../components/ui';
import { ErroDeNegocio } from '../modelos/erros';
import { finalizarCompra } from '../servicos/checkout';

// fora do componente
const TEXTO_DA_ETAPA = {
  estoque: 'Conferindo o estoque...',
  reserva: 'Reservando seus produtos...',
  pagamento: 'Processando o pagamento...',
  confirmacao: 'Confirmando o pedido...',
};
const ORDEM = Object.keys(TEXTO_DA_ETAPA);

// dentro de Checkout, junto dos outros useState
const [etapa, setEtapa] = useState(null);
const [erro, setErro] = useState(null);

function finalizar() {
  let pedido;
  try {
    pedido = fecharPedido(dados); // E32: CEP e cupom inválidos lançam aqui
  } catch (falha) {
    return mostrarErro(falha); // como no E32: o erro vai para o Campo ou o Toast
  }
  setErro(null);
  finalizarCompra(pedido, setEtapa)
    .then(() => {
      registrar(pedido); // "Meus pedidos", como no E32
      router.replace('/confirmacao');
    })
    .catch((falha) => {
      if (falha instanceof ErroDeNegocio) return setErro(falha.message);
      console.error(falha); // bug: não esconda
      setErro('Algo inesperado aconteceu. Tente de novo.');
    })
    .finally(() => setEtapa(null));
}
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| Tela presa em "Etapa 1 de 4" depois de uma falha | `setEtapa(null)` só no `then`, ou corrente sem `catch` | Mover a limpeza para o `finally`; conferir o `catch` antes dele |
| A cobrança começa antes de a reserva terminar | `then` com chaves e sem `return` | Ler o `then` em voz alta: "o que esta função devolve?" |
| `TypeError: sortear is not a function` | `sortear: Math.random()`, com parênteses, ou um número | Passar a função: `Math.random` ou `() => 1` |
| Teste que às vezes passa e às vezes falha | `opcoes` não repassadas a uma etapa, que sorteia com `Math.random` | Seguir as `opcoes` de `finalizarCompra` até `simularEtapa` |
| Teste verde mesmo com o esperado errado | Função do teste sem `return` | Trocar o esperado de propósito: se continuar verde, falta o `return` |
| "Algo inesperado aconteceu" sempre na confirmação | `reserva` ficou `undefined`: faltou `reserva = resultado` | Ler o `console.error` no terminal do Expo |
| `finalizarCompra is not a function` | Import de `../regras/checkout`, as regras do E32 | Corrigir para `../servicos/checkout` |

- **Sem internet:** o laboratório não instala pacote nenhum, e o Expo Go só precisa da rede local. Se o Wi-Fi cair, use o hotspot do seu celular com `npx expo start --offline`, o emulador ou a web.
- **Turma atrasada no laboratório:** priorize o serviço e as etapas na tela; os testes 1 a 4 são o mínimo, e os de `comTempoLimite` ficam para casa.
