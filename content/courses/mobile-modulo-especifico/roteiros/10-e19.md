## Visão do encontro

**Objetivo:** dar ao Lojinha movimento que comunica e fazer cada tela dizer o que está acontecendo: carregando, vazia, com erro ou com conteúdo.

**Resultado:** `EstadoCarregando`, `EstadoVazio`, `EstadoErro`, `Esqueleto` e `Toast` em `src/components/ui/`; Início com esqueleto por 1,5 segundo, erro simulado com "Tentar novamente" e cartões em cascata; carrinho vazio com "Ver produtos"; Detalhe com botão que pulsa e toast. Commit "E19: animações e estados de tela".

**Pré-requisitos:** `lojinha` do E18 rodando no Expo Go (abas, `CarrinhoContext`, grade com `colunas`, `useTema()`, UI kit com `index.js`); `useEffect` e os estados `carregando` e `erro` do E05; `useRef` do E15.

**Materiais:** projetor espelhando o celular do instrutor, Wi-Fi comum, uma folha A4 por aluno, um Android para mostrar "Remover animações", quiz "Quiz: E19 · Animações e estados de tela" publicado.

```jsx
// src/telas/DemoAnimacao.js: só para a demonstração do Bloco 1
import { useEffect, useRef } from 'react';
import { Animated, Button, StyleSheet, Text, View } from 'react-native';

const NATIVO = false; // segunda rodada: true, e recarregue com r

function travarJavaScript() {
  const fim = Date.now() + 2000;
  while (Date.now() < fim) {} // 2 segundos de JavaScript ocupado
}

export default function DemoAnimacao() {
  const x = useRef(new Animated.Value(0)).current;

  useEffect(() => {
    const vaiEVem = Animated.loop(
      Animated.sequence([
        Animated.timing(x, { toValue: 200, duration: 800, useNativeDriver: NATIVO }),
        Animated.timing(x, { toValue: 0, duration: 800, useNativeDriver: NATIVO }),
      ])
    );
    vaiEVem.start();
    return () => vaiEVem.stop();
  }, []);

  return (
    <View style={estilos.tela}>
      <Text style={estilos.rotulo}>useNativeDriver: {String(NATIVO)}</Text>
      <Animated.View style={[estilos.bola, { transform: [{ translateX: x }] }]} />
      <Button title="Travar o JavaScript por 2 segundos" onPress={travarJavaScript} />
    </View>
  );
}

const estilos = StyleSheet.create({
  tela: { flex: 1, justifyContent: 'center', padding: 24, gap: 32, backgroundColor: '#ffffff' },
  rotulo: { fontSize: 20, color: '#0f172a' },
  bola: { width: 56, height: 56, borderRadius: 28, backgroundColor: '#7c3aed' },
});
```

## Bloco 1 · Animações com Animated (50 min)

**"O toque que parece não funcionar" e "Animação comunica, não enfeita" (8 min).** Pergunta do slide, uma frase por pessoa. Esperado: "o botão reage na hora", "aparece um aviso". Peça um exemplo de animação que só enfeita em algum app do celular deles. Fixe a regra: resposta a toque em 150 a 300 ms.

**"Animated.Value guardado em useRef" a "Animated.timing: de 0 a 1 em 300 ms" (12 min).** Use o dimmer: o valor é a posição do botão; a `Animated.View`, a lâmpada. Ao vivo, no cabeçalho do Início:

:::steps
1. Acrescente uma `Animated.View` com "Frete grátis acima de R$ 150" e `opacity: opacidade`, com `useRef(new Animated.Value(0)).current`. Salve: a faixa some.
2. Escreva o `useEffect` com `Animated.timing`, sem o `.start()`. Recarregue com `r`: nada, e nenhum erro. Acrescente o `.start()`: a faixa aparece. Mostre com `duration: 2000` e volte a 300.
3. O erro clássico: troque por `const opacidade = new Animated.Value(0);`, sem `useRef`, e recarregue: tudo parece normal. Na aba Perfil, alterne o tema e volte ao Início: a faixa sumiu.
4. Pergunte por quê. Esperado: "o corpo rodou de novo e criou outro valor, em 0; o efeito com `[]` não roda de novo". Volte o `useRef` e repita: a faixa fica.
:::

Não use o salvamento do arquivo para mostrar o erro: o Fast Refresh roda os efeitos de novo e esconde o problema.

**"Pense" (5 min).** Esperado: cartões em sequência e botão que pulsa comunicam; o logo girando só enfeita; a troca de aba comunica, mas 1 segundo atrasa. Se travarem: "o que mudou na tela quando o logo gira?".

**"60 quadros por segundo" e "useNativeDriver: a animação no lado nativo" (10 min).** Explique os 16 ms por quadro com o desenho animado de caderno. Depois, na aba Perfil:

:::steps
1. `NATIVO = false`: a bola vai e volta lisa; no monitor de desempenho, UI e JS perto de 60.
2. Toque em "Travar o JavaScript": a bola congela e salta; a linha JS despenca. "Quem calculava cada quadro estava ocupado."
3. `NATIVO = true`, salve e recarregue com `r` (misturar os dois modos no mesmo valor gera erro). Toque de novo: o botão fica preso 2 segundos, mas a bola segue lisa.
4. Acrescente `width: x` ao estilo da bola: tela vermelha `Style property 'width' is not supported by native animated module`. Leia e desfaça.
:::

Só então projete a tabela do slide: ela resume o que a turma viu.

**"interpolate: o cartão que entra deslizando" a "Animated.spring: o botão que pulsa" (10 min).** Ao vivo:

:::steps
1. No `Inicio.js`, escreva a `EntradaAnimada` fora do componente e envolva o `CartaoProduto` com ela, passando para ela o `style={estilos.celula}`.
2. Crie `entradas` e o `useEffect` com `Animated.stagger(80, ...)`. Recarregue: cascata. Mostre com 300 e volte a 80.
3. No `Detalhe.js`, o `comprar` do E17 vira `adicionarAoCarrinho`: adiciona, sem `router.back()`. Envolva o `Botao` numa `Animated.View` com `scale` e escreva o `setValue(0.85)` e o `spring`. Toque: o botão encolhe e volta com um pulo.
4. Teste `friction` 1 e 10 e pergunte qual parece certo para um botão.
:::

**"Quem desliga o movimento" a "Próximos passos" (5 min).** Mostre onde fica "Remover animações" e conte o que viu no ensaio: o sistema avisa, mas é o app que decide respeitar, com `AccessibilityInfo.isReduceMotionEnabled()`. É visão; ninguém aplica hoje. Reanimated em um minuto, sem instalar.

:::tip Ritmo
Se atrasar, mostre o `spring` só no slide e pule o `width` com driver nativo. Não corte o erro sem `useRef` nem a demonstração sob carga: são os pontos que mais caem no quiz.
:::

```jsx
import { useEffect, useRef } from 'react';
import { Animated } from 'react-native';
import { useTema } from '../../theme/TemaContext';

export default function Esqueleto({ largura = '100%', altura = 16, style }) {
  const { cores, raio } = useTema();
  const opacidade = useRef(new Animated.Value(0.4)).current;

  useEffect(() => {
    const pulso = Animated.loop(
      Animated.sequence([
        Animated.timing(opacidade, { toValue: 1, duration: 700, useNativeDriver: true }),
        Animated.timing(opacidade, { toValue: 0.4, duration: 700, useNativeDriver: true }),
      ])
    );
    pulso.start();
    return () => pulso.stop();
  }, []);

  const forma = { width: largura, height: altura, borderRadius: raio.sm, backgroundColor: cores.borda };
  return <Animated.View style={[forma, { opacity: opacidade }, style]} />;
}
```

```jsx
import { useEffect, useRef } from 'react';
import { AccessibilityInfo, Animated, StyleSheet, Text } from 'react-native';
import { useTema } from '../../theme/TemaContext';
import { familia, espaco, fonte, raio } from '../../theme/tokens';

export default function Toast({ mensagem, visivel, onSumir }) {
  const { cores } = useTema();
  const anim = useRef(new Animated.Value(0)).current;

  useEffect(() => {
    if (!visivel) return;
    AccessibilityInfo.announceForAccessibility(mensagem);
    Animated.sequence([
      Animated.timing(anim, { toValue: 1, duration: 200, useNativeDriver: true }),
      Animated.delay(1800),
      Animated.timing(anim, { toValue: 0, duration: 200, useNativeDriver: true }),
    ]).start(() => onSumir());
  }, [visivel]);

  if (!visivel) return null;
  const subida = anim.interpolate({ inputRange: [0, 1], outputRange: [16, 0] });
  const animacao = { opacity: anim, transform: [{ translateY: subida }] };
  return (
    <Animated.View style={[estilos.toast, { backgroundColor: cores.texto }, animacao]}>
      <Text style={[estilos.texto, { color: cores.fundo }]}>{mensagem}</Text>
    </Animated.View>
  );
}

const estilos = StyleSheet.create({
  toast: {
    position: 'absolute', left: espaco.md, right: espaco.md, bottom: espaco.lg,
    padding: espaco.md, borderRadius: raio.md,
  },
  texto: { fontSize: fonte.corpo, fontFamily: familia.negrito, textAlign: 'center' },
});
```

```jsx
import { Animated, FlatList, StyleSheet, Text, View, useWindowDimensions } from 'react-native';

const CHANCE_DE_ERRO = 0.3; // 1 força o erro; 0 nunca falha

export default function Inicio() {
  const { cores } = useTema();
  const { width } = useWindowDimensions();
  const colunas = width >= 600 ? 3 : 2;

  const [erro, setErro] = useState(null);
  const entradas = useRef(produtos.map(() => new Animated.Value(0))).current;

  function carregar() {
    setCarregando(true);
    setErro(null);
    setTimeout(() => {
      if (Math.random() < CHANCE_DE_ERRO) setErro('Não conseguimos buscar os produtos.');
      setCarregando(false);
    }, 1500);

    Animated.stagger(80, entradas.map((valor) =>

    )).start();
  }, [carregando, erro]);
```

```jsx
function EntradaAnimada({ valor, style, children }) {
  const subida = valor.interpolate({ inputRange: [0, 1], outputRange: [24, 0] });
  return (
    <Animated.View style={[style, { opacity: valor, transform: [{ translateY: subida }] }]}>
      {children}
    </Animated.View>
  );
}

function GradeEsqueleto({ colunas }) {
  const { cores } = useTema();
  const largura = colunas === 3 ? '30%' : '47%';
  return (
    <SafeAreaView style={[estilos.tela, { backgroundColor: cores.fundo }]}>
      <View style={estilos.grade} accessible accessibilityLabel="Carregando produtos">
        {[1, 2, 3, 4, 5, 6].map((n) => (
          <View key={n} style={[estilos.cartaoEsqueleto, { width: largura }]}>
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| Faixa ou cartão some ao trocar o tema | `new Animated.Value(0)` sem `useRef` | `useRef(new Animated.Value(0)).current` |
| Nada se move, sem erro | falta `.start()` ou a `View` não é animada | conferir o `.start()`; usar `Animated.View` |
| Tela vermelha `Style property 'width' is not supported by native animated module` | `width`, `height` ou cor com driver nativo | animar `scale` ou `opacity` |
| Tela vermelha `Rendered more hooks than during the previous render` | `useEffect` depois de um `return` | todos os hooks antes dos `return` |
| Cartões estreitos ou desalinhados na grade | `estilos.celula` ficou no cartão, não na `EntradaAnimada` | passar o `style` para a `EntradaAnimada` |
| Esqueleto que nunca sai | `setCarregando(false)` dentro do `if` do erro | `setCarregando(false)` sempre, fora do `if` |
| Toast que rola com a tela ou não aparece | `Toast` dentro do `ScrollView` ou antes dele | último filho de uma `View` com `flex: 1` |
