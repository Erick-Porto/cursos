## Bloco 1 · Variáveis e tipos no app (50 min)

**"2 + 1 = 21 no carrinho" (5 min).** Faça a pergunta do slide e anote os palpites no quadro, sem responder. Monte o bug ao vivo, no Detalhe da demonstração:

:::steps
1. No `Detalhe.js`, junto dos outros hooks: `const [textoQtd, setTextoQtd] = useState('1');`. Importe o `Campo` do kit.
2. Acima do botão: `<Campo rotulo="Quantidade" keyboardType="numeric" value={textoQtd} onChangeText={setTextoQtd} />` e um `Text` com ``{`Com mais um: ${textoQtd + 1}`}``.
3. No celular, digite 2: a tela mostra "Com mais um: 21". Deixe a turma rir e pergunte de novo: "por quê?".
4. Acrescente `console.log(typeof textoQtd)` e digite outro número: o terminal do Expo mostra `string`, mesmo com o teclado numérico.
5. Deixe o código assim: ele volta no bloco "Number e parseInt".

**"const" a "Por que não var" (10 min).** No REPL, previsão antes de cada Enter. `const freteFixo = 15` e depois `freteFixo = 20`: `TypeError`. Mostre o `var` vazando do `if` e o `let` dando `ReferenceError`. Reforce a linha do `useState`: "estado é `const`; quem muda é o `set`". Se perguntarem por que `const itens = []` aceita `push`: o nome está preso, o conteúdo não.

**"Tipos primitivos" e "typeof" (7 min).** No REPL, `typeof` em cada exemplo da tabela. O `typeof null` dando `'object'` arranca risada: é um erro antigo que ninguém conserta sem quebrar a web. Lembre o E16: foi o `typeof id` que revelou a string da rota.

**"O TextInput sempre entrega texto" e "Coerção" (8 min).** No celular, cole "dois" no campo: o teclado numérico não impede. No REPL, as quatro linhas da coerção, com previsão antes de cada uma. Esperado na última: `NaN`.

**"Pense" (5 min).** Duplas, 2 minutos. Esperado: `+` com texto concatena, `*` converte, e a correção é `const qtd = Number(textoQtd)` logo depois de ler o campo. Se ninguém chegar à conversão única: "quantas linhas mudariam se você convertesse em cada conta?".

**"Number e parseInt" e "NaN e Number.isNaN" (8 min).** Projete a tabela com a coluna de resultados coberta; a turma prevê linha a linha e você confere no REPL. Pare no `'2,5'`: é o que o brasileiro digita. No Detalhe, troque o `Text` por `Number(textoQtd) + 1` e apague o campo: "Com mais um: 1", porque `Number('')` é `0`. Escreva a versão com `parseInt(textoQtd, 10)` e `Number.isNaN`, passando a mensagem ao `erro` do `Campo`. Depois, `git checkout -- src/telas/Detalhe.js`: o campo era só demonstração.

**"Template strings" e "Pratique" (5 min).** Mostre a concatenação com o espaço esquecido ("Adicionado:2 x Fone") e a mesma mensagem com crases. Pratique individual, 3 minutos. Esperado: a função do slide, com o teste de `NaN` antes da conta.

**"Erros comuns" a "Próximos passos" (2 min).** Leitura rápida; termine com o mistério do `0.1 + 0.2`, sem rodar.

:::tip Ritmo
Se atrasar, faça o `var` e o `typeof` só no REPL e pule o `Number('')` no celular. O bug do 21 ao vivo e a tabela prevista pela turma não se cortam: são eles que tornam o tipo concreto.

**O que observar:** conta de preço no JSX (`produto.preco * 0.95`); `formatarPreco` dentro da regra; `toFixed` no lugar de centavos; `Math.round` em cada parcela; valor esperado copiado da saída da função; contas antes do `if (!produto)`. Para quem travou: "Em centavos, quanto é isso?"

:::example Solução de referência
`src/regras/precos.js`:

```javascript
// Regras de preço da Lojinha.
// Entrada e saída em reais, como no catálogo; a conta é feita em centavos inteiros.

export const PERCENTUAL_PIX = 5;
export const PARCELAS_NA_VITRINE = 3;

export function paraCentavos(reais) {
  return Math.round(reais * 100);
}

export function paraReais(centavos) {
  return centavos / 100;
}

// Valor do desconto, arredondado ao centavo. O percentual fica entre 0 e 100.
export function calcularDesconto(preco, percentual) {
  const limitado = Math.min(Math.max(percentual, 0), 100);
  const desconto = Math.round((paraCentavos(preco) * limitado) / 100);
  return paraReais(desconto);
}

export function precoComPix(preco) {
  const desconto = calcularDesconto(preco, PERCENTUAL_PIX);
  return paraReais(paraCentavos(preco) - paraCentavos(desconto));
}

// A primeira parcela leva os centavos que sobram da divisão.
export function parcelar(total, parcelas) {
  const centavos = paraCentavos(total);
  const valor = Math.floor(centavos / parcelas);
  const resto = centavos % parcelas;
  return { parcelas, valor: paraReais(valor), primeira: paraReais(valor + resto) };
}
```

`src/regras/precos.test.js`, primeira parte:

describe('centavos', () => {

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `npm test` diz que não encontrou testes | Arquivo sem `.test.js` no nome ou fora de `src/` | Conferir o nome `precos.test.js`, ao lado de `precos.js` |
| `Cannot use import statement outside a module` | Falta o preset `jest-expo` no `package.json` | Conferir `"jest": { "preset": "jest-expo" }` do E24 |
| `Expected: 189.9, Received: 189.91` | Arredondou o preço final (`preco * 0.95`), não o desconto | Arredondar o desconto em centavos e subtrair |
| `Expected: 66.63, Received: 66.63333333333334` | Dividiu em reais, sem `paraCentavos` e `Math.floor` | Converter para centavos antes de dividir |
| Detalhe vermelho com um `id` inexistente | `parcelar(produto.preco, ...)` antes do `if (!produto)` | Contas depois do `if`; hooks continuam antes |
| "R$ NaN no Pix" | Campo errado, como `produto.valor`: `undefined * 100` dá `NaN` | `console.log(typeof produto.preco)` e conferir o `catalogo.json` |
| "ou 3x de R$ 66,64" | Mostrou `primeira` em vez de `valor` | A vitrine anuncia o valor das demais parcelas |
