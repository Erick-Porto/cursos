## Abertura (15 min)

Retomada (5 min):

1. "Por que `new Date('2026-10-16')` pode mostrar o dia 15 no celular?" Esperado: texto só com a data é lido como meia-noite em UTC, que em Brasília ainda é dia 15; monte com `new Date(2026, 9, 16)`.

```javascript
import { paraCentavos, paraReais } from './precos';

export function subtotal(itens) {
  const centavos = itens.reduce((soma, item) => soma + paraCentavos(item.preco) * item.qtd, 0);
  return paraReais(centavos);
}

export function contarItens(itens) {
  return itens.reduce((total, item) => total + item.qtd, 0);
}

export function itemMaisCaro(itens) {
  return itens.reduce(
    (maisCaro, item) => (maisCaro === null || item.preco > maisCaro.preco ? item : maisCaro),
    null,
  );
}
```

`src/regras/catalogo.js`:

```javascript
export function agruparPorCategoria(produtos) {
  return produtos.reduce((grupos, produto) => {
    const slug = produto.categoria;
    if (!grupos[slug]) grupos[slug] = [];
    grupos[slug].push(produto);
    return grupos;
  }, {});
}
```

`src/regras/pedido.js`, acrescentado ao fim do arquivo:

```javascript
import { paraCentavos, paraReais } from './precos';

function chaveDoMes(data) {
  const d = new Date(data); // o texto ISO que o registrar do E32 grava
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}`;
}

export function totalPorMes(pedidos) {
  const centavosPorMes = pedidos
    .filter((pedido) => pedido.status !== 'cancelado')
    .reduce((meses, pedido) => {
      const mes = chaveDoMes(pedido.data);
      meses[mes] = (meses[mes] ?? 0) + paraCentavos(pedido.total);
      return meses;
    }, {});

  return Object.entries(centavosPorMes)
    .map(([mes, centavos]) => ({ mes, total: paraReais(centavos) }))
    .sort((a, b) => b.mes.localeCompare(a.mes));
}
```

O `import` vai para o topo do arquivo. O mês sai do fuso do celular, não do texto em UTC: o pedido das 22h do dia 31 em Brasília é gravado como dia 1º em UTC, e `slice(0, 7)` no texto o jogaria no mês seguinte.

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| Badge com `[object Object]` ou `Reduce of empty array with no initial value` | `reduce` sem valor inicial | Perguntar quanto vale o acumulador na primeira volta; acrescentar `0`, `null` ou `{}` |
| `map` devolve `[undefined, undefined]` | Arrow com chaves e sem `return` | Tire as chaves ou escreva o `return`; com objeto, use parênteses |
| Teste do subtotal falha com `379.70000000000005` | Soma em reais, sem `paraCentavos` | Somar em centavos e voltar com `paraReais` no fim |
| `Cannot read properties of null (reading 'preco')` em `itemMaisCaro` | Lê `maisCaro.preco` antes de testar `maisCaro === null` | A ordem do `||` importa: o teste de `null` vem primeiro |
| Categorias sem seções | Agrupou por `nome` ou leu `grupos[c.nome]` em vez de `grupos[c.slug]` | `console.log(Object.keys(grupos))` e comparar com os `slug` |
| Meus pedidos com `RangeError: Invalid time value`; teste com mês `'NaN-NaN'` | `totalPorMes` lê um campo que o pedido não tem (o do E32 é `data`) | `console.log(pedidos[0])` e ajustar o campo em `totalPorMes` |
| Mês adiantado ou atrasado em um | `getMonth()` sem `+ 1`, ou `new Date(ano, mes)` sem `- 1` | Lembrar que janeiro é 0; o teste de janeiro pega esse erro |
| Tela não muda depois de alterar o carrinho | `push`, `sort` ou atribuição no estado | Trocar pela coluna da direita da tabela "Atualizar sem mutar" |
