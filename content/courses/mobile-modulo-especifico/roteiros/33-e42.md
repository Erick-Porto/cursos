## Visão do encontro

**Objetivo:** dar a cada equipe a estrutura do projeto até o Demo Day: pastas por funcionalidade, uma API própria com `json-server` acessada pelo celular e o estado do domínio num contexto com `useReducer`, explicado linha a linha.

**Resultado ao fim das 4h:** no celular de cada pessoa, as 5 telas do protótipo navegam por abas e pilha, no tema da equipe; a tela principal lista dados do `db.json`; o contexto do domínio tem guarda, reducer e testes verdes; cada parte entrou na `main` por PR revisado.

**Pré-requisitos:** entrega do E41 (quadro com 12 a 20 issues, `main` protegida, app com Expo Router abrindo no celular de todos); a Lojinha v2, de onde saem o tema e o kit de UI; Git Bash, que vem com o Git.

**Materiais:** projetor espelhando celular e terminal, quadro com duas cores, Wi-Fi que permita conexões entre aparelhos, hotspot de reserva, repositório de demonstração da lanchonete no estado do E41 com a solução na branch `e42-solucao`, quiz publicado.

## Antes do encontro

:::steps

```javascript
const URL_BASE = process.env.EXPO_PUBLIC_API_URL;

export async function pedir(caminho, opcoes = {}) {
  let resposta;
  try {
    resposta = await fetch(URL_BASE + caminho, {
      ...opcoes,
      headers: { 'Content-Type': 'application/json', ...opcoes.headers },
    });
  } catch (erro) {
    if (erro.name === 'AbortError') throw erro;
    throw new Error('Sem conexão com o servidor. Confira o Wi-Fi e o IP do .env.');
  }
  if (!resposta.ok) throw new Error('O servidor respondeu ' + resposta.status + '.');
  return resposta.json();
}
```

`src/features/carrinho/carrinhoReducer.js`, com as regras do briefing:

```javascript
const QTD_MAXIMA = 10;
const limitar = (qtd) => Math.min(Math.max(qtd, 1), QTD_MAXIMA);

export function carrinhoReducer(itens, acao) {
  switch (acao.type) {
    case 'adicionar': {
      if (!acao.produto.disponivel) return itens; // indisponível não entra
      const existe = itens.some((i) => i.id === acao.produto.id);
      if (!existe) return [...itens, { ...acao.produto, qtd: 1 }];
      return itens.map((i) => (i.id === acao.produto.id ? { ...i, qtd: limitar(i.qtd + 1) } : i));
    }
    case 'alterarQtd':
      return itens.map((i) => (i.id === acao.id ? { ...i, qtd: limitar(acao.qtd) } : i));
    case 'remover':
      return itens.filter((i) => i.id !== acao.id);
    case 'limpar':
      return [];
    default:
      throw new Error('Ação desconhecida: ' + acao.type);
  }
}
```

`src/features/carrinho/CarrinhoContext.js`:

```jsx
import { createContext, useContext, useReducer } from 'react';
import { carrinhoReducer } from './carrinhoReducer';

const CarrinhoContext = createContext(null);

export function CarrinhoProvider({ children }) {
  const [itens, dispatch] = useReducer(carrinhoReducer, []);
  const valor = {
    itens,
    quantidade: itens.reduce((soma, i) => soma + i.qtd, 0),
    total: itens.reduce((soma, i) => soma + i.preco * i.qtd, 0),
    adicionar: (produto) => dispatch({ type: 'adicionar', produto }),
    alterarQtd: (id, qtd) => dispatch({ type: 'alterarQtd', id, qtd }),
    remover: (id) => dispatch({ type: 'remover', id }),
    limpar: () => dispatch({ type: 'limpar' }),
  };
  return <CarrinhoContext.Provider value={valor}>{children}</CarrinhoContext.Provider>;
}

export function useCarrinho() {
  const valor = useContext(CarrinhoContext);
  if (!valor) throw new Error('useCarrinho precisa estar dentro do CarrinhoProvider');
  return valor;
}
```

```javascript
  async function recarregar() {
    setSecoes(null);
    setErro(null);
    try {
      const [categorias, produtos] = await Promise.all([listarCategorias(), listarProdutos()]);
      const todas = categorias.map((c) => ({
        title: c.nome,
        data: produtos.filter((p) => p.categoriaId === c.id),
      }));
      setSecoes(todas.filter((s) => s.data.length > 0));
    } catch (e) {
      setErro(e.message);
    }
  }

  useEffect(() => {
    recarregar();
  }, []);

  const carregando = secoes === null && !erro;
  return { secoes: secoes ?? [], carregando, erro, recarregar };
}
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| O JSON abre no computador, não no navegador do celular | Redes diferentes, Wi-Fi que isola aparelhos ou firewall barrando o Node | Mesmo Wi-Fi; no Windows, liberar o Node em redes privadas; em último caso, hotspot |
| O navegador do celular abre, o app mostra "Sem conexão" | `.env` com `localhost`, IP antigo, barra no fim ou Expo sem `-c` | `console.log(URL_BASE)` no `cliente.js`; corrigir e `npx expo start -c` |
| `npx json-server` não sobe ou reclama do Node | Node antigo | `node --version`; atualizar ou usar a API da máquina de um colega |
| O app abre a tela antiga do E41, sem abas | `app/index.js` sobrou ao lado de `app/(tabs)/index.js` | Apagar `app/index.js`; `npx expo start -c` |
| `db.json` modificado no `git status` sem ninguém editar | O json-server reescreve o arquivo: ids viram texto e surge o `$schema` | Esperado: commitar a versão normalizada; descartar pedidos de teste com `git restore db.json` |
| "useCarrinho precisa estar dentro do CarrinhoProvider" | Provider fora do layout, ou hook no próprio `Layout` | Provider em volta da `Pilha`; hooks só nos filhos |
| O badge não muda ao adicionar | Reducer com `push` | Devolver array novo; o teste de imutabilidade pega `qtd++` |
| Aviso de fonte não carregada com o kit da Lojinha | `familia` aponta para a Inter e o layout não a carrega | `useFonts` no `_layout.js` e `npx expo install @expo-google-fonts/inter expo-font expo-splash-screen` |

## Plano B

- **Rede que isola os aparelhos:** hotspot do seu celular, uma equipe por vez. Sem hotspot, o app roda no navegador do computador (tecla `w`, com `npx expo install react-dom react-native-web @expo/metro-runtime`), onde `http://localhost:3000` funciona, ou no emulador Android, que enxerga o computador em `http://10.0.2.2:3000`.
- **Firewall que você não pode liberar:** navegador do computador ou emulador; o teste no celular fica para casa.
- **Sem internet para o `npx`:** a máquina que já baixou o json-server serve a equipe pelo IP dela.
- **Equipe incompleta:** quem veio faz navegação e API; o contexto vira tarefa de casa, com o desafio do quadro como contrato.
- **Sem projetor:** árvore e camadas no quadro; demonstrações do json-server em rodízio, em volta do seu computador.
