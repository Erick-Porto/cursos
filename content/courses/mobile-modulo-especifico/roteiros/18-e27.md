## Bloco 1 · Laços com for e while (50 min)

**"Um carrinho com 2 itens ou com 20" (5 min).** Peça a um aluno que escreva no quadro o total de 3 itens com `itens[0]`, `itens[1]`...; depois o de 7 itens e o do carrinho vazio. Faça a pergunta do slide. Esperado: "escrever a conta de um item e repetir para cada um".

**"for" e "Teste de mesa" (10 min).** Rode `iconesDaNota(4.4)` no REPL do Node. Depois, faça o teste de mesa com a turma sendo o laço: um aluno diz o valor de `i`, outro responde se a condição vale, um terceiro escreve no quadro o que entra na lista. Na volta com `i` valendo 6, pare e pergunte: "e agora?". Esperado: a condição é falsa, o laço termina e o `return` roda.

**"Acumulador" a "O acumulador, volta a volta" (10 min).** Demonstração com TDD, a peça mais importante do bloco:

:::steps
1. Crie `src/regras/carrinho.test.js` com o objeto `fone` (199.9, `qtd` 2), a `luminaria` (89.9, `qtd` 1) e o teste `expect(subtotal([fone, luminaria])).toBe(489.7)`.
2. Crie `src/regras/carrinho.js` com a `subtotal` somando reais, como a `totalDoCarrinho` do slide.
3. `npm test`: vermelho, `Expected: 489.7`, `Received: 489.70000000000005`. Pergunte de qual encontro é esse número. Esperado: E25, ponto flutuante.
4. Troque para `paraCentavos` e `paraReais` e rode de novo: verde.
5. Acrescente o teste do carrinho vazio. Pergunte quantas voltas o laço dá. Esperado: nenhuma, `0 < 0` é falso.
:::

Entre os passos 4 e 5, projete "O acumulador, volta a volta" e narre junto com a animação: o `i`, o item da volta e quanto entrou em `centavos`. Pare na linha de `i` valendo 2 e pergunte por que não há uma terceira barra.

**"Contador" (4 min).** Antes de mostrar o resultado, pergunte quantos produtos em destaque a vitrine tem. Esperado: 4, os ids 1, 4, 7 e 10. Pergunte também qual a única diferença para o acumulador. Esperado: soma 1 em vez de um valor.

**"Pense" (5 min).** Dois minutos individuais. Esperado: o `<=` faz uma volta a mais, e `itens[itens.length]` é `undefined`. Ao vivo, troque `<` por `<=` na `subtotal` e rode o teste: o Jest mostra `Cannot read properties of undefined (reading 'preco')`, a versão do Node da mensagem que o app mostra (E21). Volte o `<`.

**"while" e "do...while" (7 min).** Desenhe duas portas: o `while` confere a condição **na entrada** de cada volta; o `do...while`, **na saída**. Pergunte: "com R$ 200 no carrinho, quantas voltas a `unidadesParaFreteGratis` dá?". Esperado: zero. No sorteio da sugestão, pergunte por que o `do...while` cabe melhor. Esperado: é preciso sortear antes de conferir.

**"break" e "continue" (4 min).** Pergunte quantas voltas o laço do `break` dá para achar o id 7. Esperado: 7, porque ele está na posição 6. Leia o aviso do `continue` no `while` em voz alta: ele volta no quiz.

**"Pratique" (3 min).** Em duplas. Esperado: `for` para os 6 esqueletos, `do...while` para o cupom e `while` para o dia útil. Se alguém disser `for` para o dia útil, pergunte: "quantas voltas, se hoje é sexta?".

**"Laço infinito" a "Próximos passos" (2 min).** Mostre o laço infinito no Jest, não no celular: um teste com `unidadesParaFreteGratis(89.9, 0)` deixa o terminal parado. <kbd>Ctrl</kbd> + <kbd>C</kbd> e apague o teste. "No app, a tela congela do mesmo jeito."

:::tip Ritmo
Se atrasar, faça o teste de mesa só com as voltas 1, 5 e 6 e mostre o `do...while` sem discutir. O vermelho dos centavos e o off-by-one ao vivo não se cortam: eles explicam metade dos erros do laboratório.
:::

`src/regras/carrinho.js`, primeira parte:

```javascript
import { paraCentavos, paraReais } from './precos';

// Regras puras do carrinho e da vitrine: recebem dados e devolvem dados.

export function subtotal(itens) {
  let centavos = 0;
  for (let i = 0; i < itens.length; i++) {
    centavos += paraCentavos(itens[i].preco) * itens[i].qtd;
  }
  return paraReais(centavos);
}

export function contarItens(itens) {
  let total = 0;
  for (const item of itens) {
    total += item.qtd;
  }
  return total;
}

export function itemMaisCaro(itens) {
  let maisCaro = null;
  for (const item of itens) {
    if (maisCaro === null || item.preco > maisCaro.preco) {
      maisCaro = item;
    }
  }
  return maisCaro;
}
```

`src/regras/carrinho.js`, segunda parte:

```javascript
export function paginar(lista, pagina, tamanho) {
  if (pagina < 1 || tamanho < 1) return [];
  const inicio = (pagina - 1) * tamanho;
  const fim = Math.min(inicio + tamanho, lista.length);
  const resultado = [];
  for (let i = inicio; i < fim; i++) {
    resultado.push(lista[i]);
  }
  return resultado;
}

function normalizar(texto) {
  return texto.normalize('NFD').replace(/[\u0300-\u036f]/g, '').toLowerCase();
}

export function buscarProdutos(produtos, termo) {
  const procurado = normalizar(termo).trim();
  if (procurado === '') return produtos;
  const encontrados = [];
  for (const produto of produtos) {
    if (normalizar(produto.nome).includes(procurado)) {
      encontrados.push(produto);
    }
  }
  return encontrados;
}
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `NaN` no total, ou "R$ NaN" no carrinho | `for...in` no lugar de `for...of` | Trocar `in` por `of`; mostrar `typeof item` no breakpoint |
| `Cannot read property 'preco' of undefined` | `<=` no limite do `for` | Teste de mesa com 2 itens no papel |
| `npm test` não termina | Laço infinito: preço 0, `i--` ou `continue` antes do `i++` | <kbd>Ctrl</kbd> + <kbd>C</kbd>; conferir condição e passo |
| `Received: 489.70000000000005` | Soma em reais | `paraCentavos` na soma e `paraReais` no fim |
| `Cannot find module './precos'` | `precos.js` do E25 ausente ou fora de `src/regras/` | Conferir a pasta; copiar da branch do E25 |
| A busca não acha "tenis" | Normalizou só um lado, ou o `normalize` não age no aparelho | Rodar o teste no Jest; no celular, Plano B |
| O teclado fecha a cada letra | Campo dentro de um componente criado no corpo da Início, como `ListHeaderComponent={() => ...}` | Campo acima da `FlatList`, como na solução |
| `Rendered more hooks than during the previous render` | `useState` do termo depois de um `return` antecipado | Todos os hooks no topo da Início |

## Plano B

- **`normalize` sem efeito no celular:** se o teste do Expo Go falhar, troque o `normalizar` por esta versão com `for...of`, que passa nos mesmos testes:

```javascript
const SEM_ACENTO = { á: 'a', à: 'a', â: 'a', ã: 'a', é: 'e', ê: 'e', í: 'i', ó: 'o', ô: 'o', õ: 'o', ú: 'u', ç: 'c' };

function normalizar(texto) {
  let limpo = '';
  for (const letra of texto.toLowerCase()) {
    limpo += SEM_ACENTO[letra] ?? letra;
  }
  return limpo;
}
```

- **Aluno sem celular:** as regras e os testes não precisam de aparelho. A busca roda no navegador (tecla `w`) ou no emulador; último caso, dupla.
- **Sem projetor:** o teste de mesa no quadro vira o centro do Bloco 1, e o TDD acontece em rodízio, em grupos de 5 em volta do seu computador.
