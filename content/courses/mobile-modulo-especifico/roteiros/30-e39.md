## Visão do encontro

**Objetivo:** fazer a Lojinha lembrar do cliente: carrinho e favoritos salvos com AsyncStorage pelo serviço `src/servicos/armazenamento.js`, e a constante `logado` do E17 trocada por um login real na DummyJSON, com o token no SecureStore e um `AuthContext` alimentando o `Redirect`. **Resultado ao fim das 4h:** carrinho e favoritos voltam depois de tirar o app dos recentes; `emilys` entra, o Perfil mostra "Emily Johnson" com a foto e o login sobrevive ao reabrir; a senha errada mostra uma mensagem em português; "Sair" leva a Entrar sem caminho de volta.

**Materiais:** projetor espelhando o celular, Wi-Fi testado com a DummyJSON, quadro com duas cores, solução de referência na branch `e39-solucao`, quiz publicado.

## Abertura (15 min)

Retomada (5 min):

1. "O que o `fetch` faz quando a API responde 404?" Esperado: não rejeita; a resposta chega com `ok` falso, e por isso o `pedir` confere `resposta.ok` e lança o erro.

**"Código limpo (1)" e "(2)" (5 min).** A turma aponta cada regra no código de hoje: `VALIDADE_EM_MINUTOS` (5), `traduzirUsuario` (2 e 7), o `catch` da tela Entrar (8), o comentário `// sem este campo` (9).

**Desafio que prepara o laboratório (5 min).** Em duplas: "Quantas regras este trecho de tela quebra? Reescrevam a chamada como a tela deveria fazer."

```javascript
async function f(u, s) {
  const r = await fetch('https://dummyjson.com/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ username: u, password: s }),
  });
  const d = await r.json();
  await AsyncStorage.setItem('t', d.accessToken);
  await AsyncStorage.setItem('senha', s);
  try {
    setUsuario(d.firstName + ' ' + d.lastName);
  } catch (e) {}
}
```

Esperado: nomes sem sentido (`f`, `u`, `s`, `r`, `d`, regra 1); chave mágica `'t'` (5); endereço repetido em vez do `pedir` (6); `fetch` na tela (7); nenhum `r.ok` e um `catch` vazio (8). E dois problemas de segurança: token no AsyncStorage e senha guardada. A reescrita cabe numa linha, dentro do `try` da tela: `await entrar(nomeDeUsuario, senha);`.

:::tip Ritmo
Se atrasar, deixe os passos 2 e 5 do `curl` no slide e passe o token vencido para o Fechamento, durante o quiz. Não corte o `curl` sem `Content-Type`, a demonstração sem `carregando` nem o desafio.
:::

`src/servicos/armazenamento.js`:

```javascript
import AsyncStorage from '@react-native-async-storage/async-storage';

export async function salvar(chave, valor) {
  try {
    await AsyncStorage.setItem(chave, JSON.stringify(valor));
  } catch (erro) {
    console.warn(`Não foi possível salvar ${chave}`, erro);
  }
}

export async function ler(chave, padrao) {
  try {
    const texto = await AsyncStorage.getItem(chave);
    return texto === null ? padrao : JSON.parse(texto);
  } catch (erro) {
    console.warn(`Não foi possível ler ${chave}`, erro);
    return padrao;
  }
}
```

`src/contexts/FavoritosContext.js`:

```jsx
import { createContext, useContext, useEffect, useState } from 'react';
import { alternarFavorito } from '../regras/favoritos';
import { ler, salvar } from '../servicos/armazenamento';

const CHAVE = 'lojinha.favoritos';
const FavoritosContext = createContext(null);

export function FavoritosProvider({ children }) {
  const [favoritos, setFavoritos] = useState(new Set());
  const [carregado, setCarregado] = useState(false);

  useEffect(() => {
    async function carregar() {
      setFavoritos(new Set(await ler(CHAVE, [])));
      setCarregado(true);
    }
    carregar();
  }, []);

  useEffect(() => {
    if (carregado) salvar(CHAVE, [...favoritos]);
  }, [favoritos, carregado]);

  function alternar(id) {
    setFavoritos((anterior) => alternarFavorito(anterior, id));
  }
  function ehFavorito(id) {
    return favoritos.has(id);
  }
  const valor = { favoritos, alternar, ehFavorito };
  return <FavoritosContext.Provider value={valor}>{children}</FavoritosContext.Provider>;
}

export function useFavoritos() {
  const valor = useContext(FavoritosContext);
  if (!valor) throw new Error('useFavoritos fora do FavoritosProvider');
  return valor;
}
```

`src/api/auth.js`:

```javascript
import { pedir } from './cliente';

const VALIDADE_EM_MINUTOS = 60 * 24 * 7; // sem este campo, a API usa 60

export async function autenticar(nomeDeUsuario, senha) {
  const dados = await pedir('/auth/login', {
    method: 'POST', // o pedir já manda o Content-Type: application/json
    body: JSON.stringify({ username: nomeDeUsuario, password: senha, expiresInMins: VALIDADE_EM_MINUTOS }),
  });
  return dados.accessToken;
}

export async function buscarUsuario(token) {
  const dados = await pedir('/auth/me', { headers: { Authorization: `Bearer ${token}` } });
  return traduzirUsuario(dados);
}

function traduzirUsuario(dados) {
  return {
    id: dados.id,
    nome: `${dados.firstName} ${dados.lastName}`,
    email: dados.email,
    foto: dados.image ?? null,
    cidade: dados.address?.city ?? '',
  };
}
```

`src/contexts/AuthContext.js`, estado e sessão restaurada:

```jsx
import { createContext, useContext, useEffect, useState } from 'react';
import * as SecureStore from 'expo-secure-store';
import { autenticar, buscarUsuario } from '../api/auth';

const CHAVE_TOKEN = 'lojinha.token';
const AuthContext = createContext(null);

export function AuthProvider({ children }) {
  const [usuario, setUsuario] = useState(null);
  const [carregando, setCarregando] = useState(true);

  useEffect(() => {
    async function restaurarSessao() {
      try {
        const token = await SecureStore.getItemAsync(CHAVE_TOKEN);
        if (token) setUsuario(await buscarUsuario(token));
      } catch {
        await SecureStore.deleteItemAsync(CHAVE_TOKEN); // vencido ou inválido
      } finally {
        setCarregando(false);
      }
    }
    restaurarSessao();
  }, []);
```

`src/contexts/AuthContext.js`, entrar, sair e o hook:

```jsx
  async function entrar(nomeDeUsuario, senha) {
    const token = await autenticar(nomeDeUsuario, senha);
    await SecureStore.setItemAsync(CHAVE_TOKEN, token);
    setUsuario(await buscarUsuario(token));
  }

  async function sair() {
    await SecureStore.deleteItemAsync(CHAVE_TOKEN);
    setUsuario(null);
  }

  const valor = { usuario, entrar, sair, carregando };
  return <AuthContext.Provider value={valor}>{children}</AuthContext.Provider>;
}

export function useAuth() {
  const valor = useContext(AuthContext);
  if (!valor) throw new Error('useAuth fora do AuthProvider');
  return valor;
}
```

```jsx
import { useState } from 'react';
import { StyleSheet, Text, View } from 'react-native';
import { router } from 'expo-router';
import { useAuth } from '../contexts/AuthContext';
import { useTema } from '../theme/TemaContext';
import { espaco, familia, fonte } from '../theme/tokens';
import { validarObrigatorio } from '../utils/validar';
import { Botao, Campo } from '../components/ui';

export default function Entrar() {
  const { cores } = useTema();
  const { entrar } = useAuth();
  const [nomeDeUsuario, setNomeDeUsuario] = useState('');
  const [senha, setSenha] = useState('');
  const [erro, setErro] = useState(null);
  const [enviando, setEnviando] = useState(false);

  async function enviar() {
    const faltando = validarObrigatorio(nomeDeUsuario, 'seu usuário') ?? validarObrigatorio(senha, 'sua senha');
    if (faltando) {
      setErro(faltando);
      return;
    }
    setErro(null);
    setEnviando(true);
    try {
      await entrar(nomeDeUsuario.trim(), senha);
      router.replace('/');
    } catch (erro) {
      setErro(erro.status === 400 ? 'Usuário ou senha incorretos.' : erro.message);
    } finally {
      setEnviando(false);
    }
  }
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `NativeModule: AsyncStorage is null` | Pacote instalado com `npm install` em versão incompatível, ou servidor não reiniciado | `npx expo install` de novo e `npx expo start -c` |
| Carrinho volta vazio depois do `r` | Salvar sem a trava, ou chave diferente na leitura e na gravação | Constante `CHAVE` no topo; `console.log` no resultado do `ler` |
| Favoritos não voltam, sem erro | `Set` salvo direto, que vira `'{}'` | `[...favoritos]` na ida e `new Set(...)` na volta |
| Login sempre diz "Usuário ou senha incorretos." | Corpo com `usuario` e `senha` em vez de `username` e `password` | `console.log` provisório do `body`; comparar com o `curl` |
| App abre em Entrar mesmo logado | Abas sem o `if (carregando)` | Ordem: hooks, `carregando`, depois `usuario` |
| Erro de chave inválida no SecureStore | Chave com `:` ou espaço | Só letras, números, `.`, `-` e `_` |
| "useAuth fora do AuthProvider" em Entrar | `AuthProvider` no layout das abas | Mover para `app/_layout.js`, por fora da `Pilha` |
| O voltar reabre o Perfil depois de sair | Perfil ainda faz `router.push('/entrar')` | O Sair só chama `sair()`; o `Redirect` navega |

## Plano B

- **Sem internet ou DummyJSON fora do ar:** o AsyncStorage funciona sem rede; faça essa parte inteira. Para o login, troque o corpo de `autenticar` por uma Promise com `setTimeout` (padrão do E37) que devolve `'token-de-teste'` para `emilys` e rejeita o resto, e o de `buscarUsuario` por um usuário fixo. Só `auth.js` muda: é a regra 7 na prática. Quiz na abertura do E40.
- **Muitos pedidos na mesma rede:** a DummyJSON limita pedidos por endereço (cabeçalhos `x-ratelimit`). Com a turma no mesmo Wi-Fi, um status 429 é possível: espere alguns segundos ou use o hotspot do seu celular.
- **Sem projetor:** demonstrações em rodízio, em grupos de 5 em volta do seu celular.
- **Aluno sem celular:** emulador Android, se configurado. Na web o SecureStore não funciona: quem estiver no navegador faz a persistência do carrinho e testa o login em dupla.
- **Pacote que não instala:** feche o editor e o servidor do Expo (no Windows, eles travam arquivos) e repita o `npx expo install`; persistindo, `npx expo install --fix`. Passou de 10 minutos: dupla, e você investiga a máquina na pausa.
