## Visão do encontro

**Objetivo:** levar a turma das funções puras às classes de domínio: produto e pedido calculam e validam a si mesmos, e as telas só perguntam. O ponto central, que não se corta: no estado do React ficam dados simples; a classe é criada a partir deles para calcular e validar, e um método que "muda" devolve uma instância nova.

**Resultado ao fim das 4h:** `src/modelos/Produto.js` e `src/modelos/Pedido.js` com pelo menos 10 testes verdes; o Detalhe mostra preço formatado, preço no Pix e selo "Destaque" vindos do `Produto`; cada aluno explica por que `pedido.status = 'pago'` não atualiza a tela.

**Pré-requisitos:** Lojinha do E29 com `npm test` e `npm run verificar` (E24); `precoComPix` em `src/regras/precos.js` (E25); `textoDoStatus` e `tomDoStatus` em `src/regras/pedido.js` (E26); `subtotal` (em reais) e `contarItens` em `src/regras/carrinho.js` (E27).

**Materiais:** projetor com editor e celular lado a lado, quadro com duas cores, branch `e30-solucao`, pasta compartilhada com os arquivos de regras de referência (Plano B), quiz publicado.

`src/modelos/Produto.js`, primeira parte:

```javascript
import { precoComPix } from '../regras/precos';
import { formatarPreco } from '../utils/formatar';

export default class Produto {
  constructor({
    id, nome, preco, categoria, imagem, descricao,
    destaque = false, avaliacao = 0,
  }) {
    this.id = id;
    this.nome = nome;
    this.preco = preco;
    this.categoria = categoria;
    this.imagem = imagem;
    this.descricao = descricao;
    this.destaque = destaque;
    this.avaliacao = avaliacao;
  }

  static deJSON(obj) {
    if (!obj || typeof obj.preco !== 'number') {
      throw new Error('Produto inválido no JSON');
    }
    return new Produto(obj);
  }

  static listaDeJSON(lista) {
    return lista.map((obj) => Produto.deJSON(obj));
  }
```

`src/modelos/Pedido.js`, primeira parte:

```javascript
import { contarItens, subtotal as somarItens } from '../regras/carrinho';
import { formatarPreco } from '../utils/formatar';

const STATUS = ['pendente', 'pago', 'enviado', 'entregue', 'cancelado'];

export default class Pedido {
  constructor({ id, itens = [], status = 'pendente', frete = 0, desconto = 0 }) {
    this.id = id;
    this.itens = itens;
    this.status = status; // passa pelo setter, que valida
    this.frete = frete;
    this.desconto = desconto;
  }

  get status() {
    return this._status;
  }

  set status(valor) {
    if (!STATUS.includes(valor)) {
      throw new Error(`Status inválido: ${valor}`);
    }
    this._status = valor;
  }
```

`src/modelos/Pedido.js`, segunda parte:

```javascript
  get quantidade() {
    return contarItens(this.itens);
  }

  get subtotal() {
    return somarItens(this.itens);
  }

  get total() {
    const centavos = Math.round((this.subtotal + this.frete - this.desconto) * 100);
    return Math.max(centavos, 0) / 100;
  }

  comStatus(novo) {
    return new Pedido({ ...this.paraJSON(), status: novo });
  }

  paraJSON() {
    const { id, itens, status, frete, desconto } = this;
    return { id, itens, status, frete, desconto };
  }

  toString() {
    return `Pedido ${this.id}, ${this.status}, ${formatarPreco(this.total)}`;
  }
}
```

import Produto from './Produto';
import { formatarPreco } from '../utils/formatar';

const fone = { id: 1, nome: 'Fone Bluetooth', preco: 199.9, categoria: 'audio', avaliacao: 4.6 };

describe('Produto', () => {
  test('deJSON cria uma instância com os dados do catálogo', () => {
    const produto = Produto.deJSON(fone);
    expect(produto).toBeInstanceOf(Produto);
    expect(produto.nome).toBe('Fone Bluetooth');
  });

  test('deJSON recusa preço que não é número', () => {
    expect(() => Produto.deJSON({ ...fone, preco: '199.90' })).toThrow('Produto inválido');
  });

  test('listaDeJSON converte a lista inteira', () => {
    const lista = Produto.listaDeJSON([fone, { ...fone, id: 2 }]);
    expect(lista).toHaveLength(2);
    expect(lista[1]).toBeInstanceOf(Produto);
  });

  test('precoFormatado usa o formatarPreco', () => {
    expect(Produto.deJSON(fone).precoFormatado).toBe(formatarPreco(199.9));
  });

  test('emDestaque pela nota ou pela marcação da loja', () => {
    expect(Produto.deJSON(fone).emDestaque).toBe(true);
    expect(Produto.deJSON({ ...fone, avaliacao: 4.2 }).emDestaque).toBe(false);
    expect(Produto.deJSON({ ...fone, avaliacao: 4.2, destaque: true }).emDestaque).toBe(true);
  });

  test('precoPara, precoNoPix e toString', () => {

    expect(produto.precoPara(3)).toBe(599.7);
    expect(produto.precoNoPix).toBe(189.9);

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `Class constructor Produto cannot be invoked without 'new'` | Faltou `new`; no app a mensagem pode vir com outras palavras | Procurar `Produto(` sem `new` antes; nas telas, preferir `Produto.deJSON(dados)` |
| `ReferenceError: preco is not defined` dentro de um método | Leu `preco` em vez de `this.preco` | "Quem guarda o preço?" Toda propriedade, dentro da classe, é `this.alguma` |
| `produto.precoFormatado is not a function` | Getter chamado com parênteses, inclusive em teste antigo | Tirar os parênteses na tela e no teste |
| `Maximum call stack size exceeded` ao criar o `Pedido` | O setter faz `this.status = valor` | Gravar em `this._status`; o getter lê `this._status` |
| Badge não muda ao confirmar, e muda depois "sozinho" | Instância no estado mudada por dentro | Dados simples no estado, `new Pedido(dados)` na renderização e `comStatus(...).paraJSON()` |
| Pedido pago volta a "Pendente" | Estado ou armazenamento recebeu `{ ...pedido }` ou `JSON.stringify(pedido)` | Usar `pedido.paraJSON()` |
| Teste de `precoFormatado` falha com textos que parecem iguais | O `toLocaleString` usa um espaço que não quebra linha depois de "R$" | Comparar com `formatarPreco(199.9)` ou usar `toContain('199,90')` |
| `Cannot find module '../modelos/Produto'` só no CI | Arquivo salvo como `produto.js`; o Windows ignora a diferença | Renomear com `git mv produto.js Produto.js` e novo commit |
