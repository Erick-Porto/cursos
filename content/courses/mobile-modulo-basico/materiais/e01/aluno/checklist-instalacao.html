Tudo o que o seu computador precisa para programar em React a partir do E02. Marque cada item quando terminar: a página lembra as marcações neste navegador. Em casa, siga a mesma ordem.

0 de 6 itens concluídos Entrega do dia: a captura de tela do terminal com as três versões (item 7).

Os seis itens

Como abrir
  • Windows: Win + X e escolha Terminal (ou Windows PowerShell). Também vale digitar "terminal" no menu Iniciar.
  • macOS: Cmd + Espaço, digite "Terminal" e aperte Enter.
  • Linux: Ctrl + Alt + T.
  • Dentro do VS Code: menu Terminal, New Terminal (ou Ctrl + `, a crase).
Como conferir
Uma janela com um cursor piscando esperando você digitar. Teste com echo oi e Enter: ele responde oi.
Onde baixar
nodejs.org, botão LTS. A versão LTS tem número par (como 22). Não pegue a "Current".
Como instalar
  • Windows: baixe o instalador .msi e avance com as opções padrão. Não precisa marcar "Automatically install the necessary tools".
  • macOS: instalador .pkg, avance até o fim.
  • Linux: use os binários do site ou o nvm. Evite o apt, que traz uma versão antiga.
Como conferir
Feche o terminal, abra de novo e digite:
terminal
node -v
npm -v
Esperado: algo como v22.12.0 e 10.9.0. O que importa é o número par depois do v.
Se falhar
  • "node não é reconhecido": o terminal estava aberto antes da instalação. Feche tudo (terminal e VS Code) e abra de novo.
  • Versão ímpar (23, 25): você baixou a "Current". Desinstale e instale a LTS.
  • No Windows, npm -v reclama que "a execução de scripts foi desabilitada": rode Set-ExecutionPolicy -Scope CurrentUser RemoteSigned e responda S, ou use o Prompt de Comando no lugar do PowerShell.
Onde baixar
git-scm.com, Downloads.
Como instalar
  • Windows: instalador normal; mantenha as opções padrão. Quando perguntar o editor, pode escolher o VS Code.
  • macOS: ao digitar git --version, o sistema oferece instalar as "ferramentas de linha de comando". Aceite e espere.
  • Linux: sudo apt install git (ou o gerenciador da sua distribuição).
Como conferir
terminal
git --version
Esperado: git version 2.x.x.
Se falhar
Mesmo caso do item 2: feche e reabra o terminal. Se o antivírus apagar o instalador, peça o pendrive ao instrutor.
Onde baixar
code.visualstudio.com, botão Download. No Windows, prefira o User Installer: não pede senha de administrador.
Como instalar
Avance pelo instalador. Marque Add to PATH e as opções "Abrir com Code" quando aparecerem.
Extensões
Dentro do VS Code, aperte Ctrl + Shift + X (Cmd + Shift + X no Mac), procure e instale, uma a uma:
  • ES7+ React/Redux/React-Native snippets
  • Prettier - Code formatter
  • Error Lens
Como conferir
As três aparecem em "Instaladas" na aba de extensões. No terminal, code --version mostra a versão (opcional).
Se falhar
Loja de extensões bloqueada pela rede: instale de casa. Dá para acompanhar o E02 sem elas; são conveniências.
Como conferir
Em qualquer página, F12 abre o painel do DevTools. Também funciona Ctrl + Shift + I (Cmd + Option + I no Mac) ou o botão direito na página e Inspecionar.
Se falhar
Em alguns notebooks, F12 precisa da tecla Fn junto. Se o navegador for antigo, atualize pelo menu Ajuda.
Onde criar
github.com/signup, com um e-mail que você consegue abrir pelo celular agora.
Nome de usuário
Um nome que você colocaria em um currículo: seu nome ou uma variação, só com letras, números e hífen. Exemplos: ana-souza, anasouza-dev. Ele aparece no endereço de todos os seus projetos.
Depois de criar
Confirme o e-mail (veja a caixa de spam) e coloque uma foto no perfil: ela serve de avatar na página do laboratório.
Como conferir
github.com/SEU-USUARIO abre a sua página e github.com/SEU-USUARIO.png mostra a sua foto.
Se falhar
Nome em uso ou com espaço: escolha outro. E-mail de confirmação que não chega: procure "GitHub" no spam ou use outro e-mail.

7. Entrega: a captura de tela

Com tudo instalado, feche e abra o terminal e digite os três comandos, um por linha. Tire uma captura de tela com as três respostas na mesma janela.

terminal
node -v
npm -v
git --version
  • Como tirar a captura: Windows, Win + Shift + S; macOS, Cmd + Shift + 4; Linux, PrtSc.
  • Onde enviar: ao instrutor, pelo sistema, junto com a sua página de perfil. Prazo: hoje.
  • Não deu tempo? Termine em casa com este checklist. No E02 você aprende a entregar por commit.

Sem permissão de administrador

Dá para instalar quase tudo só na sua conta de usuário:

  • Node.js: em nodejs.org, baixe o "Windows Binary (.zip)" da LTS e descompacte em Documentos\node. Peça ao instrutor para colocar a pasta no PATH; enquanto isso, os comandos funcionam com o terminal aberto dentro dela.
  • Git: em git-scm.com, baixe o Portable Git ("thumbdrive edition") e descompacte em Documentos\git.
  • VS Code: o User Installer já não pede administrador. Se ele for barrado, use o .zip.

Antivírus ou proxy continuam barrando? Avise o instrutor. Você faz o laboratório em uma máquina preparada ou no editor do GitHub, e a instalação fica para casa, com este checklist.
