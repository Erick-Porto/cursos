## Visão do encontro

**Objetivo:** levar a turma da repetição de tags a um componente que recebe props e é gerado a partir de um array.

**Resultado esperado:** o `minhas-tarefas` de cada aluno mostra 5 tarefas de um array, com `ListaTarefas`, `CartaoTarefa` em CSS Modules, `key` sem avisos e estado vazio, publicado no GitHub.

**Pré-requisitos (E02):** projeto rodando com `npm run dev`, `Cabecalho` e `Rodape` em `src/components`, as três regras do JSX, o ciclo `add`, `commit`, `push`. A turma não estudou arrays, arrow functions nem desestruturação: apresente os três devagar.

**Materiais:** projetor, Wi-Fi (push e quiz), um computador por aluno com o projeto do E02, painel do instrutor com as entregas. Sem celulares.

## Antes do encontro

:::steps
1. Seu `minhas-tarefas` no estado final do laboratório do E02 (`App` só com `Cabecalho` e `Rodape`), `npm run dev` ligado, DevTools na aba Console, fonte do editor em 18 ou mais.
2. Solução de referência (seção Laboratório) testada em outra pasta: 5 cartões, alta destacada, sem aviso de `key`, `[]` mostrando "Nenhuma tarefa por aqui".
3. Abas: as duas aulas no sistema, as entregas do E02 no painel e o `quiz-e03` publicado (7 questões, nota mínima 70, 3 tentativas).
4. Só os nomes do slide "No laboratório": props `titulo`, `prioridade`, `concluida` e `tarefas`; classes `cartao`, `alta` e `concluida`. Nomes improvisados confundem a turma no laboratório.
5. Pen drive com o projeto do E02 zipado, com `node_modules`, para quem perdeu o projeto ou ficar sem internet.
:::

## Abertura (15 min)

Projete o `minhas-tarefas` rodando e faça três perguntas (6 min):

1. "O navegador abre qual arquivo primeiro, e como chega ao `App`?" Esperado: `index.html` carrega `main.jsx`, que renderiza `<App />` na `div#root`.
2. "Quais são as três regras do JSX?" Esperado: uma raiz, `className` e camelCase, toda tag fecha.
3. "O `Saudacao` é o quê? Ele sempre mostra 'Ana'; como mostrar outro nome?" Esperado: função que devolve JSX, com `export default`. A turma vai sugerir trocar a variável; responda que hoje o nome chega **de fora**.

**Tarefa de casa (5 min):** dois repositórios entregues no projetor: `Cabecalho.jsx`, `Rodape.jsx`, dois commits. Elogie quem usou `{new Date().getFullYear()}`. Quem não entregou mostra o projeto no laboratório.

**Objetivos (4 min):** leia "O que você vai aprender" da aula A: "hoje o `minhas-tarefas` ganha a lista de verdade".

## Bloco 1 · Componentes e props (50 min)

Ritual do dia: você digita, para antes de salvar e pergunta **"o que vai aparecer?"**. Duas respostas, salve, compare.

**"Três cartões iguais, três textos diferentes" a "Componente: uma função que devolve JSX" (8 min).** Cole no `App.jsx` as três `<div className="cartao">` do slide: "e se forem 50?". Crie `src/components/CartaoTarefa.jsx` com texto fixo e use `<CartaoTarefa />` três vezes: três "Estudar React". A estrutura foi reaproveitada, o texto não.

**"Props: os parâmetros do componente" a "Desestruturação: pegando as props pelo nome" (15 min).** A demonstração mais lenta do dia.

:::steps
1. `function CartaoTarefa(props)` com `console.log(props)` antes do `return`. Salve: três `{}` no console.
2. No `App.jsx`, `<CartaoTarefa titulo="Estudar React" />` na primeira tag. Pergunte; salve: `{ titulo: 'Estudar React' }`.
3. Troque o `<h3>` fixo por `<h3>{props.titulo}</h3>`. "E nos outros dois?" Salve: `<h3>` vazio, sem erro. "Prop que não chega vale `undefined`; o React não desenha nada." Preencha as três tags e projete "O objeto props de perto".
4. Desestruturação primeiro no console do navegador: `const tarefa = { titulo: 'Estudar React', prioridade: 'alta' }`, depois `const { titulo } = tarefa`, depois `titulo`. Pergunte antes de cada Enter.
5. No componente, troque `(props)` por `({ titulo, prioridade })` e apague os `props.`. "Mudou algo na tela?" Nada. Remova o `console.log`.
:::

**"Props de vários tipos" a "children: o que vai dentro da tag" (12 min).** `pontos="10"` na tag e `<p>{pontos + 1} pontos</p>` no componente: a turma espera 11 e vê **101**; corrija para `pontos={10}`. Apague `prioridade` de uma tag, mostre o `<p>` vazio e escreva `prioridade = 'media'` no parâmetro. Para `children`, leia o slide com a analogia da moldura, sem digitar.

**"Pense" (5 min).** Esperado: duas props, o texto por `children` e uma `variante` com padrão `'primario'`. Se ninguém responder: "o texto 'Salvar' é conteúdo ou configuração?". Revele "Uma resposta possível".

**"Composição: componente dentro de componente" a "Próximos passos" (10 min).** Crie `src/components/ListaTarefas.jsx` com as três tags em uma `<section>` e use `<ListaTarefas />` entre `Cabecalho` e `Rodape`. Em "Props são somente leitura", digite `props.titulo = 'Outro'` e salve: tela em branco e `TypeError: Cannot assign to read only property`. Desfaça. Feche com "Nomeação e organização" e "Erros comuns".

:::tip Ritmo
Atrasou? Corte o `pontos="10"` (mostre só a tabela) e leia "Nomeação e organização" sem digitar. Nunca corte a desestruturação no console nem o `console.log(props)`: eles sustentam o laboratório.
:::

## Bloco 2 · Listas, keys e estilos (50 min)

**"O que você vai aprender" a "Arrays: várias coisas em uma só variável" (8 min).** "Como desenhar um cartão por tarefa sem saber quantas existem?" No console do navegador, cole o array `tarefas` do slide e digite, perguntando antes de cada Enter: `tarefas.length`, `tarefas[0].titulo`, `tarefas[3]` (`undefined`: o índice começa em 0).

**"map: transformar cada item em outra coisa" a "key: a etiqueta de cada item" (15 min).** Segunda demonstração lenta.

:::steps
1. No console: `[1, 2, 3].map((n) => n * 2)`. "O que sai?" Arrow function em uma frase: "recebe `n`, devolve `n * 2`". Depois `tarefas.map((t) => t.titulo)`.
2. Mova o array para o `App.jsx`, acima da função `App`, e passe `<ListaTarefas tarefas={tarefas} />`. No `ListaTarefas`, parâmetro `({ tarefas })`.
3. Apague as três tags e digite devagar `{tarefas.map((t) => (` e `))}` com `<CartaoTarefa titulo={t.titulo} prioridade={t.prioridade} concluida={t.concluida} />` dentro. "Quantos cartões?" Salve: três.
4. Leia o aviso em voz alta: `Each child in a list should have a unique "key" prop`. "Como o React sabe qual cartão é qual?" Adicione `key={t.id}`: o aviso some.
5. Acrescente uma quarta tarefa ao array e salve: quatro cartões sem tocar no `ListaTarefas`. O momento de convencimento do dia.
:::

Entre os passos 3 e 4, projete "Três tarefas, três cartões": a animação repete o `.map()` volta a volta; aponte com o dedo qual item do array vira qual cartão e use a última linha do slide para puxar o aviso de `key`.

**"Por que o id, e não o índice" a "Escolher entre dois: o ternário" (9 min).** Comente o diagrama: removida a primeira tarefa, com `key={t.id}` as outras guardam a key e com `key={i}` todas mudam; regra: "`key` é o `id` do dado". Adicione `{tarefas.length === 0 && <p>Nenhuma tarefa por aqui</p>}`, troque o array por `[]` no `App` e pergunte. No `CartaoTarefa`, `<p>{concluida ? 'Concluída' : 'Pendente'}</p>`: só "Fazer compras" fica concluída.

**"Pense" (4 min).** Esperado: junto do componente, porque duas `.cartao` no CSS global colidem e o inline não aceita `:hover`. Se ninguém responder: "se dois arquivos CSS declaram `.cartao` com cores diferentes, qual vence?".

**"Três formas de estilizar" a "No laboratório" (10 min).** Crie `CartaoTarefa.module.css` com `cartao`, `alta` e `concluida`. No componente, `import estilos from './CartaoTarefa.module.css'` e `className={estilos.cartao}`. No DevTools, a classe real é algo como `_cartao_x7f2a`. Mostre `const classeAlta = prioridade === 'alta' ? estilos.alta : ''` e o template literal na `className`. "Erros comuns" e "Resumo" em 2 min; projete "No laboratório".

**Desafio (5 min):** "Sem escrever nenhuma tag nova, faça aparecer uma quinta tarefa com prioridade alta e borda vermelha. Depois troque o array por `[]`." Quem conseguir já começa o laboratório.

:::tip Ritmo
Reduza "Por que o id, e não o índice" à regra prática e mostre só a primeira forma da classe dinâmica. Não corte o passo 5 do `.map()`.
:::

| Minuto | Todos devem ter |
|---|---|

| 35 | `ListaTarefas` com `.map()`, 5 tarefas, sem aviso de `key` |
| 50 | alta destacada; estado vazio testado com `[]` |

**Onde circular:** olhe o console, não só a tela: aviso de `key`, `key={i}`, `key={t.titulo}`. Confira `.module.css` no nome do arquivo, `estilos.` na `className`, `class` no lugar de `className`, `concluida="false"` entre aspas. Nos 10 minutos finais, só commit e push.

:::example Solução de referência
`src/components/CartaoTarefa.jsx`:

```jsx
import estilos from './CartaoTarefa.module.css'

export default function CartaoTarefa({ titulo, prioridade = 'media', concluida = false }) {
  const classeAlta = prioridade === 'alta' ? estilos.alta : ''
  const classeConcluida = concluida ? estilos.concluida : ''

  return (
    <div className={`${estilos.cartao} ${classeAlta} ${classeConcluida}`}>
      <h3>{titulo}</h3>
      <p>Prioridade: {prioridade}</p>
      <p>{concluida ? 'Concluída' : 'Pendente'}</p>
    </div>
  )
}
```

`src/components/CartaoTarefa.module.css`:

```css
.cartao {
  border: 1px solid #ccc;
  border-radius: 8px;
  padding: 12px;
  margin-bottom: 8px;
}

.alta {
  border-left: 4px solid #d33;
}

.concluida {
  opacity: 0.6;
  text-decoration: line-through;
}
```

`src/components/ListaTarefas.jsx`:

```jsx
import CartaoTarefa from './CartaoTarefa.jsx'

export default function ListaTarefas({ tarefas }) {
  return (
    <section>
      {tarefas.length === 0 && <p>Nenhuma tarefa por aqui</p>}
      {tarefas.map((t) => (
        <CartaoTarefa
          key={t.id}
          titulo={t.titulo}
          prioridade={t.prioridade}
          concluida={t.concluida}
        />
      ))}
    </section>
  )
}
```

`src/App.jsx` (se a turma manteve `<Saudacao />`, pode ficar):

```jsx
import Cabecalho from './components/Cabecalho.jsx'
import ListaTarefas from './components/ListaTarefas.jsx'
import Rodape from './components/Rodape.jsx'

const tarefas = [
  { id: 1, titulo: 'Estudar React', prioridade: 'alta', concluida: false },
  { id: 2, titulo: 'Fazer compras', prioridade: 'baixa', concluida: true },
  { id: 3, titulo: 'Ir à academia', prioridade: 'media', concluida: false },
  { id: 4, titulo: 'Entregar relatório', prioridade: 'alta', concluida: false },
  { id: 5, titulo: 'Ler um livro', prioridade: 'baixa', concluida: false },
]

function App() {
  return (
    <>
      <Cabecalho />
      <ListaTarefas tarefas={tarefas} />
      <Rodape />
    </>
  )
}

export default App
```
:::

**Critérios:** lista renderizada a partir do array; sem avisos de `key`; alta visualmente diferente; estado vazio com `[]`. **Entrega:** link do mesmo repositório do E02, com o novo commit, na atividade do encontro no sistema.

## Fechamento (25 min)

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `<h3>` vazio, sem erro | `titulo=` na tag e `props.title` dentro, ou `function CartaoTarefa(titulo)` sem chaves | `console.log(props)` e comparar com a tag |
| Aviso de `key` mesmo com `key` | a `key` foi na `<div>` do `CartaoTarefa`, não na tag que o `.map()` devolve | mover a `key` para o `<CartaoTarefa>` do `ListaTarefas` |
| Nada estiliza; `estilos.cartao` é `undefined` | arquivo salvo sem `.module`, ou caminho do `import` errado | renomear para `.module.css`; conferir o `./` |
| Um `0` acima da lista vazia | `{tarefas.length && ...}` | comparar com `=== 0` |
| `tarefas.map is not a function` | faltou `tarefas={tarefas}` no `ListaTarefas`, ou `tarefas="tarefas"` entre aspas | chaves, não aspas, na tag do `App.jsx` |
| "101 pontos" ou todas "Concluída" | número ou booleano entre aspas; `"false"` é uma string verdadeira | chaves em tudo que não é texto |
| `Missing script: dev` ou push recusado | terminal fora de `minhas-tarefas`; GitHub sem credencial neste computador | `cd minhas-tarefas`; autenticar pelo navegador quando o Git pedir |
