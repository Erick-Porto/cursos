## Visão do encontro

**Objetivo**: entender como uma página chega ao navegador, ver HTML, CSS e JavaScript no DevTools, saber por que o React existe e deixar o computador pronto para o E02.

**Resultado ao fim das 4h**: `perfil.html` e `estilo.css` abertos no navegador; Node.js LTS, Git e VS Code instalados e conferidos; conta no GitHub com nome apresentável.

**Pré-requisitos**: nenhum. Peça antes, por mensagem, notebook carregado (se houver) e um e-mail pessoal acessível pelo celular.

**Materiais**: projetor, Wi-Fi para cerca de 150 MB por máquina, um computador por aluno (ou duplas), pendrive com instaladores, quiz `quiz-e01` publicado, lista de presença.

## Antes do encontro

:::steps
1. Confira no painel se as duas aulas e o quiz `quiz-e01` estão publicados; faça uma tentativa de teste.
2. Sua máquina no estado final do laboratório: Node.js LTS, Git, VS Code com ES7+ React snippets, Prettier e Error Lens.
3. Baixe [demos-e01.zip](materiais/e01/demos-e01.zip) e descompacte: a pasta `demos-e01/` traz `contador.html` (o contador em JavaScript puro dos slides) e `perfil/` com a solução de referência e uma `foto.jpg`. Abra os dois no navegador para testar. Confira também a [versão do aluno do contador](materiais/e01/aluno/contador.html), que o slide liga.
4. Dois pendrives com Node.js LTS (`.msi` e `.zip` para Windows, `.pkg` para macOS), Git for Windows (instalador e Portable Git) e VS Code (User Installer e `.zip`).
5. Pergunte ao laboratório se há permissão de administrador e proxy; se não houver, peça hoje a instalação das três ferramentas e prepare o plano B.
6. Abas: aula no sistema, nodejs.org, code.visualstudio.com, git-scm.com, github.com/signup e um portal de notícias.
:::

## Abertura (15 min)

Sem encontro anterior nem tarefa a corrigir.

**Curso (5 min)**. Página do curso no sistema: dois módulos, React (E01 a E05) e React Native (E06 a E09); o mesmo app Minhas Tarefas no navegador e depois no celular; quiz em todo encontro, prova no E05 e no E09; conquista "Primeiro componente" após quatro aulas.

**Combinados (3 min)**. Celular guardado nos blocos de slides; ler o erro em voz alta antes de pedir ajuda; entregas pelo sistema no prazo; notebook carregado.

**Diagnóstico (4 min)**, mão levantada:

1. "Quem já salvou um arquivo de texto com a extensão que quis?" É o que mais trava o laboratório.
2. "Quem já escreveu alguma linha de código? Fórmula de planilha conta."
3. "Quem já digitou um comando em um terminal?" Prevê o tempo da conferência das versões.

Monte as duplas com uma pessoa de três mãos ao lado de uma de nenhuma.

**Objetivos (3 min)**. Projete "O que você vai aprender" da aula A e leia os itens: "No fim da tarde, o computador de vocês estará pronto para programar em React."

## Bloco 1 · A web por dentro (50 min)

**Slides "Por que isso importa" a "Front-end e back-end" (10 min)**. Deixe a pergunta do delivery no ar por 30 segundos. Em "Cliente e servidor", o notebook de cada um é o cliente; o servidor do curso está em outro prédio. Em "Front-end e back-end", a linha "Onde roda" resolve qualquer dúvida.

**Slides "HTML: a estrutura" a "As três linguagens juntas" (12 min)**. Leia o HTML como lista de peças. No CSS, `h1` e `button` são as palavras do HTML. No JavaScript: encontrar, esperar o clique, rodar. Feche com a dica: mudou cor, CSS; mudou texto, HTML; aconteceu algo, JavaScript.

**Slides "DevTools: o raio-x da página" a "Demonstração: aba Console" (18 min)**. Todos acompanham no portal de notícias.

:::steps
1. `F12`, aba **Elements**: HTML à esquerda, **Styles** à direita.
2. Seta do canto do painel, depois a manchete: o elemento fica destacado.
3. Dois cliques no texto, troque por "Olá, turma": a manchete muda.
4. Em **Styles**, troque `color` por `red`.
5. Recarregue: tudo volta. "Vocês mudaram a cópia na memória do navegador, o DOM. O servidor nem soube."
6. Aba **Console**: `console.log('Olá, turma!')`, `2 + 2` e `document.title`.
7. `console.log(Olá)` sem aspas: leia o erro vermelho com a turma.
:::

**Slide "Pense" (5 min)**. Esperado: sem JavaScript a página aparece, mas o botão não faz nada; sem CSS, texto preto, links azuis, imagens no tamanho original. Se ninguém responder, faça o teste da dica: "Disable JavaScript" no DevTools, recarregue e pergunte o que parou.

**Slides "O que faz um programador mobile" a "Próximos passos" (5 min)**. Destaque o quadro "Por que começar pela web": a turma precisa sair sabendo que a web é só o caminho até o celular. Erros comuns e resumo: leia sem comentar; voltam no quiz.

:::tip Ritmo
Atrasado? Resuma "O que faz um programador mobile" em uma frase e pule o passo 7. Nunca corte a aba Elements.
:::

## Bloco 2 · Por que React (50 min)

**Slides "Por que isso importa" a "O problema cresce com a tela" (12 min)**. Abra `contador.html` e clique três vezes. Comente a linha `span.textContent = total`, recarregue e clique: a tela mostra 0; no Console, `total` vale 3. "A variável mudou; a tela não. Manter os dois em dia é trabalho seu." É o bug de uma questão do quiz.

A turma acompanha pela [versão do aluno](materiais/e01/aluno/contador.html), aberta pelo link do slide: o mesmo contador com um quadro "Na memória" (quem está no celular ou sem DevTools vê o valor de `total`), uma chave que desliga a linha sem editar código e a explicação linha por linha. Peça que repitam os quatro passos da página junto com você.

**Slides "O mesmo contador em React" a "Um molde, muitas peças" (13 min)**. Só leitura. `Cliques: {total}` é a tela inteira; quando `total` muda, o React cuida do resto. Na árvore, `CartaoTarefa` aparece três vezes: "Se o cartão tiver um bug, em quantos lugares você corrige?" Um.

**Slide "Pense" (5 min)**. Esperado: `Cabecalho` com `CampoBusca`, `ListaCategorias` com vários `ChipCategoria`, `ListaRestaurantes` com vários `CartaoRestaurante`, `BarraInferior` com três `BotaoAba`; repetem-se chip, cartão e botão; `App`, listas e cartão contêm outros. Sem resposta, desenhe retângulos no quadro e pergunte só "o que se repete?".

**Slides "SPA: uma página, muitas telas" a "Mercado e tendência" (8 min)**. Navegue pelo painel do curso: a tela não pisca. No ecossistema, hoje só o Node.js é instalado; a conta do GitHub de hoje é o começo do portfólio.

**Slides "Erros comuns" a "Checklist de instalação" (7 min)**. Deixe o checklist projetado até o fim do laboratório. Mostre o botão LTS do nodejs.org e o seu `node -v`. Leia a dica de reabrir o terminal: a dificuldade mais frequente do dia.

**Desafio (5 min)**. Projete "No laboratório" e lance: "Antes da pausa, criem a pasta `perfil` na Área de Trabalho com `perfil.html` e um `h1` com o seu nome; abram no navegador; quem conseguir, inicie o download do Node.js LTS." Sem VS Code, vale Bloco de Notas.

:::tip Ritmo
Reduza "Mercado e tendência" a uma frase e "SPA" a dois minutos. Nunca corte o checklist nem o desafio.
:::

## Laboratório (70 min)

**Enunciado**: `perfil.html` e `estilo.css` com foto, nome e três links, inspecionados no DevTools; instalar Node.js LTS e Git; conferir as versões; criar a conta no GitHub com um nome que caiba em um currículo.

**Organização**: individual; quem não tem computador faz a página em dupla. Nos primeiros 5 minutos, identifique quem não tem permissão de administrador e aplique o plano B.

**Marcos**: 10 min, `perfil.html` aberto no navegador e downloads em andamento; 25 min, `estilo.css` ligado (sem foto, avatar do GitHub: `https://github.com/SEU-USUARIO.png`); 45 min, Node.js e Git instalados, terminal reaberto, três versões na tela; 60 min, GitHub confirmado e VS Code com extensões; 70 min, captura e arquivos enviados.

**Onde circular**: fileiras do fundo. Observe se o arquivo virou `.txt` (ative "extensões de nome de arquivo" no Explorador), se a aba Network mostra `estilo.css` em vermelho e se alguém travou em um instalador pedindo senha.

| Sistema | Terminal | Comandos | Se falhar |
|---|---|---|---|
| Windows | Win + X, "Terminal" | `node -v`, `npm -v`, `git --version` | "não é reconhecido": feche terminal e VS Code e reabra |
| macOS | Cmd + Espaço, "Terminal" | os mesmos | `git` pede as ferramentas de linha de comando: aceite |
| Linux | Ctrl + Alt + T | os mesmos | `sudo apt install git`; Node.js pelo site ou `nvm`, não pelo `apt` |

**Sem permissão para instalar**: tente as versões sem administrador (Node.js `.zip` em Documentos, Portable Git, User Installer do VS Code). Se antivírus ou proxy continuarem barrando, use uma máquina preparada; sem ela, o aluno cria a conta no GitHub, um repositório `perfil` e escreve os dois arquivos no editor online. A instalação fica para casa; confira no E02.

## Fechamento (25 min)

**Correção coletiva (10 min)**. Projete três páginas: uma caprichada, uma com problema de CSS, uma com avatar do GitHub. Elogie `alt` na imagem, `ul`/`li` nos links, CSS separado, textos de link descritivos. Aponte sem nomear: `style` dentro do HTML, `href` sem `https://` (vira caminho relativo), tag sem fechar, nome de arquivo com espaço ou acento.

**Quiz (15 min)**. Abra `quiz-e01` ("Quiz: E01 · A web, o celular e o React"): sete questões, três tentativas, 70% para aprovar, gabarito ao fim. Sem máquina, pelo celular. Peça que leiam a explicação de cada erro antes de tentar de novo.

**Usar o resultado**: veja no painel as questões com mais erro. O contador que não atualiza e as afirmações sobre o DevTools costumam ser as piores: abra o E02 refazendo o `contador.html`. Erros em `node -v` apontam quem não instalou.

## Encerramento (5 min)

**Tarefa de casa**: revisar e concluir as duas aulas no sistema; terminar a instalação com o checklist e tirar a captura; completar o perfil do GitHub com foto. Quem ficou no plano B chega 20 minutos antes no E02.

**Prévia do E02**: "Ambiente de desenvolvimento: Node.js, npm, VS Code e Git" e "Primeiro projeto React com Vite e JSX". "O terminal de hoje cria um projeto React com um comando, e o contador vai rodar de verdade."

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `node` "não é reconhecido" após instalar | Terminal aberto antes da instalação | Fechar tudo e reabrir |
| Instalador pede senha de administrador | Conta restrita | Node.js `.zip`, Portable Git, User Installer; se bloquear, plano B |
| "O Windows protegeu o computador" ou antivírus apaga o instalador | SmartScreen ou antivírus | "Mais informações", "Executar assim mesmo"; se barrar, pendrive |
| Download parado em 0% | Proxy ou Wi-Fi saturado | Pendrive; escalonar downloads por fileira |
| Página sem estilo | `href` errado, `estilo.css.txt` ou outra pasta | Mostrar extensões; conferir `estilo.css` na aba Network |
| GitHub não confirma ou recusa o nome | E-mail com filtro; nome com espaço ou em uso | E-mail pessoal, conferir spam; só letras, números e hífen |
