## Abertura (15 min)

Perguntas de retomada (6 min), com a resposta esperada:

1. "Por que `tarefas.push(nova)` seguido de `setTarefas(tarefas)` não muda a tela?" — `push` muta o mesmo array; React vê o mesmo objeto e não redesenha. Precisa de `[...tarefas, nova]`.
2. "O que acontece se eu apagar o `event.preventDefault()` do `onSubmit`?" — a página recarrega e o estado volta ao inicial.
3. "Onde mora o array `tarefas` e como o `FormularioTarefa` adiciona uma tarefa?" — no `App`; o formulário recebe `onAdicionar` por prop e a chama.

Tarefa de casa (5 min): dois alunos mostram o app adicionando, concluindo e removendo; confira no GitHub de um terceiro o commit "E04: estado e formulário". Comente as questões mais erradas do quiz E04, em geral `onClick={contar()}` e o `forEach` que muta o estado: as duas voltam na prova.

Objetivos (4 min): projete "O que você vai aprender" da aula 9 e anuncie: "Aula nova de 50 minutos, revisão de 50, laboratório de 40 e, às 3:00, a Prova 1. O quiz desta aula fica para casa."

:::example Solução de referência
`src/App.jsx`, parte 1: busca e efeito, exatamente como na aula 9.

```jsx
import { useState, useEffect } from 'react'
import Cabecalho from './components/Cabecalho'
import FormularioTarefa from './components/FormularioTarefa'
import ListaTarefas from './components/ListaTarefas'

const URL_API = 'https://jsonplaceholder.typicode.com/todos?_limit=10'

async function carregarTarefas() {
  const resposta = await fetch(URL_API)
  const dados = await resposta.json()
  return dados.map((item) => ({
    id: item.id,
    titulo: item.title,
    concluida: item.completed,
    prioridade: 'media',
  }))
}

function App() {
  const [tarefas, setTarefas] = useState([])
  const [carregando, setCarregando] = useState(true)
  const [erro, setErro] = useState(null)

  useEffect(() => {
    async function iniciar() {
      try {
        const lista = await carregarTarefas()
        setTarefas(lista)
      } catch (e) {
        setErro('Não foi possível carregar as tarefas.')
      } finally {
        setCarregando(false)
      }
    }
    iniciar()
  }, [])
```

Parte 2: funções do E04 e JSX condicional; os nomes das props seguem o que o aluno usou no E04.

```jsx
  function adicionarTarefa(titulo, prioridade) {
    const nova = { id: Date.now(), titulo, prioridade, concluida: false }
    setTarefas([...tarefas, nova])
  }

  function alternarConcluida(id) {
    setTarefas(tarefas.map((t) => (t.id === id ? { ...t, concluida: !t.concluida } : t)))
  }

  function removerTarefa(id) {
    setTarefas(tarefas.filter((t) => t.id !== id))
  }

  const pendentes = tarefas.filter((t) => !t.concluida).length

  return (
    <div>
      <Cabecalho pendentes={pendentes} />
      <FormularioTarefa onAdicionar={adicionarTarefa} />
      {erro && <p className="erro">{erro}</p>}
      {carregando ? (
        <p>Carregando...</p>
      ) : (
        <ListaTarefas tarefas={tarefas} onAlternar={alternarConcluida} onRemover={removerTarefa} />
      )}
    </div>
  )
}

export default App
```
:::

Critérios: dez tarefas da API ao abrir; "Carregando..." antes delas; mensagem de erro sem rede; uma única requisição; console sem erros; adicionar, concluir e remover funcionando; README com o que o projeto faz e como rodar.

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| `dados.map is not a function` | Faltou `await` antes de `fetch` ou de `resposta.json()` | `console.log(dados)` mostra uma Promise; adicione os dois `await` |
| Tela pisca; aba Rede com dezenas de requisições | `useEffect` sem o `[]` | Olhe o fim do efeito e complete `}, [])` |
| Aviso "useEffect must not return anything besides a function" | `useEffect(async () => ...)` | Crie `iniciar` dentro do efeito e chame-a |
| "Carregando..." para sempre, sem erro | `setCarregando(false)` dentro do `try` e a requisição falhou, ou URL errada | Mova para o `finally`; veja o status na aba Rede |
| Cartões sem título ou prioridade | `setTarefas(dados)` sem o `map` de tradução | Compare o JSON da API com as props do `CartaoTarefa` |
| `Failed to fetch` com Wi-Fi funcionando | API fora do ar ou bloqueada pela rede da escola | Troque `URL_API` por `'/tarefas.json'` |
| `git push` recusado ou pedindo senha | Token expirado ou remoto errado | `git remote -v`; refaça o login; se não resolver, push de casa |
