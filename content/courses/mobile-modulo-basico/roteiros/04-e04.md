## Abertura (15 min)

Três perguntas rápidas, sem projetar código (5 min):

1. "O que é uma prop e quem decide o valor dela?" Esperado: valor passado na tag; o pai decide, o filho só lê.
2. "Por que o React pede `key` no `.map()`, e por que o `id` e não o índice?" Esperado: a key identifica o dado quando a lista muda; o índice, só a posição.
3. "O que vale `estilos.cartao` depois do `import` do CSS Module?" Esperado: um nome de classe gerado e único, como `_cartao_x7f2a`.

Tarefa de casa (5 min): projete os dois repositórios. Elogie `key={t.id}` e o estado vazio com `=== 0`; aponte o detalhe do segundo (em geral `key={i}` ou um `0` sobrando na tela). Cite as questões do quiz E03 com mais erros: elas voltam hoje.

Objetivos (5 min): leia o slide "O que você vai aprender". Diga: "Até o fim de hoje, o app deixa de ser um cartaz."

## Bloco 1 · Eventos e estado com useState (50 min)

**Slides "Por que isso importa" e "Eventos no JSX" (7 min).** Recolha duas hipóteses para a pergunta do slide, sem corrigir. Mostre o erro das colunas ao vivo: com `onClick={avisar()}` o `alert` dispara ao carregar a página.

**Slide "O problema: a variável comum não redesenha" (9 min).** Demonstração ao vivo:

:::steps
1. Em `Contador.jsx`, digite o código do slide (`let contador = 0` fora da função; `contador++` e `console.log` em `contar`) e use `<Contador />` no `App`.
2. Antes de clicar: "Depois de três cliques, o que o botão mostra?" Mãos levantadas para "3", "0" ou "dá erro".
3. Com o console aberto, clique três vezes: o console imprime 1, 2, 3 e o botão fica em `Cliques: 0`.
4. "A variável mudou; por que a tela não?" Deixe a turma chegar lá: ninguém avisou o React.
:::

**Slides "useState: a memória do componente" e "Exemplo completo: contador" (8 min).** Refatore o mesmo arquivo: `import { useState } from 'react'`, `const [contador, setContador] = useState(0)` dentro da função, `setContador(contador + 1)`. Clique: funciona. Pergunte "por que o `0` só vale na primeira vez?" (depois o React devolve o valor guardado).

**Slide "O ciclo de um clique" (dentro dos mesmos 8 min).** Deixe a animação rodar uma vez em silêncio e, na segunda, narre os três passos: clique, `setContador` pede o redesenho, o React chama `Contador()` de novo e o botão mostra 1. Pergunte "em qual passo o `let contador` falhava?" (no segundo: ninguém pedia o redesenho).

**Slide "Pense" (5 min).** Esperado: tocando/pausado (`false`), progresso (`0`), volume (`50`) e curtido (`false`) são estado; nome da música e próximas faixas vêm por props. Se ninguém responder, comece pelo tocar/pausar: "muda quando você clica? Então é estado. Qual o valor inicial?"

**Slides "Estado com arrays: nunca mutar" a "Receita 3: alterar com map" (11 min).** `push` é o erro mais comum do dia. Mini-exercício de 3 min: todos abrem o console do navegador (F12) e digitam, com você ditando:

```javascript
const tarefas = [{ id: 1, titulo: 'Ler' }, { id: 2, titulo: 'Correr' }]
const mais = [...tarefas, { id: 3, titulo: 'Dormir' }]
const menos = tarefas.filter((t) => t.id !== 2)
const feitas = tarefas.map((t) => (t.id === 1 ? { ...t, concluida: true } : t))
tarefas
```

Confiram: `tarefas` segue intacto; `mais` tem três itens; `menos`, um; `feitas`, dois com só o primeiro marcado. Depois a prova: `const a = [1]; const b = a; b.push(2); a === b` dá `true`. "É isso que o React vê com `push`: o mesmo array." Ligue cada slide de receita à linha do console.

**Slides "No projeto: alternarConcluida no App" e "CartaoTarefa: o botão Concluir" (7 min).** Renomeie o array para `tarefasIniciais`, crie `useState(tarefasIniciais)` e digite `alternarConcluida` com `map`. Passe `onAlternar` e `id={t.id}` por `ListaTarefas` até o botão `onClick={() => onAlternar(id)}`. Clique: o cartão fica riscado. Destaque a arrow function e que o cartão só avisa; quem muda a lista é o `App`.

**Slides "A atualização não é imediata" a "Próximos passos" (3 min).** Mostre o `console.log` após o `set` exibindo o valor antigo. Erros comuns: o checklist do laboratório.

:::tip Ritmo
Com pouco tempo, faça o mini-exercício só no seu console e reduza o "Pense" a 3 min. Não corte a demonstração do contador: ela sustenta o encontro.
:::

## Bloco 2 · Formulários controlados (50 min)

**Slides "Por que isso importa" e "Input controlado" (7 min).** Pergunte "onde fica o texto enquanto a pessoa digita?"; a maioria dirá "no campo". Crie `FormularioTarefa.jsx` com o input do slide e um `<p>Você digitou: {texto}</p>` provisório: o estado acompanha cada tecla.

**Slide "Por que 'controlado'" (5 min).** Leia os passos. Apague o `onChange` e tente digitar: campo travado. Pergunte por quê (o campo obedece ao estado, que não muda). Restaure.

**Slides "Enviando com form e preventDefault" e "Validação e limpeza do campo" (9 min).** Embrulhe o input em um `form` com `onSubmit={enviar}`, de propósito sem `preventDefault`. Aperte Enter: a página recarrega e o contador zera. Adicione `event.preventDefault()`, depois `if (texto.trim() === '') return` e `setTexto('')`; o campo limpa sozinho porque é controlado.

**Slide "select controlado para a prioridade" (4 min).** Adicione o `select` com `useState('media')`; `e.target.value` sempre chega como texto.

**Slide "Pense" (5 min).** Esperado: três `useState` separados seriam três listas que não se enxergam; a tarefa do formulário não apareceria na lista. O array mora no `App`. Se ninguém responder, desenhe a árvore no quadro e pergunte "qual é o pai comum?".

**Slides "Onde o estado deve morar" a "FormularioTarefa: o JSX" (7 min).** Percorra a tabela: quem guarda, quem cria, quem mostra, quem conta. Troque o `console.log` por `onAdicionar(titulo, prioridade)` e mostre o componente completo.

**Slides "Cada tarefa precisa de um id" e "App: o dono das tarefas" (5 min).** Digite `Date.now()` duas vezes no console. Escreva `adicionarTarefa` com spread e o atalho `{ titulo, prioridade }`; adicione uma tarefa pela tela.

**Slides "Fluxo de dados em uma direção" a "Resumo" (3 min).** Dados descem por props, eventos sobem por funções: uma fonte da verdade.

**Desafio (5 min).** "Em duplas, escrevam `removerTarefa(id)` com uma das três receitas e digam qual." Esperado: `filter` com `t.id !== id`; corrija quem usou `splice`. Então leia o slide "No laboratório": seis passos e critérios.

:::tip Ritmo
Atrasado? Junte `select` e `id` em 4 min e encurte o "Pense". Não pule o formulário recarregando a página: é o erro mais comum do laboratório.
:::

## Laboratório (70 min)

**Enunciado (slide "No laboratório"):** array em `useState` no `App`; `FormularioTarefa.jsx` recebendo `onAdicionar`; `adicionarTarefa`, `alternarConcluida` e `removerTarefa` no `App`, passadas até `CartaoTarefa`, que ganha Concluir e Remover; `pendentes` no `Cabecalho`; tarefa vazia bloqueada e campo limpo; commit "E04: estado e formulário" e push.

**Organização:** individual; quem não entregou o E03 faz dupla com quem entregou, no projeto do colega.

**Marcos (no quadro):** 15 min, Concluir riscando o cartão; 35 min, `FormularioTarefa` adicionando; 50 min, `removerTarefa` e contador; 60 min, validação, campo limpo, console sem avisos; 70 min, push e link entregue.

**Onde circular:** duplas primeiro, depois o fundo da sala. Quatro pontos: arrow function no `onClick`; nenhum `push`; `event.preventDefault()` na primeira linha de `enviar`; `value` e `onChange` juntos. Extra para quem terminar cedo: botão "Limpar concluídas" com `filter`.

:::example Solução de referência
`src/App.jsx`:

```jsx
import { useState } from 'react'
import Cabecalho from './components/Cabecalho.jsx'
import FormularioTarefa from './components/FormularioTarefa.jsx'
import ListaTarefas from './components/ListaTarefas.jsx'
import Rodape from './components/Rodape.jsx'

const tarefasIniciais = [
  { id: 1, titulo: 'Estudar React', prioridade: 'alta', concluida: false },
  { id: 2, titulo: 'Fazer compras', prioridade: 'baixa', concluida: true },
]

function App() {
  const [tarefas, setTarefas] = useState(tarefasIniciais)
  const pendentes = tarefas.filter((t) => !t.concluida).length

  function adicionarTarefa(titulo, prioridade) {
    const nova = { id: Date.now(), titulo, prioridade, concluida: false }
    setTarefas([...tarefas, nova])
  }

  function alternarConcluida(id) {
    setTarefas(tarefas.map((t) => (t.id === id ? { ...t, concluida: !t.concluida } : t)))
  }

  function removerTarefa(id) {
    setTarefas(tarefas.filter((t) => t.id !== id))
  }

  return (
    <>
      <Cabecalho pendentes={pendentes} />
      <FormularioTarefa onAdicionar={adicionarTarefa} />
      <ListaTarefas tarefas={tarefas} onAlternar={alternarConcluida} onRemover={removerTarefa} />
      <Rodape />
    </>
  )
}

export default App
```

`src/components/FormularioTarefa.jsx`:

```jsx
import { useState } from 'react'

function FormularioTarefa({ onAdicionar }) {
  const [titulo, setTitulo] = useState('')
  const [prioridade, setPrioridade] = useState('media')

  function enviar(event) {
    event.preventDefault()
    if (titulo.trim() === '') return
    onAdicionar(titulo, prioridade)
    setTitulo('')
  }

  return (
    <form onSubmit={enviar}>
      <input
        value={titulo}
        onChange={(e) => setTitulo(e.target.value)}
        placeholder="O que precisa fazer?"
      />
      <select value={prioridade} onChange={(e) => setPrioridade(e.target.value)}>
        <option value="alta">Alta</option>
        <option value="media">Média</option>
        <option value="baixa">Baixa</option>
      </select>
      <button type="submit">Adicionar</button>
    </form>
  )
}

export default FormularioTarefa
```

`src/components/CartaoTarefa.jsx`:

```jsx
import estilos from './CartaoTarefa.module.css'

export default function CartaoTarefa({ id, titulo, prioridade, concluida, onAlternar, onRemover }) {
  const classeAlta = prioridade === 'alta' ? estilos.alta : ''
  const classeConcluida = concluida ? estilos.concluida : ''

  return (
    <div className={`${estilos.cartao} ${classeAlta} ${classeConcluida}`}>
      <h3>{titulo}</h3>
      <p>Prioridade: {prioridade}</p>
      <button onClick={() => onAlternar(id)}>{concluida ? 'Reabrir' : 'Concluir'}</button>
      <button onClick={() => onRemover(id)}>Remover</button>
    </div>
  )
}
```

`ListaTarefas.jsx` repassa as funções; `Cabecalho.jsx` ganha `pendentes`:

```jsx
import CartaoTarefa from './CartaoTarefa.jsx'

export default function ListaTarefas({ tarefas, onAlternar, onRemover }) {
  return (
    <section>
      {tarefas.length === 0 && <p>Nenhuma tarefa por aqui</p>}
      {tarefas.map((t) => (
        <CartaoTarefa key={t.id} id={t.id} titulo={t.titulo} prioridade={t.prioridade}
          concluida={t.concluida} onAlternar={onAlternar} onRemover={onRemover} />
      ))}
    </section>
  )
}
```

```jsx
export default function Cabecalho({ pendentes }) {
  return (
    <header>
      <h1>Minhas Tarefas</h1>
      <p>{pendentes} pendente(s)</p>
    </header>
  )
}
```

## Dificuldades frequentes

| Sintoma | Causa provável | Como ajudar |
|---|---|---|
| Ação dispara ao carregar a página, ou "Too many re-renders" | `onClick={funcao()}` com parênteses | Tire os parênteses ou embrulhe: `() => funcao(id)` |
| Concluir não muda a tela, mas o `console.log` mostra o valor novo | Mutação (`push`, `t.concluida = true`) ou variável comum | "O array entregue ao `setTarefas` é novo?"; refaça com as receitas |
| "useState is not defined" | Falta o `import` | `import { useState } from 'react'` |
| Ao adicionar, a página pisca e a lista volta ao início | Sem `event.preventDefault()`, ou `onClick` no botão em vez de `onSubmit` | `preventDefault` na primeira linha de `enviar`; botão `type="submit"` |
| Campo não aceita digitação | `value` sem `onChange` | `onChange={(e) => setTitulo(e.target.value)}` |
| Tarefa entra, mas o campo não limpa | Input sem `value` | `value={titulo}` |
| "onAlternar is not a function" ou aviso de `key` na tarefa nova | Prop não repassada pelo `ListaTarefas`; `id` esquecido em `nova` | Siga a cadeia `App`, `ListaTarefas`, `CartaoTarefa`; confira `Date.now()` |
| Salva e nada muda; terminal parado | `npm run dev` caiu ou roda em outra pasta ("Missing script: dev") | `cd minhas-tarefas` e `npm run dev` |
